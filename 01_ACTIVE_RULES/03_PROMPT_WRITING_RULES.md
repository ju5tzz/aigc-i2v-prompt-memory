# Prompt Writing Rules

## 0. 故事优先于运镜

AI 视频不是让画面动起来就行，而是要让镜头替故事组织信息和情绪。

镜头设计既不能长期停留在安全、保守、模板化的固定中景，也不能为了展示技术而堆叠复杂运镜。

选择景别、机位、运镜和剪辑节奏前，先回答：

- 当前镜头要让观众看到什么。
- 当前镜头要推进哪个动作或剧情信息。
- 当前镜头要让观众产生什么情绪变化。
- 当前镜头为什么需要移动，或者为什么应该保持静止。

复杂度不是高级感的标准。镜头是否准确服务故事，才是标准。

## 1. 片段类型判断

写提示词前，先判断当前片段属于哪一类：

- 普通对话
- 单人动作
- 空间发现
- 复杂调度
- 机械奇观
- 战场 / 城池 / 阵地
- 角色表演
- 道具特写
- 转场 / 过渡
- 覆盖镜头素材

## 2. 信息密度检查

低信息密度提示词会导致平均水准输出。

弱写法：

```text
一个农民在深夜把地下党藏在地窖里，紧张，感人。
```

这类写法只提供剧情概括和抽象情绪，模型不知道按什么节奏、镜头、动作细节和光影质感执行。

写 I2V 提示词前，应检查是否已经回答：

- 主体：谁在画面里。
- 动作：主体正在做什么，动作是否可见。
- 场景：年代、地点、空间是否明确。
- 光影：主要光源、时间和色调是否明确。
- 镜头：景别、机位、运镜或是否固定。
- 风格：项目视觉调性是否明确。
- 约束：当前最不能出错的内容是什么。
- 结束：片段最后停在哪里。

这些是检查清单，不是机械填空模板。简单补镜、道具特写、单人反应镜头可以删减，但不能让模型只凭抽象剧情自行补全。

## 3. 时间轴切片是可选骨架

对常规 15 秒片段，可以使用四段式时间轴作为新手骨架：

```text
0-3 秒：全景，交代环境。
3-7 秒：中景，主体出现并开始动作。
7-11 秒：特写，动作细节或情绪放大。
11-15 秒：拉远 / 收尾 / 转折。
```

这个结构适合把一段剧情概述转成可执行分镜。

但它不是硬规则。镜头时长仍由片段任务决定：

- 竖屏爆点可使用 1-2 秒快切。
- 情绪戏可使用静止凝视或慢推。
- 空间揭示可使用 5-8 秒连续镜头。
- 一镜到底可以作为非常规手段保留。

不要机械把所有 15 秒片段都切成同一个节奏。

## 4. 历史细节必须具体化

不要期待模型自动理解历史时期、地域和服装细节。

弱写法：

```text
抗战时期的村庄。
```

更稳写法：

```text
1942 年华北农村，青瓦土墙院落，屋内昏黄油灯，农民穿打补丁的粗布棉袄，泥地上有冰霜。
```

历史短剧提示词应尽量写清：

- 年代。
- 地域。
- 建筑。
- 服装。
- 军装。
- 道具。
- 生活质感。
- 光源类型。

## 5. 什么时候升级到专业拍摄语言

适合升级：

- 空间关系复杂。
- 信息需要逐步揭示。
- 镜头有明确运动路线。
- 角色行动路径容易误判。
- 视线发现顺序很重要。
- 战场、城门、楼梯、走廊、二楼平台等空间复杂。

不需要升级：

- 单人固定机位说话。
- 简单正反打。
- 普通站立、坐下、转头。
- 单一道具动作。
- 普通口播。
- 无复杂空间关系的小动作。

## 6. 微表情写法

微表情是把抽象情绪翻译成 I2V 可执行表演的中间层。

不要只写：

```text
她很开心。
```

```text
他非常害怕。
```

```text
她很悲伤。
```

更稳写法：

```text
她嘴角轻轻上扬，眼神放松柔和，脸颊微微抬起。
```

```text
他眼睛睁大，眉毛上提，嘴唇微张，肩膀微微后缩。
```

```text
她眼眶泛红，嘴唇紧抿，低头停顿半秒，右手攥住衣角。
```

### 使用范围

适合写细微表情：

- 近景。
- 中近景。
- 面部特写。
- 对话反应镜头。
- 情绪转折镜头。

不适合写细微表情：

- 远景。
- 大远景。
- 群像调度。
- 快速动作镜头。
- 战场混乱镜头。

在远景中不要写“瞳孔放大、嘴唇轻颤”这类细节，模型很难稳定执行。应改成更大的身体动作，例如后退、停住、低头、握拳、跪倒。

### 表情锚点不要过量

一个镜头通常选择 2-4 个微表情锚点即可：

- 眼神 + 嘴角。
- 眼神 + 眉毛 + 呼吸。
- 嘴唇 + 头部动作 + 手部动作。
- 眼眶 + 低头 + 声音。

不要在同一个镜头中堆叠过多互相竞争的表演指令。

## 6.1 当前片段前置信息的使用边界

当前片段前置信息可以帮助模型理解角色为什么在此刻产生某种表演、语气、停顿或动作选择。

它不等于全局剧情梗概，也不等于完整前情复述。前置信息只保留能服务当前片段生成效果的原因。

例如：

```text
【当前片段前置信息】
她今天刚因为替同事背锅被公司解雇，此刻不想让任何人看出自己崩溃。
```

再写：

```text
她坐在公交车靠窗位置，低头忍着眼泪，肩膀轻轻发抖。
```

这类画面外信息虽然不能直接被镜头拍到，但会影响模型对哭泣方式、压抑程度、台词语气和停顿的理解。

经过 2026-06-28 实测，类似信息不仅会影响角色动作和视线，也可能影响台词配音的语气，例如让诱导、试探、心虚等潜台词更明确。

适合使用：

- 当前表演依赖画面外原因。
- 多角色互相隐瞒、误会、试探、背叛、嫁祸。
- 角色表面动作和真实目的不一致。
- 台词需要潜台词、诱导感、压迫感或心虚感。
- 单人情绪戏需要说明崩溃、隐忍、麻木或爆发的来源。

不适合使用：

- 简单动作镜头。
- 单一道具特写。
- 画面关系已经足够清楚的小片段。
- 完整复述上一集、整段剧本或与当前表演无关的背景。
- 写入角色不会在当前片段中体现的未来信息。

推荐写法：

```text
【当前片段前置信息】
陆衡误以为沈砚只是奉命审问自己，但已经怀疑降书是伪造的。
沈砚知道自己是叛徒，必须诱导陆衡签字，才能坐实陆衡通敌。
阿照亲眼看见沈砚伪造封泥，但双手被绑，只能用视线提醒陆衡。
本段只生成：陆衡从犹豫签字，转为发现沈砚破绽。
```

## 6.2 环境参与的使用边界

环境参与不是给每个镜头添加气氛词，而是在当前片段的关键戏剧节点，让雨声、雷声、闪电、灯影、风、火光、门帘、阴影或道具细微变化参与叙事。

经过 2026-06-28 实测，类似“角色即将签字时，雷声响起，闪电一刹那照亮他的脸”这类细节，可以明显提升关键时刻的戏剧质感。

环境参与应写进具体镜头的画面、人物动作或声音中，不应作为独立的空泛氛围说明。

适合使用：

- 高潮前的停顿。
- 关键发现。
- 身份反转。
- 谎言被识破。
- 角色做出重大决定的一瞬间。
- 情绪从压抑转向爆发的卡点。

不适合使用：

- 普通对白全程铺满环境描写。
- 每个镜头都加入雷声、闪电、火光、风雨等强刺激。
- 环境物件比人物表演更抢眼。
- 已经有强动作或强表演时继续堆叠环境戏。

推荐写法：

```text
陆衡的手即将碰到毛笔时，帐外突然响起一声闷雷，闪电从帐缝掠过，一瞬间照亮他的半张脸，他的动作停住。
```

弱写法：

```text
帐外下雨，灯光摇晃，气氛紧张。
```

## 7. 竖屏短剧镜头不能过度保守

9:16 竖屏短剧提示词不能长期停留在“中景 / 中近景、平视、固定、固定微推”的安全组合里。

这种写法结构上看似完整，但画面会变成连续站桩对白，缺少短剧需要的情绪卡点、反应节奏和视觉变化。

尤其是奇迹发生、身份反转、众人震惊、刀落地、跪谢、被打断、结尾钩子这类强戏剧节点，应主动使用更有节奏的镜头组合：

- 单人近景微侧快切。
- 慢动作特写。
- 手部、刀、水壶、膝盖落地等物件或动作特写。
- 画外音怒斥，人物暂不入画。
- 反应镜头组，每个人出现时间相同。
- 低机位、俯拍、侧逆光、前景遮挡。
- 近景单人镜头拆长对白。
- 从静态固定镜头切到突然推近、甩向、跟进或压迫式构图。

但快切不是越多越好。竖屏爆点镜头必须控制主次关系。

反应镜头应分层使用：

- 核心人物：可以给近景或特写。
- 次要关键人物：可以给短反应镜头。
- 普通士兵 / 群众：优先用群体反应、背景反应或声音，不要轻易给大量单人特写。

如果主要人物已经连续给出反应特写，不要再给大量普通士兵特写，否则容易形成镜头重叠、信息重复和主次不分。

错误方向：

```text
镜头1：4秒，中近景，平视，固定。
镜头2：4秒，中景，平视，固定。
镜头3：4秒，中近景，平视，固定微推。
```

正确方向：

```text
【5秒】【单人近景微侧快切】老军医、李校尉、普通士兵依次出现，每个人出现时间相同，表情不可置信，呆愣愣地看向镜头外的萧烈。

【3秒】【慢动作特写】李校尉手中的钢刀“哐当”掉在地上。

【3秒】【近景侧面，单人镜头】李校尉惊喜若狂，大喊：“王爷！王爷活了！”
```

短剧提示词应根据戏剧功能选择镜头，而不是每个段落都平均分配为中景说明。

## 8. 冷开场不是默认解法

不要把“短视频强钩子”机械理解为必须冷开场。

在改写剧本大纲或写分镜前，先判断正片第一场是否已经具备强冲突、强动作或强悬念。如果第一场本身就是追逐、突袭、刺杀、审判、兵临城下等强事件，通常应直接从该事件开场。

冷开场只有在它提供新的信息、新情绪或新的视觉差异时才有价值。若冷开场与后文关键事件重复，例如先拍一次“被擒”，后文又拍一次“落马被擒”，会削弱节奏而不是增强节奏。

适合使用冷开场：

- 正片开头较平，需要提前建立危险。
- 冷开场展示的是后文暂时看不到的结果、代价或悬念。
- 冷开场与正片开头在画面、事件和情绪上有明显差异。

不适合使用冷开场：

- 正片第一场已经是强动作或强冲突。
- 冷开场与后文高光事件重复。
- 冷开场只是把后文同一危机提前展示一遍。

## 9. 核心道具要少而准

核心道具不是出镜越多越好。道具越重要，越要把露出放在关键戏剧时刻。

优先安排核心道具出现的位置：

- 首次建立身份、任务或承诺。
- 道具被夺走、踩踏、摔落、污染等尊严受辱时刻。
- 主角主动夺回、握紧、举起、拒绝放手等意志反击时刻。
- 段落结尾的视觉钩子。

避免每个紧张段落都重复给道具特写。过度出现会把精神锚点降级成普通随身物。

## 10. 完整分镜前先做节奏预案

当用户要把完整剧本大纲改成分镜提示词时，不要总是直接展开全集分镜。先判断整集是否会因为连续快切、连续特写或连续压迫构图而节奏趋同。

如果是整集、整段或多场戏的分镜任务，应先提出 2-4 个节奏变化方向，与用户确认后再写完整分镜。

可选方向包括：

- 追逐段：贴地快切、横向包抄、前景掠过，突出速度。
- 连续动作段：一镜到底，突出空间、路径和压迫。
- 道具或身份段：慢动作特写、声音卡点，突出仪式感。
- 转场段：风沙、火光、门帘、阴影等实拍感遮挡，承担真实切换。
- 对峙段：减少切镜，用低机位长压迫镜头制造窒息感。

用户确认节奏方案后，再进入完整分镜提示词写作。

## 11. 运镜写法

不要只写设备名词或笼统动作。

错误写法：

```text
使用摇臂镜头展现大场面。
```

正确写法：

```text
镜头从贴近回回炮木轮的低位开始，沿摇臂缓慢升高并后拉，先露出单台主炮，再露出同一方向排列的多台回回炮，最后停在阵地中远景。
```

### 一镜到底

一镜到底可以成立，但在 9:16 竖屏短剧中属于非常规拍摄手段，不应过度使用。

适合：

- 入帐。
- 押送。
- 突然打断。
- 空间进入。
- 单一动作路径。

不适合：

- 普通对白。
- 需要强反应快切的短剧爆点。
- 多人物复杂调度。
- 需要稳定交代信息的段落。

如果使用一镜到底，应优先写摄影机连续路径，而不是只列人物动作：

```text
一镜到底。摄影机从帐内右侧低位开始，先拍到门帘被急促掀开；士兵押着黑瘦少年从帐门逆光进入时，镜头向后退让，保持少年在画面中央；少年被推向帐中央时，摄影机贴着右侧木柱横移避开士兵身体；少年膝盖落地时，镜头降到低位，最后从少年肩后越肩看见帐中众人同时转头看向他。
```

## 12. 人物调度写法

必须写清：

- 谁在画面哪里。
- 从哪里进入。
- 往哪里走。
- 在哪里停。
- 看向哪里。
- 谁遮挡谁。
- 谁是主体。
- 谁只是边缘局部。
- 哪些人物不能抢主体。

人物移动必须写清完整目标，不能只写抽象空间名词。

弱写法：

```text
李破奴接过水壶，转身扑向病榻。
```

更稳写法：

```text
李破奴接过水壶，转身扑向病榻上的萧烈。
```

推荐结构：

```text
人物 + 动作 + 方向 / 路径 + 目标空间中的具体对象。
```

例如：

```text
士兵押着黑瘦少年从帐门右侧进入，把他推向帐中央的空地。
```

```text
苏瑾转头看向病榻上的萧烈，而不是看向帐门。
```

```text
李破奴接过水壶，转身扑向病榻上的萧烈。
```

## 13. 结束状态

每段提示词都必须写清最后停在哪里。

结束状态用于：

- 控制片段边界。
- 避免模型继续演下去。
- 方便下一段剪辑衔接。
- 防止动作过度生成。
- 稳定人物、道具和空间关系。

但结束状态不是精确调度指令。它的约束力弱于画面段落里的可见动作、人物位置和镜头路径。

如果结束状态只是在重复画面段落，或写成过度精确的抽象要求，模型可能不会严格遵循。

更稳的写法是把关键结束状态提前写进画面和人物调度：

```text
画面：李破奴从床侧踉跄前扑，双手撑到床沿，身体停在床前。
结束状态：李破奴停在床前，身体前倾看向床上的萧烈。
```

## 14. 声音提示的有效边界

声音字段只写当前片段中模型可以生成、同步或保留的声音。

默认禁止项保持精简。当前常规提示词只需要：

```text
禁止字幕，禁止 BGM。
```

除非具体项目已经反复出现水印、logo 或现代元素，否则不要机械堆叠大量禁止项。

声音字段对“语气”和“情绪”的精确控制力弱于台词本身、标点符号和表演动作。

弱约束写法：

```text
声音：李破奴说话发颤，声音压着激动。
```

更稳的写法：

```text
台词：李破奴颤声说：“王爷……王爷！您终于醒了！”
声音：室内安静，只保留李破奴的颤抖对白、急促呼吸和衣料摩擦声。
```

## 15. 台词标点控制语气

台词标点不是装饰。经过实测，标点符号对模型的语气、停顿和情绪引导能力很显著。

写台词时，应根据需要保留或调整标点，而不是只看文字内容。

| 符号 | 主要作用 | 适合语气 | 示例 |
| --- | --- | --- | --- |
| `，` | 短暂停顿 | 思考、犹豫、撒娇、克制 | `等一下，我想，先确认一件事。` |
| `。` | 正常收尾 | 平静、冷淡、无情绪 | `别碰我的东西，听懂了吗。` |
| `！` | 加强情绪 | 警告、兴奋、愤怒、强调 | `别碰我的东西，听懂了吗！` |
| `？` | 语尾上扬 | 疑问、试探、怀疑 | `你刚才去哪了？` |
| `？！` | 质问 + 情绪爆发 | 愤怒、震惊、不敢相信 | `你还敢说不是你？！` |
| `……` | 明显停顿 | 难过、犹豫、紧张、压抑 | `没关系……反正我也习惯了。` |
| `～` | 尾音拉长 | 撒娇、轻快、开心、温柔 | `太好了～我们终于成功了！` |
| `——` | 拉开语气 | 强调、转折、情绪断裂 | `我只是想知道——你到底有没有骗我。` |
| `“ ”` | 明确台词 | 让模型聚焦说话内容 | `她轻声说：“没事的，我在这里。”` |
| `【 】` | 强调核心台词 | 方便模型识别要配音的句子 | `【你终于……来了。】` |

例如：

```text
“王爷……王爷！您终于醒了！”
```

比：

```text
“王爷！王爷！您终于醒了！”
```

更容易引导出先停顿、压抑、再爆发的语气。

## 15.1 对白字数与镜头时长检查

有台词的镜头必须先参考 `09_SKILLS/i2v-prompt-workflow/references/dialogue-timing.md` 做时长预算。镜头秒数不是平均分配出来的，而是由动作、停顿、表情变化、台词字数、语气类型和听者反应共同决定。

基础公式：

```text
镜头时长 = 台词字数 / 语速系数 + 气口秒数 + 反应镜头秒数
```

输出到提示词中的时长只允许整数或 `.5`，按最接近的 `0.5 秒` 四舍五入。

常用语速：

| 台词类型 | 语速系数 |
| --- | --- |
| 爽点金句 | 2 字/秒 |
| 深情 / 告白 | 2.5 字/秒 |
| 冲突对峙 | 3 字/秒 |
| 日常对话 | 3.5 字/秒 |
| 苏瑾嘴炮连珠 | 4.5 字/秒 |
| 内心独白 / 画外音 | 4 字/秒 |

判断时还要扣除：

- 人物看向目标的时间。
- 道具动作时间。
- 微表情变化时间。
- 对方反应时间。
- 镜头进入和结束停点。

如果一个 3 秒镜头既要完成动作，又要两个人说完整对白，通常就是时长分配错误。

台词过长时，不要删减台词。应优先：

- 拆成两个或多个镜头，让后半句续接在下一镜头。
- 前半句拍说话人，后半句作为画外音叠到听者反应、道具特写或空镜。
- 如果整段超过 15 秒，拆成多个生成单位。

## 15.2 重要要求只写正向边界

`【重要要求】` 不是负面提示词收纳区。除默认的“禁止字幕，禁止 BGM”外，不要把后续剧情、平台常识或人类解释写成大量“不要生成什么”。

更稳的写法是把它改成正向生成边界：

- 当前片段的最后停点。
- 当前片段的主体优先级。
- 群演、群众、士兵或百官的视觉权重。
- 道具、人物、空间的最终位置。
- 下一生成单位的衔接方向。

弱写法：

```text
不要提前进入太和殿台阶，不要生成跪地求婚内容。
```

更稳写法：

```text
本片段结尾停在凤辇驶离旧宅院，苏瑾重新看向主街前方。百姓只作为两侧群体欢呼和声音背景，视觉焦点始终落在苏瑾与柳娘。
```

## 16. 标准输出结构

推荐结构：

```text
【全局设定】
画幅：
风格：
时代 / 场景：
禁止项：
声音原则：

【生成内容】
生成一段 X 秒视频，由 X 个镜头组成。

镜头1：X秒，景别，机位，运镜 / 摄影机路径。
镜头任务：
画面：
人物调度：
声音：
结束状态：
硬切结束。

镜头2：X秒，景别，机位，运镜 / 摄影机路径。
镜头任务：
画面：
人物调度：
声音：
结束状态：
片段结束。
```

Codex 输出标准提示词时，不写 `@Image`、`@Video`、`@Audio` 或人物资产绑定。参考层由用户粘贴提示词到 I2V 平台后手动补充。
