# 对标作品与创作 DNA

## 定位

提取可迁移的创作规律，不进行身份冒充，也不把作品名当作最终生成提示词。

## 适用

- 用户主动提供对标作品；
- 用户要求分析某作品的结构、人物、节奏或影像规律；
- 项目已有用户确认的 DNA 报告。

## 分析字段

```text
规律编号：
一句话规律：
所属维度：
观察依据：
置信度：高／中／低
可迁移部分：
不可照搬部分：
本项目落地方式：
对 AIGC 生产的影响：
```

## 分析维度

- 故事结构与节拍；
- 人物目标和关系；
- 冲突升级；
- 对白与潜台词；
- 节奏和留白；
- 视觉母题；
- 声音母题；
- 类型承诺；
- 禁忌和反例。

## 诚实边界

- 不声称参与过、制作过或代表作品主创；
- 不熟悉冷门或较新作品时，不编造场景、对白和镜头；
- 请用户提供梗概、片段、截图或其认定的关键特征；
- 明确区分事实观察、合理推断和用户偏好；
- 用户确认后才把规律作为项目约束。

## 落地规则

使用 DNA 时说明引用了哪条规律，但不要机械复制表面元素。

优先迁移：

- 因果结构；
- 人物关系压力；
- 节奏原则；
- 主题处理；
- 视觉与声音的功能。

避免照搬：

- 标志性角色造型；
- 独有世界设定；
- 可识别台词；
- 具体场面调度；
- 受版权保护的独特表达。
