### V01：项目状态包是否真的降低重复说明成本

**要验证的问题**

当一个短剧项目跨多个场景、多个角色、多个资产时，是否需要在最终 Skill 包中加入“项目状态包”作为核心工作物。

**变量**

- A：每次任务只读当前片段和现有规则。
- B：先建立轻量项目状态包，再生成分镜/I2V 提示词。

**建议测试场景**

使用已有第三集或第五集片段，尤其是人物状态、道具、场景连续性较多的片段。

**B 版最小状态包**

```text
项目：
当前集数/场次：
核心剧情目标：
当前生成范围：

角色状态：
- 角色名：位置 / 伤势 / 情绪 / 知道的信息 / 持有道具

场景状态：
- 场景名：时间 / 光源 / 破坏或污损 / 入口出口 / 空间方向

关键资产：
- 人物资产：
- 场景资产：
- 道具资产：

本场不可改：
本场可调整：
下游生成风险：
```

**观察指标**

- 是否减少你反复补充背景的次数。
- 是否减少人物状态、道具状态、空间方向的误写。
- 是否让 Codex 输出更稳定，还是只是增加表格负担。

**升级条件**

如果 B 明显减少返工，并且状态包不显得繁琐，则进入最终 Skill 包，作为“多场景/连续短剧项目”的启动步骤。

### V02：资产圣经是否比临时资产说明更稳

**要验证的问题**

是否要在最终 Skill 包里把“资产圣经”作为独立模块，而不是只在提示词里临时描述角色/场景/道具。

**变量**

- A：生成提示词时临时描述资产。
- B：先建立角色、场景、道具资产卡，再生成提示词。

**建议测试场景**

选择同一角色跨 2-3 个镜头出现的片段，最好包含人物、场景和关键道具。

**B 版最小资产卡**

```text

戏剧功能：

入口/出口：
主光方向：
环境动态：

PROP001 道具名
归属者：
形状/材料：
交互方式：
当前状态：
```

**观察指标**

- 人物是否更一致。
- 道具是否更少丢失或变形。
- 提示词是否变短、变清楚。
- 是否更容易手动绑定参考层。

**升级条件**

### V03：复杂镜头前做“参考素材角色表”是否减少冲突

**要验证的问题**

多参考图、首帧、角色图、场景图、道具图、音频参考混用时，是否必须先做参考素材角色表。

**变量**

- A：直接写提示词。
- B：先写参考素材角色表，再写提示词正文。

**B 版参考素材角色表**

```text
参考素材角色表
- 首帧：负责开场构图、人物位置、机位、光线和裁切。
- 角色图：只负责脸型、发型、服装、身份一致性，不负责构图。
- 场景图：只负责空间风格、固定地标、光影气质，不改变首帧机位。
- 道具图：只负责道具形状、材质和使用方式。
- 尾帧：只负责最终状态。
- 音频：只负责声音质感、台词节奏或环境音。

提示词正文不写平台资产绑定，由用户在平台中手动绑定。
```

**观察指标**

- 首帧构图是否更稳定。
- 角色图是否不再干扰场景构图。
- 场景图是否不再覆盖人物身份。
- 手动绑定时是否更清楚。

**升级条件**

如果 B 明显减少参考冲突，则进入最终 Skill 包，作为多参考任务前置步骤。

### V04：时间预算表是否能提前识别单条提示词过载

**要验证的问题**

4-15 秒片段里动作、对白、反应镜头过多时，时间预算表是否能提前发现“塞太多”的问题。

**变量**

- A：直接按剧情写 15 秒提示词。
- B：先做时间预算表，再决定是否拆分。

**B 版时间预算表**

```text
目标时长：
有效叙事时长：

| 时间片 | 秒数 | 动作/对白/反应 | 预算拍数 | 风险 |
|---|---:|---|---:|---|
| 1 | 0-3s |  |  |  |
| 2 | 3-7s |  |  |  |
| 3 | 7-11s |  |  |  |
| 4 | 11-15s |  |  |  |

结论：单条可承载 / 需要拆分
```

**观察指标**

- 是否减少动作缺失。
- 是否减少对白挤压。
- 是否更容易决定拆成几条生成。
- 是否比单纯“15 秒上限”更有判断力。

**升级条件**

如果 B 能稳定帮助拆分复杂片段，则进入最终 Skill 包，作为“复杂片段负载检查”。

### V06：连续性状态账本是否需要记录“知道/误解/伏笔”

**要验证的问题**

连续性是否不只包括外观和道具，还要包括人物知道的信息、仍然误解的信息、伏笔和倒计时。

**适用测试**

悬疑、反转、误会、细作、背叛、伏笔回收场景。

**最小记录**

```text
角色：
当前知道的信息：
当前误解的信息：
对其他人的信任状态：
已建立伏笔：
本场推进/回收伏笔：
```

**观察重点**

台词、表演和镜头是否更符合角色当下信息状态。

**要验证的问题**

中文对白进入 I2V 前，是否需要检查字数、语速、口型、画内/画外声音来源。

**最小检查**

```text
镜头秒数：
台词字数：

是否要求口型同步：
语速：慢 / 正常 / 快 / 过载

```

**观察重点**

- 口型是否更可用。

**观察重点**
