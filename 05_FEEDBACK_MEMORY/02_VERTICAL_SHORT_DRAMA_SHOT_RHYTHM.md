# Vertical Short Drama Shot Rhythm

来源：用户对第五集分镜头提示词的反馈。

## 观察到的问题

第五集分镜提示词结构完整，但在 9:16 竖屏画幅下，景别、机位和运镜过于保守。

大量镜头使用：

- 中景 / 中近景
- 平视
- 固定
- 固定微推
- 轻微跟拍

这种写法会让竖屏短剧变成连续站桩对白，削弱奇迹苏醒、众人震惊、跪谢、身份反转和结尾钩子的戏剧冲击。

## 可能原因

写提示词时过度追求“每个镜头结构完整”，但没有按短剧节奏重新分配镜头功能。

第五集的剧情节点本身有很多可视化爆点：

- 萧烈睁眼。
- 李破奴扑到床前。
- 众人不可置信。
- 水壶递出。
- 李破奴单膝跪谢。
- 众将齐跪。
- 老军医服软。
- 士兵押入黑瘦少年。
- “细作”二字落下。

这些节点不应全部用平视中景承接。

## 有效修正

- 情绪爆点使用单人近景、特写、低机位、快切。
- 群体震惊使用反应镜头组，每个人出现时间相同。
- 关键物件使用动作特写，例如钢刀落地、水壶递出、膝盖落地、手扶起人。
- 长对白拆成单人近景或画外音，不必让说话者每次都出现在画面中。
- 画外音可用于怒斥、打断和压迫感，画面可以继续跟随主角动作。
- 结尾钩子要集中到新的视觉主体，不要只用中景交代信息。

## 示例方向

```text
【5秒】【单人近景微侧快切】老军医、李校尉、普通士兵依次出现，每个人出现时间相同，表情不可置信，呆愣愣地看向镜头外萧烈。

【3秒】【慢动作特写】李校尉手中的钢刀“哐当”掉在地上。

【3秒】【近景侧面，单人镜头】李校尉惊喜若狂，大喊：“王爷！王爷活了！”

【3秒】【近景单人镜头】老军医画外音怒斥，人物不出现在镜头当中。画面继续拍勤天在萧烈左手旁边擦拭萧烈胸口。
```

## 适用范围

- 9:16 竖屏短剧。
- 强情绪反应镜头。
- 人物单人长对白拆分。
- 室内帐篷、军营、病榻等空间较小但人物关系密集的场景。

## 不适用范围

- 需要稳定展示空间关系的建立镜头。
- 需要长时间观察复杂动作路径的镜头。
- 用户明确要求克制、纪实、低剪辑感的片段。
