# AIGC 剧本诊断框架

## 先建立事实

在判断前列出：

- 作品形态与目标时长；
- 主角和外在目标；
- 主要阻力；
- 高潮选择；
- 已锁定内容；
- 当前版本；
- 本轮诊断范围。

## 编剧诊断

检查：

- 前提能否一句话说清；
- 主角是否主动制造关键转折；
- 失败代价是否具体；
- 场次是否通过“因此/但是”连接；
- 中段是否重复相同冲突；
- 高潮是否来自人物选择；
- 结局是否回答主题；
- 场景删除后是否影响剧情。

## 观众诊断

检查：

- 前 15% 是否出现类型承诺；
- 观众何时知道主角要什么；
- 信息是否通过行动而非说明书传递；
- 悬念和情绪是否有清晰对象；
- 世界观是否挤占人物行动；
- 结尾是否兑现开场承诺；
- 是否存在理解障碍而非有意留白。

## 制作诊断

检查：

- 核心角色数量；
- 新增场景和资产数量；
- 群演、复杂表演、特效和声音需求；
- 高成本设计是否有剧情价值；
- 原创宇宙是否只是已知 IP 换名；
- 对标元素是否越过致敬边界；
- 内容尺度与平台是否冲突。

## AIGC 生产诊断

检查：

- 相似角色是否易混淆；
- 多角色同框与遮挡；
- 精细手部和道具传递；
- 连续打斗与高速运动；
- 空间出入口和移动方向；
- 口型、长对白和多人抢话；
- 伤势、湿润、污损和服装状态；
- 动物、异形、镜面、液体和破坏；
- 文字界面和小物细节；
- 高风险因素是否在同一场叠加。

## 根因合并

多个表面问题可能来自同一根因。例如：

```text
开场解释多
角色不主动
冲突启动晚
```

可能共同指向“故事发动机进入太晚”。问题单应合并根因，避免重复。

## 修改目标而非代写

诊断给出：

- 要保留的功能；
- 要解决的问题；
- 可选择的策略；
- 每种策略的损失。

不直接写完整替代场景。
