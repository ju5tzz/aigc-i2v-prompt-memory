# Polish Screenplay Dialogue

## 定位与职责边界（Boundary）

全量扫描结构已锁定剧本中的对白，只修改有明确证据的问题句子。

负责：

- 建立角色语言指纹；
- 诊断角色辨识度、潜台词、冲突、类型语感、信息效率、节奏和记忆点；
- 检查口型、发音、对白长度和声音来源；
- 提供原台词、改写、理由和连锁影响；
- 更新正式剧本的台词层、语言指纹和版本记录。

不负责：

- 改变剧情结构、场次结果、主题、结局或人物弧光；
- 新写整场戏；
- 解决上游世界观和人物设定冲突；
- 最终配音或视频模型提示词。

结构问题交给 `diagnose-aigc-screenplay`；用户采纳结构修改后由 `draft-aigc-screenplay` 执行。

## 共享项目状态包（Shared Project State）

优先读取：

- 人物与关系圣经；
- 正式剧本最新版；
- 已锁定结构状态；
- 已采纳修改清单；
- 连续性账本；
- 诊断问题单。

本 Skill 可更新：

- 正式剧本中的对白；
- 台词语言指纹；
- 台词修改执行状态；
- 版本变更记录。

不得直接更新故事核心、分场表、人物弧光和连续性事实。台词改变剧情信息时提交变更请求。

## 阶段门禁（Gate / Structure Lock）

全面精修必须满足：

- 剧本结构：已锁定；
- 人物设定：已锁定；
- 正式剧本存在。

结构未锁定时，只允许：

- 建立临时语言指纹；
- 诊断指定关键场；
- 标记明显解释性对白；
- 不进行全剧逐句改写。

## 九维扫描

完整规则读取 `references/dialogue-framework.md`。

### 1. 角色辨识度

遮住角色名，是否能判断谁在说话。

### 2. 潜台词

字面内容是否与真实意图存在可理解的层次。

### 3. 冲突推进

台词后是否改变信息、立场、关系、情绪或行动。

### 4. 类型语感

词汇、称谓和节奏是否符合年代、世界观和类型。

### 5. 信息效率

是否向彼此解释双方都知道的设定；能否用动作替代。

### 6. 节奏与音乐性

句长、停顿、打断、重复和演员呼吸是否自然。

### 7. 记忆点

关键位置是否有属于角色而非通用文案的可记忆表达。

### 8. 口型与发音可执行性（Lip Sync）

检查拗口连续音节、难同步专有名词、情绪与嘴部动作冲突。

### 9. 单生成片段对白长度

重要句子能否在一个合理片段内完整说完；是否因过长导致表演和口型压力。

## 全量扫描、选择性修改（Selective Changes）

每句对白都扫描，但只修改：

- 命中明确问题；
- 修改收益大于角色与节奏损失；
- 不改变剧情事实；
- 能解释为什么改。

禁止为了体现工作量而改动原本有效的台词。

## 输出契约

每条修改必须包含：

```text
场次与角色：
原台词：
问题维度：
改写建议：
为什么这样改：
是否改变剧情信息：
需要同步的前后对白：
口型与时长影响：
```

理由必须具体对应诊断维度，不使用“更自然”“更有感觉”等空泛表述。

## 角色语言指纹

使用 `assets/voice-print-template.txt` 建立：

- 词汇范围和禁用表达；
- 句长偏好；
- 句式、停顿与打断；
- 直接表达和回避方式；
- 权力变化时的语言变化；
- 专有名词和口型风险；
- 角色弧光前后的语言变化。

语言指纹不是靠重复口头禅。角色辨识应主要来自思维方式、策略和句法。

## 工作流程

1. 校验结构锁定状态；
2. 盘点发言角色和关键场次；
3. 建立语言指纹；
4. 全量扫描九维；
5. 合并重复病因；
6. 优先修改影响角色、冲突和信息的台词；
7. 再处理节奏、口型和记忆点；
8. 检查改写是否改变剧情事实；
9. 更新剧本和变更记录；
10. 交回 `develop-aigc-screenplay` 做最终连续性与生产复检。

## 结构问题处理

若一句台词之所以糟糕，是因为场景目标、人物动机或剧情信息本身不成立：

- 不用漂亮台词掩盖结构问题；
- 保留原台词或只做最低限度清理；
- 创建结构变更请求；
- 路由至 `diagnose-aigc-screenplay`。

## AIGC 对白处理

- 关键对白尽量不跨片段；
- 画外音、背影和遮挡可以降低口型压力，但不能滥用来逃避表演；
- 多人抢话、高速动作中长对白和持续情绪大幅变化属于高风险；
- 声音来源必须明确：画内、画外、通讯、广播、录音或内心旁白；
- 改写后保留角色信息和场景冲突。

## 输出

使用：

- `assets/voice-print-template.txt`
- `assets/dialogue-change-list-template.txt`

输出：

- 语言指纹；
- 主要病因；
- 选择性修改清单；
- 未修改但扫描通过的关键台词；
- 结构变更请求；
- 台词锁定建议。

## 常见错误

- 每句都改，导致原有好台词被磨平；
- 满篇金句，所有角色像同一个文案；
- 用潜台词名义让观众完全听不懂；
- 为口型方便牺牲关键信息；
- 结构未锁定就做全剧精修；
- 台词改写改变了人物决定却不回退结构。
