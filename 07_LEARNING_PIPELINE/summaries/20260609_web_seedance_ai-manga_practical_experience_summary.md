# Web Research Summary - Seedance 2.0 / AI漫剧 / 提示词 / 运镜 / 故事板

- 日期：2026-06-09
- 来源类型：Web search，包含社区帖、B站/抖音页面抓取、知乎测评、AI漫剧工具页、提示词教程站
- 当前用途：外部经验归纳
- 当前状态：待验证

## 搜索目标

搜索创作者在 Seedance 2.0、AI漫剧、提示词、运镜、镜头、故事板方面的实战经验，判断是否有可迁移到当前 I2V 短剧工作流的信息。

## 有效来源类型

### 1. 社区实战帖

Reddit 上多条 Seedance 2.0 创作者帖子反复提到：

- 不要使用一整段 blob prompt。
- 改用结构化 shot list。
- 每个镜头单独写 camera angle / lens / movement / action / SFX layers。
- 6-8 个镜头在一个 prompt 中还能保持，超过约 10 个镜头连续性开始变差。
- 明确 lens，如 24mm / 35mm / 50mm，可以减少模型默认成平庸中景。
- SFX 层即使不生成声音，也会帮助视觉节奏。
- 多段 15 秒序列比一次生成 30 秒更稳。

### 2. 中文短视频平台教程页

抖音抓取页中出现较完整的 Seedance 2.0 文生图 / 文生视频提示词公式：

```text
主体 + 动作 + 场景 + 光影 + 镜头语言 + 风格 + 画质 + 约束
```

其中强调：

- Seedance 2.0 对动作描述敏感。
- 不要只写“走路”“跳舞”，要写连续、自然、慢动作细节。
- 运镜应直接写出：缓慢推镜、平稳横移、轻微环绕、稳定跟拍等。
- 多镜头 / 分镜可按时间和镜头顺序描述，但不要过于碎片化。

### 3. 知乎测评与案例

知乎测评中有几类值得注意的信息：

- 有创作者用 4 个镜头提示词 + 同一段剧情描述，再用剪映拼接，短时间完成动漫短剧片段。
- 多模态参考能力可以同时承接角色图、视频节奏、音乐节拍。
- 视频参考生成中，Seedance 2.0 对运镜复刻较强，但可能出现无关人物或镜头衔接生硬。
- 参考图中包含真人或 AI 模特人脸时，可能触发平台限制。

### 4. AI漫剧工具页

海豹分镜等 AI漫剧工具页反映出当前 AI漫剧工作流正在趋向：

```text
小说 → 剧本 → 分镜 → 统筹 → Seedance / 即梦提示词
```

其中比较有价值的是：

- 分镜 Prompt 被视为 AI漫剧命门。
- 光影、镜头、台词、衔接逻辑要独立标注。
- 角色库和场景库用于跨集一致。
- 分镜锁定后生成制作统筹表，提前检查角色、场景、道具和接戏风险。

### 5. 运镜提示词教程站

多个教程站反复出现同一类结论：

- AI 视频运镜的本质是用文字模拟摄影镜头语言。
- 基础运镜包括推、拉、摇、移、环绕、跟随。
- 提示词需要同时包含主体、动作、场景、镜头语言、光影、氛围。
- 只写画面元素，不写镜头行为，会导致画面平、像静态图。

## 可迁移信息

1. 当前仓库已有“提示词是给模型执行”和“竖屏短剧镜头不能保守”的规则，外部搜索强烈支持这一方向。
2. Shot list 结构值得进一步验证，尤其是每个镜头写：景别 / 机位 / 镜头运动 / 动作 / 声音层。
3. Lens 信息是否适合中文 I2V 提示词需要验证。它可能提升镜头倾向，也可能变成无效专业词。
4. SFX 层作为视觉节奏提示很值得验证，即使最终不生成声音。
5. 多镜头数量要控制。外部经验认为 6-8 镜头仍可保持，超过 10 个镜头容易断裂；但当前仓库的 15 秒片段通常 3-5 镜头，更保守，需要对照测试。
6. AI漫剧应建立制作统筹意识：角色、场景、道具、镜头状态、接戏风险需要在分镜阶段就检查。

## 低可信或需谨慎内容

- 很多 Seedance 提示词网站是 SEO 模板站，可能混有营销文案。
- “一句话生成电影”类说法不适合直接采纳。
- 一些教程强调 `@` 资产绑定，但在当前工作流里，Codex 只写提示词层，参考层由用户手动补充。
- 部分“自运镜 / 自分镜”说法容易让提示词变懒；对当前高可控短剧工作流，应继续明确写镜头任务。
