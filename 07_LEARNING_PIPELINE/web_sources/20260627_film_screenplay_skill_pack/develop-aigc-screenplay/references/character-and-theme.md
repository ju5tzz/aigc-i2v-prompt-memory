# 人物、关系与主题

## 人物戏剧身份

每个核心人物定义：

```text
角色 ID：
戏剧功能：
公开目标：
真实欲望：
内在需求：
旧伤：
错误信念：
惯用策略：
道德底线：
压力破口：
秘密：
矛盾特质：
失败代价：
不可逆选择：
人物弧光：
```

避免只写“善良、坚强、外冷内热”。每个特征都要能在压力下通过行动证明。

## 人物生成身份

```text
年龄与体型：
身体轮廓：
脸部识别锚点：
发型：
服装轮廓：
主色与辅助色：
标志性道具：
动作习惯：
表情习惯：
说话方式：
声音特征：
禁止漂移项：
```

角色区分优先级：

1. 身体与服装轮廓；
2. 颜色系统；
3. 发型与脸部锚点；
4. 姿态和运动方式；
5. 道具与声音。

不要让多个核心角色在年龄、发型、服装色彩和体型上同时高度相似。

## 状态编号

角色初始状态为 `CHR001-S0`，每次影响后续镜头的变化递增：

```text
CHR001-S0：整洁，无伤，持有外套。
CHR001-S1：右袖破损，额头血迹，仍持有外套。
CHR001-S2：全身湿透，失去外套，左手受伤。
```

新状态必须说明相对上一状态发生了什么。

## 关系发动机

重要关系不要只写亲属或职业。定义：

```text
表面关系：
双方各自想从对方得到什么：
权力不对称：
未说出口的债务或秘密：
关系中的惯用模式：
什么事件会打破模式：
关系最终发生什么不可逆变化：
```

## 主题设计

主题优先写成可争论的问题：

```text
主题问题：
主角最初的答案：
对手的答案：
重要配角的答案：
高潮迫使主角如何选择：
结局通过什么结果给出回答：
```

例：

```text
主题问题：爱一个人，是保护他不受伤，还是允许他承担选择的后果？
```

主题由人物行动和结果证明，不靠角色在结尾总结中心思想。

## 对白与潜台词

- 角色说的话不必等于真正想要的；
- 每段对白都应服务于目标、试探、隐瞒、施压、交换或关系变化；
- 不同人物使用不同句长、词汇、回避方式和停顿；
- 能用动作完成的信息，不重复用台词解释；
- 长对白若造成口型压力，可调整为画外、背影、环境动作或拆成自然回合，但不得破坏戏剧节奏。
