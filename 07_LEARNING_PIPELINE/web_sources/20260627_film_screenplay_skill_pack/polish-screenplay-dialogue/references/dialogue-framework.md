# 九维台词诊断框架

## 1. 角色辨识度

检查：

- 专属词汇与禁用表达；
- 句长和句式；
- 权力关系中的说话策略；
- 教育、职业、年代和世界观痕迹；
- 角色弧光前后的变化。

角色辨识度主要来自思维和策略，不靠机械口头禅。

## 2. 潜台词

检查字面意图、真实意图和观众可解码程度。潜台词不是故意说得含糊。

## 3. 冲突推进

每个有效回合至少改变：

- 信息；
- 立场；
- 关系；
- 情绪温度；
- 下一步行动。

连续多个回合没有变化时，删除、合并或改变策略。

## 4. 类型语感

检查年代、称谓、技术词、宗教词、阶层和类型节奏。原创世界观应建立自己的语汇，不照搬已知 IP 的标志性表达。

## 5. 信息效率

检查：

- 双方都知道的信息灌输；
- 自报家门；
- 用对白解释已被画面证明的内容；
- 一句是否同时承担性格、冲突和信息；
- 是否可由动作替代。

## 6. 节奏与音乐性

检查：

- 长短句交错；
- 停顿是否有表演目的；
- 打断和重复是否改变权力；
- 一口气能否说完；
- 情绪高点是否被冗词削弱。

## 7. 记忆点

只在关键位置寻找：

- 角色独有的反讽；
- 主题的行动化表达；
- 前后呼应；
- 简洁而有语境的句子。

脱离角色也成立的广告文案不一定是好台词。

## 8. 口型与发音

检查：

- 连续拗口音节；
- 专有名词密度；
- 快速动作中的长句；
- 哭喊、喘息、受伤状态与发音能力；
- 角色嘴部被遮挡时是否仍要求精确可见口型。

## 9. 片段长度

估算一句或一个完整回合能否在预期生成片段中自然完成。

优先保留完整句意。需要拆分时，在自然反应、动作或对方打断处拆，不把一个语义单位硬切两半。

## 修改优先级

1. 角色和剧情信息错误；
2. 冲突不推进；
3. 解释性灌输；
4. 角色声音混同；
5. 口型与长度不可执行；
6. 节奏；
7. 记忆点。

## 结构警报

出现以下情况，停止用台词修补：

- 人物没有明确目标；
- 场景没有冲突；
- 角色必须说出不可能知道的信息；
- 台词需要改变场次结果才能成立；
- 所有表达问题都来自前置剧情缺失。

创建结构变更请求，交回诊断。
