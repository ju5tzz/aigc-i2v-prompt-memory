# Continuity Ledger

## 长线状态总览

| 集数 | 连续性状态 | 提示词写作注意 |
| --- | --- | --- |
| 1-4 | 苏瑾作为假皇后入宫，萧珩识破她不是传统皇后，楚恒仍在幕后操盘。 | 重点是契约、误闯、试探和谈判，不要提前写成真爱。 |
| 5-6 | 苏瑾确认有孕，萧珩强制留宫，苏瑾把“留宫”转成商业开价。 | 重点是爬墙出逃、有孕暴露、龙椅前砍价。 |
| 7-12 | 沈妙音、冯德海开始动手，苏瑾用查账和话术反击。 | 宫斗不写成传统哭诉，要写成证据、账目、漏洞拆解。 |
| 13-18 | 北狄和亲危机、外交博弈、民间舆论战。 | 女主高光是语言、情报和策略书；男主开始暗中护她。 |
| 19-24 | 孕期脆弱、临产、生下萧团子，一家三口开始形成。 | 甜虐并行：萧珩笨拙照顾，团子只认母亲。 |
| 25-32 | 宫禁收紧，苏瑾搭建内务府底层情报网，小杏从内应变忠仆。 | 重点是信息断流后的自救和假情报反杀。 |
| 33-42 | 身份证据、伪造信件、朝堂护后、先皇后画像带来的身份阴影。 | 苏瑾开始从“替身”转向不可替代，萧珩保护动作增多。 |
| 43-48 | 苏蔓替身登场，楚恒废后压力升级，刺客夜袭凤仪宫。 | 苏蔓是镜像威胁；刺杀段要保留苏瑾抱团子躲暗室的恐惧。 |
| 49-56 | 离间计、萧珩求她别走、祭天逼宫、楚恒伏法。 | 情感明确化与权谋高潮同线推进，不要把两者割裂。 |
| 57-63 | 叛乱余波，楚恒以真实身份做最后杀手锏，萧珩公开承认苏瑾。 | 这是“假皇后变真皇后”的核心正名段。 |
| 64-68 | 北境战事，萧珩出征，苏瑾监国理政，凯旋团圆。 | 分离戏要保留铜钱/信件/军需账册等情感与能力道具。 |
| 69-74 | 真正大婚，萧珩归还金子并以天下为聘，帝后共治制度化。 | 那袋金子是交易变聘礼的情感闭环。 |
| 75-80 | 旧怨结清、惠民商署改革、团子长大、盛世尾声。 | 收束不只是甜宠，要体现市井商业逻辑改变大齐。 |

## 关键道具连续性

- 契约 / 金子：前期是苏瑾被雇佣的报酬，后期成为萧珩重新求婚的聘礼。
- 账本 / 算盘 / 策略书：苏瑾商业能力的可视化道具。
- 团子：从皇嗣危机道具变成家庭情感锚点，再变成商业天赋继承者。
- 先皇后画像 / 苏蔓：苏瑾替身身份危机的视觉锚点。
- 铜钱 / 信件：出征前后的情感连接道具。

## 情感阶段

- 1-6：互相试探，利益捆绑。
- 7-18：萧珩开始被苏瑾能力吸引，但嘴硬。
- 19-24：照顾孕期和育儿让家庭感出现。
- 25-42：双方逐渐互信，萧珩多次暗中保护。
- 43-56：外部危机迫使情感摊牌。
- 57-74：萧珩公开选择苏瑾，把她从假皇后变成唯一皇后。
- 75-80：情感、家庭和国家改革收束。
