## 一句话结论

这条视频对仓库有明确价值，核心不在于直接照搬它的 `@1/@2` 或 UE5/LibTV 格式，而在于确认并补强一条可进入最终 Skill 的规则：表情提示词应把抽象情绪拆成可见的脸部部位变化，并根据镜头景别、动作台词、人物主次和剧情触发点决定写多细。

## 视频核心观点

1. 不要只写“生气、开心、害怕、嘲讽”等抽象情绪词，要拆成眉毛、眼睛、嘴巴、面部肌肉四个可见层面。
2. 表情必须和动作、台词绑定。放狠话可以配合咬牙切齿，嘲讽可以配合嘴角斜挑，正常说话可以配合嘴巴微张。
3. 不同景别的表情幅度不同。远景、全景需要更大的可见动作；近景、特写才适合写细腻表情、皮肤纹理、面部肌肉变化。
4. 微表情的重点不是夸张，而是“细微、短暂、不易察觉”：从初始表情开始，被事件触发，出现一瞬间的眼神、眉毛或嘴角变化，然后立刻恢复。
5. 多人场景不能只让说话者有表情。主角表情要精细突出，对手表情要形成反差，配角也要符合人设，但应简化、虚化、不抢主体。
6. 批量生产分镜时，可以先用大模型生成常规表情提示词，再对高光镜头、微表情渐变、打斗对峙镜头做二次精修。

## 关键画面证据

### 单人物表情模板

关键帧：`frames/selected/t046_frame_0024.jpg`

视频给出的单人物模板包含：

- 场景参考
- 人物名称、位置、朝向、动作
- 表情细节：眉毛、眼睛、嘴巴、面部肌肉
- 整体情绪
- 人物外观一致性与光影皮肤约束

可迁移部分是“表情拆解维度”。不建议迁移 `@1/@2` 这类平台绑定写法，也不建议默认堆叠“虚幻引擎 UE5、电影质感、光影写实”等风格词，因为仓库最终模板已经有自己的格式边界。

### 示例表情拆解

关键帧：`frames/selected/t080_frame_0041.jpg`

画面演示了三类人物表情：

- 孙悟空愤怒：眉毛紧皱下压、眉心形成川字纹、瞳孔收缩、眼神凶狠凌厉、嘴巴紧抿、牙关紧咬、面部肌肉紧绷、太阳穴青筋微凸。
- 高翠兰冷峻嘲讽：眉毛平稳下压、眼神冰冷不屑、眼尾微微上挑、嘴角向一侧斜挑、面部肌肉放松、神态从容笃定。
- 猪八戒心虚观望：眉毛高挑、眼睛瞪圆、眼神慌乱心虚、嘴巴微微张开、耳朵后贴，呈现忌惮又好奇。

这一页对仓库最有价值的不是西游案例本身，而是“同一场对峙里，主角、对手、配角应有不同表情功能”。

### 微表情模板

关键帧：`frames/selected/t124_frame_0063.jpg`

视频给出的微表情结构是：

```text
人物原本保持初始表情状态。
听到/看到触发事件时，某个部位微微变化。
补充极短细节，例如瞳孔瞬间收缩、嘴角快速闪过一丝笑意。
随即立刻恢复原本表情状态，变化极快，不易察觉。
整体神态自然，符合人物人设，无夸张变形。
```

这与仓库近期测试中“前置信息能改善表演感情”的结论可以结合：微表情不应孤立写成脸部动作，而应写清当前片段里触发它的事件。

### 多人场景表情模板

关键帧：`frames/selected/t160_frame_0081.jpg`

视频给出的多人表情结构是：

- 主角1：详细拆解，突出细节，作为画面视觉焦点。
- 主角2：详细拆解，突出与主角的反差，情绪强度与主角匹配。
- 配角：符合人设，适当简化，适当虚化，不抢主体。
- 道具或额外人物：只写位置和状态。
- 所有人物比例、透视、场景融合、光影统一。

这一点很适合进入最终 Skill 的“多人镜头判断”，但要作为可选判断项使用，不应每个镜头都写满所有人的表情。

### 高精度微表情生成指令

关键帧：`frames/selected/t236_frame_0119.jpg`

视频建议对复杂镜头要求“情绪层次、肌肉动态、微表情变化、表情过渡的动态描述”。这对高光镜头有价值，但不能泛化成普通镜头的必填项，否则会造成提示词过密，削弱动作、构图和剧情重点。

## 对仓库的价值判断

### 可直接吸收的方向

- 把“表情”从单一情绪词升级为四部位拆解：眉毛、眼睛、嘴巴、面部肌肉。
- 把“微表情”写成动态过程：初始状态、触发事件、瞬间变化、恢复状态。
- 在近景、特写、反应镜头、情绪转折镜头中增加表情细节。
- 多人镜头要有主次：主角精细，对手反差，配角符合人设但不抢戏。
- 表情要和当前动作、台词、剧情触发点绑定。

### 不应直接吸收的部分

- 不照搬 `@1/@2/@3` 资产绑定格式。
- 不把“UE5建模风格、LibTV风格”等外部平台词写入仓库固定模板。
- 不把“每个镜头都拆眉眼口肌肉”变成硬规则。
- 不把豆包/DeepSeek批量生成流程变成 Codex 必选流程，除非用户后续明确希望加入外部模型协作。

## 与近期测试结论的关系

用户近期测试确认：连续性信息与环境参与都有价值，但不能滥用。该视频正好补上“表情层”的同类判断逻辑：

- 前置信息负责让模型理解角色为什么会出现这种表情。
- 环境参与负责在关键节点提升戏剧质感。
- 微表情负责让角色情绪有细腻过渡。
- 三者都应在关键镜头启用，而不是铺满所有镜头。

## 建议进入最终 Skill 的形式

最终 Skill 不应增加一个独立的大段“微表情模板”，而应在正式写提示词前加入一个判断：

```text
当前片段是否需要精细表情？
- 近景、特写、反应镜头、情绪转折、高光对峙：需要。
- 远景、群像调度、快速动作、普通过渡镜头：只写整体情绪或身体反应即可。
```

在需要时，镜头内增加：

```text
表情：眉毛...；眼神...；嘴部...；面部肌肉...；整体情绪...
```

微表情镜头增加：

```text
表情变化：人物原本保持...；听到/看到...时，眼神/眉毛/嘴角微微...；随即恢复...；变化极快，不易察觉。
```

多人镜头增加：

```text
表情主次：主角表情精细突出；对手表情形成反差；配角符合人设但简化处理，不抢主体。
```
