# AIGC 长片模式

## 原则

长片必须分阶段开发。不要在故事圣经、人物系统和序列表未锁定时一次生成完整初稿。

## 阶段

### 阶段 1：故事圣经

锁定：

- 故事前提；
- 类型承诺；
- 主题问题；
- 主角、对抗力量和人物弧光；
- 世界规则；
- 结局方向；
- 生产等级。

### 阶段 2：人物与资产圣经

建立主要人物生成身份、关键关系、核心场景、反复道具、声音母题和状态体系。

### 阶段 3：全片序列表

把全片拆成若干具有独立目标和转折的序列：

```text
序列 ID：
序列目标：
主导人物：
主要阻力：
关键转折：
进入状态：
结束状态：
主题推进：
新增资产：
生产风险：
```

### 阶段 4：分幕处理稿

先写每一幕的因果和情绪曲线，再展开场次。不得用大量“然后”连接事件。

### 阶段 5：逐序列正式剧本

每次只写一个可审查的序列。完成后立即更新连续性状态账本。

### 阶段 6：全片审查

检查：

- 人物目标与知识是否前后一致；
- 伏笔是否建立、推进和回收；
- 伤势、服装、道具和地点状态是否连续；
- 情绪是否无原因跳变；
- 资产是否无节制增加；
- 高风险场次是否集中到不可控程度；
- 主题是否在高潮前被过早说尽。

### 阶段 7：生产诊断与交接

按序列汇总高风险场次、关键资产、可复用场景和下游需要优先测试的内容。

## 序列状态快照

每完成一个序列记录：

```text
人物现在知道什么：
人物仍误解什么：
关系发生什么变化：
谁持有什么道具：
身体和服装状态：
场景与世界状态：
建立的伏笔：
回收的伏笔：
尚未兑现的承诺：
下一序列的必然推动力：
```

## 长片防漂移规则

- 新增人物前说明其不可替代功能；
- 新增场景前检查能否复用已有场景；
- 新增资产前检查是否影响后续连续性；
- 修改早期设定时列出受影响序列；
- 每次写作只使用已锁定版本的故事圣经；
- 未锁定内容必须标记为暂定或待确认。
