- URL：https://bytedance.larkoffice.com/wiki/Rx8pwmbXjirkvukCnCQcAtH1nSd
- 本地资料包：`07_LEARNING_PIPELINE/web_sources/20260628_lark_seedance_2_official_guide/`
- 状态：官方来源。若与仓库旧资料冲突，官方指南优先。

## 1. Seedance 2.0 必须按四模态系统理解

Seedance 2.0 支持图像、视频、音频、文本四种输入。后续工作流不应只按“图生视频 + 文本提示词”理解。

对仓库的影响：

- 在写提示词前先判断输入模式。
- 多模态任务必须先列参考对象职责。
- 视频和音频都可以是控制层，不只是辅助说明。

## 2. 官方输入限制应进入素材检查

官方限制：

- 图片：最多 9 张，小于 30 MB。
- 视频：最多 3 个，总时长 2-15 秒，小于 50 MB。
- 音频：最多 3 个，总时长不超过 15 秒，小于 15 MB。

对仓库的影响：

- 多参考方案设计前必须检查素材数量和时长。
- 超出限制时，先合并、裁切或拆任务，不要直接写无法执行的参考方案。

## 3. 写实真人脸素材上传限制是硬约束

官方说明当前不支持上传包含写实真人脸部的图片和视频素材。

对仓库的影响：

- 素材检查表必须增加“是否含写实真人脸”。
- 若用户提供写实真人脸素材，应提醒它可能无法上传或生成。
- 需要改用合规素材、非写实角色、已有平台允许的素材，或改写方案。

## 4. 入口选择成为正式工作流节点

官方区分首尾帧入口和全能参考入口。只上传首帧图 + prompt，可走首尾帧；组合图像、视频、音频、文本时，应走全能参考。

对仓库的影响：

```text
任务前判断：
- 纯文本生成
- 首帧 / 首尾帧
- 全能参考
- 视频延长
- 视频编辑
- 音频 / 音乐卡点
- 多视频融合
```

## 5. 参考对象职责表必须独立于提示词正文

官方示例使用 `@图1/@视频1/@音频1` 标注对象。仓库仍应保持 Codex 默认输出不直接写平台绑定，但必须新增独立的参考对象职责表。

推荐结构：

```text
参考对象职责表
- 图1：首帧 / 起点构图 / 主体位置
- 图2：场景参考 / 空间结构
- 视频1：动作节奏与运镜参考
- 音频1：节奏或音色参考

提示词正文
只写画面、动作、镜头、声音、结束状态。

平台绑定备注
用户进入即梦后，按职责表手动绑定素材。
```

## 6. 视频参考职责需要扩展

仓库旧定义偏窄：视频参考主要负责运镜、动作节奏、转场。

官方扩展后，视频参考可负责：

- 镜头语言。
- 复杂动作节奏。
- 创意特效。
- 模板形式。
- 转场方式。
- 被延长对象。
- 被编辑对象。
- 多视频融合中的前后素材。

规则：

- 每个视频参考只能在当前任务中承担清楚职责。
- 若它只负责运镜，不应让它改变角色和场景。
- 若它是编辑对象，应单独标明需要保留、替换、删除、增加的内容。

## 7. 音频参考是控制层

官方支持音频输入，并展示音色、声音真实度、音乐卡点。

仓库应区分：

- 声音字段：当前片段可生成的环境音、动作音、台词。
- 音频参考字段：上传音频负责台词节奏、口型、音色、环境声、动作声或音乐卡点。

模板中“禁止 BGM”应调整为：

```text
默认不额外生成字幕和无关 BGM。
如上传音频/音乐参考，必须明确它负责节奏、音色、口型、环境声或音乐卡点。
```

## 8. 视频延长、视频编辑、多视频融合必须成为独立任务类型

官方支持：

- 视频平滑延长。
- 按提示继续生成连续镜头。
- 对已有视频进行角色更替、删减、增加。
- 在多个视频之间加入新内容或做融合。

对仓库的影响：

- 普通 I2V 分镜模板不应直接套用视频编辑任务。
- 最终 Skill 包应增加专用结构：

```text
原视频内容：
需要保留：
需要替换 / 删除 / 增加：
参考素材职责：
编辑后的连续动作：
声音 / 音频参考：
结束状态：
```

## 9. 连续空间参考图规则需要分场景适用

仓库旧规则强调连续镜头参考图最好来自同一母场景。官方视频编辑和多视频融合能力说明：跨空间素材也可以成立，但前提是任务本来就是编辑、融合或转场。

修正规则：

- 连续空间生成：优先同一母场景。
- 视频编辑 / 融合 / 转场：允许跨空间素材，但必须标明过渡关系和素材职责。

## 10. 一镜到底与复杂运镜官方确认可用，但仍需服务故事

官方将“高难度/可控运镜”“镜头连贯性（一镜到底）更强”列为能力点。

对仓库的影响：

- 不要默认回避复杂运镜和一镜到底。
- 仍然必须写清起点、路径、动作节奏、空间变化、终点。
- 一镜到底不是默认格式，只有连续动作、空间穿行、压迫追逐、沉浸式调度时优先考虑。

## 11. 不吸收为规则的内容

- 不直接复制官方 Case 的具体 prompt 当通用模板。
- 不把所有任务强制变成全能参考。
- 不把 `@图1/@视频1` 直接写入 Codex 默认提示词正文。
- 不因为官方展示复杂能力，就把所有短剧镜头写成复杂运镜。

## 12. 最终 Skill 包建议新增模块

建议最终 Skill 包至少包含：

1. 输入模式判断。
2. 官方限制检查。
3. 参考对象职责表。
4. 纯提示词正文。
5. 平台绑定备注。
6. 视频延长专用结构。
7. 视频编辑专用结构。
8. 音频 / 音乐卡点专用结构。

优先级最高的是前四项：它们直接决定 Seedance 2.0 多模态任务是否能被正确组织。
