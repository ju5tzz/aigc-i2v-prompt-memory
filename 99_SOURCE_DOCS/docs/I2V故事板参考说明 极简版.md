I2V故事板参考说明｜极简版
一、故事板是什么

这里的故事板不是传统分镜图，也不是给人看的美术展示板，而是给 I2V 模型使用的 片段级视觉控制板。

它的作用是把一个视频片段中的关键信息压缩到一张图里，包括：

主体是什么
场景在哪里
镜头从哪里开始
镜头如何运动
画面如何从局部发展到整体
关键动作发生在哪个阶段
最终画面停在什么状态
需要什么声音氛围

故事板不是用来替代提示词，而是用来减少提示词无法准确表达的视觉歧义。

二、故事板的目的

故事板主要解决这几类问题：

1. 复杂镜头很难用文字说清

例如：

从机械局部拉远到完整阵地
炮弹跟随视角跨越战场
高空俯拍展示地形关系
多机位连续展示同一场景
从特写逐渐揭示大场面

这些内容只靠文字描述，模型容易理解成普通镜头。故事板可以提前规定画面层级和镜头路线。

2. 防止模型直接给出最终结果

有些镜头的重点不是“画面里有什么”，而是“它如何出现”。

例如回回炮登场：

错误理解：

一开始就展示一排回回炮。

正确设计：

木梁特写 → 单台回回炮显露 → 阵地全貌 → 主炮待发。

故事板的作用就是控制这种 信息揭示顺序。

3. 统一片段内部视觉逻辑

故事板可以把：

同一台主体
同一个场景
同一条机位运动路线
同一种光影氛围
同一个最终状态

放在同一张图里，避免多张参考图互相冲突。

三、什么时候需要故事板

适合使用故事板的情况：

镜头有明显的运动路线
画面需要从局部逐渐揭示整体
单张参考图很难表达完整镜头意图
场景空间关系复杂
需要展示战场、城池、水系、阵地等大空间
需要控制“起点—中段—终点”的连续关系
需要某种特定镜头感，而不是普通画面

不一定需要故事板的情况：

单人说话
简单对话正反打
普通走路、转头、坐下
文字提示已经能清楚表达的简单镜头
单一静态场景的小动作
四、故事板应该包含什么

一张适合 I2V 的故事板，建议包含以下模块。

1. 片段目标

说明这个片段要完成什么。

例如：

从回回炮机械局部开始，逐步揭示蒙古攻城阵地上一整排回回炮，最后停在主炮待发状态。

2. 主体设定

说明片段核心主体是什么。

例如：

主体是大型回回炮。重点是木质巨型框架、长杠杆臂、配重箱、粗绳、木轮、铁箍、榫卯结构。

3. 母场景

说明主体处在什么环境里。

例如：

樊城外蒙古攻城阵地，泥土地、木桩、辎重、黑红军旗、少量士兵，远处隐约是樊城方向。

4. 机位路线

这是故事板最重要的部分。

例如：

A点：木梁与绳索超近景
B点：后拉显露单台回回炮
C点：继续后拉并轻微升高，露出多台回回炮
D点：阵地大远景，主炮待发

5. 关键状态图

不要把每格都做成独立漂亮图，而是要表现同一个镜头的连续状态。

例如：

起点：机械局部
中段：单台主体显露
后段：阵地规模展开
终点：主炮待发
6. 声音设计

故事板也可以包含声音提示，尤其适合有环境声和机械声的镜头。

例如：

木梁咯吱声、绳索绷紧声、风声、旗帜声、远处低沉鼓点。严禁背景音乐。

五、故事板设计原则
1. 15秒是上限，不是目标

不要默认所有片段都做满 15 秒。

根据镜头任务判断时长：

5-8秒：单一揭示镜头、物体展示、简单动作
8-12秒：一个连续事件，有明显前后变化
12-15秒：多阶段长镜头，包含入场、对白、转场或空间揭示

例如：

回回炮从局部拉远到阵地全貌，7-9秒可能比15秒更合适。

2. 连续镜头必须保证同一空间

如果镜头是“从局部拉远到全貌”，起点、中段、终点必须像是同一台主体、同一片场景、同一个方向。

错误方式：

单台回回炮图 + 另一张阵地全景图 + 另一张待发图。

这样容易导致 I2V 在拉远过程中跳切式强行对齐。

正确方式：

同一台主炮、同一阵地、同一方向，做成连续三段状态图。

3. 故事板不是越复杂越好

故事板要解决镜头问题，不是做信息堆叠。

不要塞太多：

无关角色
无关道具
大量解释文字
太多互相矛盾的参考画面
多个不同空间的漂亮图

故事板的核心是：

让模型知道这个片段怎么发生。

4. 人物不是重点时，不要给清晰正脸

如果片段主角是机械、阵地、战场，不要让普通士兵抢主体。

士兵可以作为：

背影
侧背影
剪影
尺度参照
操作氛围

不要给正脸，否则容易让模型误判为角色戏，也容易带偏风格。

六、配套资产原则

故事板可以作为总控参考，但不一定单独完成所有工作。

常见搭配方式：

1. 故事板总图

负责：

镜头顺序
机位路线
节奏
关键状态
2. 主体设定图

负责：

主体造型
结构细节
材质特征

例如回回炮结构设定图。

3. 母场景图

负责：

场地
光影
空间关系
氛围
4. 终点关键帧

负责：

片段结束状态
下一个片段的衔接起点

但要注意：
如果是连续拉远镜头，终点关键帧最好和母场景属于同一空间体系，否则会产生跳切感。

八、一句话总结

故事板不是为了把提示词变复杂，而是为了把文字说不清的镜头逻辑变成可视化控制。

最适合故事板的，不是普通对话戏，而是：

复杂运镜、空间揭示、机械奇观、战场调度、从局部到整体的镜头。
