# 四 Skill 工作流路由

## 标准链路

```text
develop-aigc-screenplay
→ draft-aigc-screenplay
→ diagnose-aigc-screenplay
→ draft-aigc-screenplay（结构重写）
→ polish-screenplay-dialogue
→ develop-aigc-screenplay（最终生产复检）
→ 下游分镜
```

## 路由判断

### 只有创意或大纲不稳

留在 `develop-aigc-screenplay`。

### 故事、人物和分场已锁定

进入 `draft-aigc-screenplay`。

### 已有剧本，需要判断哪里有问题

进入 `diagnose-aigc-screenplay`。

### 用户已选择采纳诊断意见

进入 `draft-aigc-screenplay` 执行局部或结构重写。

### 结构已锁定，只需要对白质量

进入 `polish-screenplay-dialogue`。

### 台词完成，准备分镜

回到 `develop-aigc-screenplay` 做连续性与生产复检。

## 回退规则

- 修改主题、结局或人物弧光：退回故事开发；
- 修改关键节拍或场次因果：退回分场，结构和台词解锁；
- 台词修改改变剧情信息：退回结构重写；
- 连续性冲突无法局部修复：退回受影响的最早场次；
- 生产简化损害高潮：由用户决定保留攻克或退回重写。

## 版本约定

```text
v0.x 故事与分场开发
v1.0 正式初稿
v1.x 结构修改稿
v2.0 结构锁定稿
v2.x 台词精修稿
v3.0 生产复检通过稿
```

每次修改记录版本、范围、原因、受影响资产和状态。
