# Standard I2V Prompt Template

复制本模板时，应根据片段类型增删字段。不要为了完整而堆砌无用信息。

## 套用模板前的判断

正式写提示词前，先完成以下判断。判断结果不一定全部写进最终提示词；只有能服务当前片段生成效果的内容才进入正文。

1. **当前片段的核心事件是什么**  
   用一句话确认本段只生成哪一个连续事件，避免把前情、后续剧情和解释性信息塞进画面。

2. **是否需要当前片段前置信息**  
   如果角色的表演、台词语气、犹豫、爆发、隐忍、误解、心虚、诱导感，依赖一个画面外原因，就在提示词正文前加入极短前置信息。
   前置信息只解释当前片段的情绪和行为来源，不复述整段剧情。

   示例：

   ```text
   【当前片段前置信息】
   她今天刚因为替同事背锅被公司解雇，此刻不想让任何人看出自己崩溃。
   ```

3. **是否需要环境参与**  
   如果当前片段存在关键转折、重大决定、发现真相、情绪崩溃、身份反转，可以让环境在那个节点参与一次。
   环境参与应写进具体镜头的画面和声音里，绑定人物动作，不要全程铺气氛。

   示例：

   ```text
   她刚要擦掉眼泪时，公交车猛地刹停，窗外冷光扫过她的脸，她的手停在半空。
   ```

4. **镜头数量是否足够承载表演**  
   如果要表现微表情、心虚、察觉、蛊惑、压抑哭泣等表演差异，必须给近景或脸部特写。不要因为预设镜头数过少，导致测试或成片看不出差异。

5. **时长和动作是否匹配**  
   瞬间动作不要分配过长时长；复杂动作、情绪停顿、视线发现、台词反应才需要更长镜头。


## 使用提醒

- Codex 只输出提示词层，不写 `@Image`、`@Video`、`@Audio` 或人物资产绑定。
- 参考层由用户粘贴提示词到 I2V 平台后手动补充。
- 默认禁止项保持精简：禁止字幕，禁止 BGM。其他禁止项只在项目确实需要时添加。
- 输出前先做信息密度检查：主体、动作、场景、光影、镜头、风格、约束、结束状态是否足够明确。
- 15 秒四段切片可以作为常规骨架，但不是硬规则。片段时长和镜头数量由镜头任务决定。
- 历史题材必须写清年代、地域、服装、建筑、军装、道具和生活质感，不要只写“古代”“抗战时期”“宋代”等泛称。
- 当前片段前置信息不是全局剧情梗概，只在它能改善当前表演、语气、停顿和动作选择时使用。
- 环境参与不是氛围铺底，只在关键转折或情绪卡点使用，并写进具体镜头的画面 / 声音。
- 近景和特写可以写微表情；远景和动作镜头应改写成更大的身体动作。
- 一个镜头只选 2-4 个表情锚点，例如眼神、眉毛、嘴角、呼吸、低头或手部动作。
- 测试或生成微表情、心虚、察觉、蛊惑、压抑哭泣时，必须安排近景或脸部特写。
- 9:16 竖屏短剧不要连续使用中景、平视、固定镜头，应根据情绪卡点加入快切、特写、物件镜头、画外音和反应镜头。
- 快切镜头要控制主次，不要给普通士兵或群众过多单人特写。
- 普通对话可以删减复杂运镜。
- 复杂空间、战场、机械奇观必须写清起点、中段、终点。
- 有故事板时，提示词中的人物位置、机位方向、声音必须与故事板一致。
- 人物移动必须写清完整目标对象，例如“转身扑向病榻上的萧烈”，不要只写“转身扑向病榻”。
