# 资产圣经

## 建档标准

满足任一条件才独立建档：

- 重复出现；
- 影响角色识别；
- 影响剧情；
- 会发生状态变化；
- 影响连续性；
- 需要独立参考图或专项生成。

普通一次性背景物件不必建档。

## ID 规则

| 类型 | 前缀 | 示例 |
|---|---|---|
| 角色/生物 | `CHR` | `CHR001` |
| 场景环境 | `ENV` | `ENV001` |
| 固定陈设 | `SET` | `SET001` |
| 道具/武器 | `PROP` | `PROP001` |
| 服装装备 | `EQP` | `EQP001` |
| 车辆机械 | `VEH` | `VEH001` |
| 视效环境 | `VFX` | `VFX001` |
| 声音母题 | `SND` | `SND001` |

ID 一旦使用，不因改名或删除而重新分配给其他资产。

## 视效和声音

视效必须说明来源、影响范围、运动逻辑、与人物/环境的交互和消散方式。

声音必须说明来源、空间位置、是否反复出现、与剧情或角色的关联。

## 资产调用

每个场次只列实际可见或可听的资产。不要把整本资产圣经复制进每场戏。

```text
SC012 使用：
CHR001-S2
CHR003-S0
ENV002-E1
PROP004-P1
VFX003
SND002
```

状态后缀必须与连续性账本一致。
