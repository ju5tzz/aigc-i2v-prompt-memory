# Continuity State and Environment Participation

来源：2026-06-28 用户完成 V06 + V08 ABCD 实测反馈。

## 结论

当前片段前置信息和环境参与都有效，但都属于“提高关键片段理解和质感”的机制，不是每个镜头都要使用的固定模板。

## 当前片段前置信息

当前片段前置信息指在正式镜头提示词前，用极短信息说明角色为什么在这一刻产生某种表演、语气、停顿或动作选择。

它可以说明：

- 角色当前知道什么。
- 角色误以为什么。
- 角色正在隐藏什么。
- 角色想达成什么。
- 角色为什么崩溃、隐忍、犹豫、试探、心虚或爆发。
- 当前片段需要推进到哪里。

实测发现，加入这些信息后，不只画面表演会更贴合剧情关系，台词配音也可能更有情绪方向。例如反派诱导签字时，语气可能从普通平淡变成更低、更有蛊惑感。

### 使用方式

适合作为当前片段的前置解释，而不是完整剧情梗概。

例如：

```text
【当前片段前置信息】
她今天刚因为替同事背锅被公司解雇，此刻不想让任何人看出自己崩溃。
```

再写当前片段：

```text
她坐在公交车靠窗位置，低头忍着眼泪，肩膀轻轻发抖。
```

这类画面外原因不能被镜头直接拍到，但能帮助模型决定哭泣的方式、压抑程度、停顿和声音质感。

不要把上一集、完整剧本或与当前表演无关的背景全部重述。

### 适合使用

- 多角色互相隐瞒。
- 误会、试探、诱导、背叛、嫁祸。
- 角色表面动作和真实目标不一致。
- 同一集连续片段需要保持上一段信息。
- 台词语气需要带有潜台词。
- 单人情绪戏需要画面外原因支撑表演。

### 不适合使用

- 简单动作镜头。
- 单一情绪反应。
- 纯道具特写。
- 画面已经能清楚表达关系的小片段。
- 每个镜头都重复完整背景说明。
- 与当前片段表演无关的长前情。

## 环境参与

环境参与指让雨声、雷声、灯影、风、火光、门帘、阴影、物件轻微移动等环境因素，在关键节点推动情绪。

实测亮点：角色准备签字的一瞬间，突然响起雷声，外面的闪电一刹那照亮他的脸。这类细节能明显提升戏剧质感。

### 使用方式

环境参与应该绑定到具体戏剧节点，而不是平均铺满全片。

更稳的写法是：

```text
陆衡的手即将碰到毛笔时，帐外突然响起一声闷雷，闪电从帐缝掠过，一瞬间照亮他的半张脸，他的动作停住。
```

弱写法是：

```text
帐外下雨，灯光摇晃，气氛紧张。
```

### 适合使用

- 高潮前的停顿。
- 关键发现。
- 身份反转。
- 谎言被识破。
- 决定签字、拔刀、跪下、转身离开等动作卡点。
- 角色情绪从压抑转向爆发。

### 不适合使用

- 普通对白全程。
- 每个镜头都加入大量环境细节。
- 环境物件比人物动作更抢眼。
- 已经有强动作或强表演时继续堆叠雷声、闪电、火光等。

## 微表情测试注意

如果测试目标包含微表情、眼神、语气、停顿、心虚、察觉、蛊惑等表演差异，镜头设计必须给足脸部信息。

后续测试不应只用 3 个镜头完成全部关系、动作和转折。至少应包含：

- 一个建立关系的中景。
- 一个手部或道具特写。
- 一个脸部近景或特写。
- 一个对方反应镜头或收束镜头。

否则模型即使产生了表演差异，观众也很难从成片中判断 A/B/C/D 的区别。

## 后续写提示词的规则

1. 当前片段前置信息只写能影响本段表演、语气、停顿和动作选择的原因。
2. 环境参与只在关键戏剧节点使用，并绑定到人物动作或心理转折。
3. 不要把环境参与写成全程气氛铺底，否则会抢走人物表演。
4. 当要测试微表情机制时，必须主动设计脸部近景 / 特写。
5. 判断 V06 的效果时，除了看动作，也要看配音语气、停顿和情绪色彩。
