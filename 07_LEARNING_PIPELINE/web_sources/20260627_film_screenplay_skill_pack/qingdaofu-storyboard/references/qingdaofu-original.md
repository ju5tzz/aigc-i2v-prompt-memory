## 清道夫模版完整说明

清道夫模版是一种用于生成 Seedance 2.0 视频提示词的影视工业化写法。它不是简单的"分镜表"，而是将**资产设定、摄影参数、画面调度、人物表演、声音设计、时间预算、物理约束**统一写进一条可投喂提示词中。

核心目标：**让 AI 不只是知道画面里有什么，而是知道这场戏应该怎么拍、怎么演、怎么运动、怎么保持风格统一。**

### 一、基础设定怎么写

基础设定不是人物简介，而是**资产锁定**。要写清楚：
- 角色年龄、性别、身高、体型
- 五官、发型、肤色
- 服装款式、颜色、材质
- 配饰、鞋子
- 气质和表演逻辑
- 场景空间、时间、关键物件
- 声音规则
- 画幅比例

#### ✅ 好的写法
```
▸ 角色1：陈墨：20多岁男性，身高约180cm，身形清瘦挺拔，肩颈线条利落，面部轮廓干净冷峻，眉眼深，眼神压迫但情绪极度克制。穿现代都市极简黑色哑光棉质衬衫，领口微开，袖口自然挽起。愤怒时不咆哮，只通过停顿、眼神、手指收紧和呼吸变慢表现压迫感。
```

## 微表演词库

### 压迫/克制
- 眼神一点点沉下去
- 呼吸变慢
- 手指一点点收紧
- 指节发白
- 停顿，眼神
- 嘴角肌肉抽动
- 不咆哮，只通过停顿和眼神表现压迫感

### 悲伤/隐忍
- 眼眶迅速泛红
- 想开口又忍住
- 喉结滚动
- 眼睫轻垂
- 呼吸停半拍
- 嘴唇微微发抖
- 垂下眼，不说话

### 紧张/恐惧
- 脚步迟疑半秒
- 肩线微微起伏
- 瞳孔微缩
- 手不自觉地攥紧
- 身体微微后仰
- 吞咽动作
- 目光闪烁不定

### 愤怒/爆发前
- 嘴角肌肉抽了一下
- 握紧的拳头微微发抖
- 额角青筋跳了一下
- 咬紧后槽牙
- 呼吸从平稳变急促
- 眼神从回避到直视

### 震惊/意外
- 先僵住
- 动作停顿在半空
- 眼睛微微睁大
- 嘴唇张了张没说话
- 身体像被定住

### 疲惫/无力
- 肩膀慢慢塌下去
- 眼神渐渐失去焦点
- 手从紧握到松开
- 长出一口气
- 身体靠向墙/椅背
- 眼皮沉重地合了一下

### 决绝/转变
- 慢慢抬起头
- 眼神从涣散到聚焦
- 深吸一口气
- 松开攥紧的东西
- 转身，不再回头
- 步伐从犹豫变坚定
