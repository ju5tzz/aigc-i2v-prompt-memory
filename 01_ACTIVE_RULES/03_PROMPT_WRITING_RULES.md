# Prompt Writing Rules

## 1. 片段类型判断

写提示词前，先判断当前片段属于哪一类：

- 普通对话
- 单人动作
- 空间发现
- 复杂调度
- 机械奇观
- 战场 / 城池 / 阵地
- 角色表演
- 道具特写
- 转场 / 过渡
- 覆盖镜头素材

## 2. 什么时候升级到专业拍摄语言

适合升级：

- 空间关系复杂。
- 信息需要逐步揭示。
- 镜头有明确运动路线。
- 角色行动路径容易误判。
- 视线发现顺序很重要。
- 战场、城门、楼梯、走廊、二楼平台等空间复杂。

不需要升级：

- 单人固定机位说话。
- 简单正反打。
- 普通站立、坐下、转头。
- 单一道具动作。
- 普通口播。
- 无复杂空间关系的小动作。

## 3. 运镜写法

不要只写设备名词或笼统动作。

错误写法：

```text
使用摇臂镜头展现大场面。
```

正确写法：

```text
镜头从贴近回回炮木轮的低位开始，沿摇臂缓慢升高并后拉，先露出单台主炮，再露出同一方向排列的多台回回炮，最后停在阵地中远景。
```

## 4. 人物调度写法

必须写清：

- 谁在画面哪里。
- 从哪里进入。
- 往哪里走。
- 在哪里停。
- 看向哪里。
- 谁遮挡谁。
- 谁是主体。
- 谁只是边缘局部。
- 哪些人物不能抢主体。

## 5. 结束状态

每段提示词都必须写清最后停在哪里。

结束状态用于：

- 控制片段边界。
- 避免模型继续演下去。
- 方便下一段剪辑衔接。
- 防止动作过度生成。
- 稳定人物、道具和空间关系。

## 6. 标准输出结构

推荐结构：

```text
【全局设定】
画幅：
风格：
时代 / 场景：
禁止项：
声音原则：
参考资产职责：

【生成内容】
生成一段 X 秒视频，由 X 个镜头组成。

镜头1：X秒，景别，机位，运镜 / 摄影机路径。
镜头任务：
画面：
人物调度：
声音：
结束状态：
硬切结束。

镜头2：X秒，景别，机位，运镜 / 摄影机路径。
镜头任务：
画面：
人物调度：
声音：
结束状态：
片段结束。
```
