Seedance 2.0 全能参考（Omni-Reference）功能官方说明文档
一、功能概述
全能参考（Omni-Reference）是字节跳动 Seed 团队发布的 Seedance 2.0 核心旗舰功能，为多模态统一参考系统，支持文本、图片、视频、音频四种模态混合输入，打破单一模态限制，让创作者以 “导演级” 操控能力精准定义视频的主体、风格、动作、运镜与音效，实现从 “生成视频” 到 “导演视频” 的升级。与基础的 “首尾帧模式” 不同，全能参考模式面向专业创作场景，支持多素材协同驱动生成，核心解决主体一致性、画面可控性、音画同步三大痛点，适配广告、影视、游戏、口播等专业内容生产。


二、核心输入规格（官方上限）
（一）多模态输入配额（单次生成）
文本：自然语言提示词（必填，用于补充细节指令）。
图片：最多9 张，单张约≤30MB，支持角色、场景、风格、构图等参考。
视频：最多3 段，总时长 2–15 秒，单段约≤50MB，用于动作、运镜、转场、特效参考。
音频：最多3 段，总时长≤15 秒，单段约≤15MB（MP3），用于节奏、BGM、口播、环境音参考。
总参考文件数：单次最多12 个（图片 + 视频 + 音频），与文本协同生效。
（二）输入规范
图片：分辨率≥720P，清晰无模糊 / 逆光 / 水印，优先主体突出、背景简洁的素材。
视频：帧率≥24fps，画面稳定，无剧烈抖动，优先选取关键动作、运镜片段。
音频：采样率≥44.1kHz，无杂音，口播音频需人声清晰，BGM 需节奏明确。
真人素材限制：真人图像 / 视频不可直接作为主体参考，需经本人验证或授权，避免侵权。
三、核心能力与参考维度
（一）主体一致性参考（Identity）
功能：锁定角色 / 物体的核心特征（脸型、发型、穿搭、体型、五官、产品形态），确保多镜头、多片段中主体无漂移、无变形。
应用：角色短片、IP 形象复刻、产品展示（如服装换色、模特替换）。
示例：上传 2 张角色正面 / 侧面图，生成全程脸型、服装一致的连续动作视频。
（二）风格与构图参考（Style）
功能：复刻参考素材的色调、光影、质感、构图（景别、视角、留白）、艺术风格（写实 / 二次元 / 赛博朋克）。
应用：影视级画面复刻、品牌视觉统一、艺术风格迁移。
示例：上传 1 张油画风格图 + 1 张场景图，生成同色调、同构图的场景动画。
（三）动作与运镜参考（Motion）
功能：精准复制参考视频的动作细节（肢体动作、舞蹈、手势）、镜头语言（推 / 拉 / 摇 / 移 / 跟 / 俯）、运动节奏、转场特效。
应用：舞蹈复刻、武术动作、专业运镜（如电商视频的远景→中景→特写）、转场模板复用。
示例：上传 1 段运镜参考视频，生成完全一致的镜头运动视频。
（四）音频与节奏参考（Audio）
功能：音频驱动画面节奏，实现音画精准同步，包括 BGM 卡点、口播对口型、环境音匹配场景；支持立体声输出，生成带音效的完整视频（非后期配音）。
应用：MV、口播解说、音乐卡点短视频、沉浸式环境视频。
示例：上传 1 段口播音频 + 1 张人像图，生成口型完全匹配的说话视频。
（五）多镜头叙事与视频延长
功能：支持基于参考素材生成连续多镜头内容，可平滑延长视频时长（最长 15 秒），保持跨镜头主体、风格、场景一致性，适配剧情类短片创作。
四、核心操作规则（@标签引用系统）
（一）引用语法
通过 **@+ 素材类型 + 序号 ** 精准绑定参考素材与生成逻辑，格式如下：
@Image1：引用第 1 张图片（主体 / 风格 / 构图）。
@Video1：引用第 1 段视频（动作 / 运镜 / 转场）。
@Audio1：引用第 1 段音频（节奏 / 口型 / BGM）。
（二）提示词万能模板
plaintext
[主体描述] + [动作指令] + [场景/构图] + [运镜/风格] + [画质要求] + @引用标签
示例：
plaintext
穿白色长裙的女性，缓慢走进古典书房，背景木质书架，暖光柔和，推镜头，写实风格，4K高清 @Image1（角色） @Video1（运镜） @Audio1（BGM）
（三）素材优先级建议
角色 / 主体图片（最高优先级，确保一致性）。
运镜 / 动作视频（定义镜头与运动）。
风格 / 场景图片（统一视觉基调）。
音频（同步节奏与音效）。
五、典型应用场景与效果
（一）角色一致性短片
输入：2 张角色图 + 1 段运镜视频 + 文本指令。
效果：3–5 个连续镜头，角色脸型、服装、发型全程无变化，动作自然连贯。
（二）电商产品视频
输入：1 张产品图 + 1 段参考视频（远景→特写） + 文本指令。
效果：一键生成含全景、细节、上身效果的专业电商视频，支持换色、换模特、改背景。
（三）口播 / 解说视频
输入：1 张人像图 + 1 段口播音频 + 文本指令。
效果：口型与音频 100% 同步，表情自然，背景简洁，适配知识类、带货类视频。
（四）音乐卡点 MV
输入：1 张风格图 + 1 段 BGM 音频 + 文本指令。
效果：画面节奏与音乐鼓点精准匹配，转场自然，风格统一。
六、官方限制与注意事项
时长限制：单段生成视频最长 15 秒，可通过多段拼接延长（需保持风格一致）。
版权规范：禁止使用侵权图片 / 视频 / 音频；真人素材需授权，否则无法生成。
质量建议：参考素材质量直接决定生成效果，优先高清、清晰、无干扰的素材。
平台差异：豆包、即梦、火山方舟等平台的输入配额可能微调，以平台界面提示为准。
七、与首尾帧模式对比
表格
对比维度	全能参考模式（Omni-Reference）	首尾帧模式（First/Last Frame）
输入能力	文本 + 9 图 + 3 视频 + 3 音频，多模态混合	仅文本 + 1 张首 / 尾帧图片
可控性	精准控制主体、动作、运镜、音效	仅控制开头 / 结尾画面，中间随机生成
一致性	跨镜头主体、风格无漂移	易出现脸型、服装、场景变化
适用场景	专业创作、广告、影视、口播	新手试玩、简单动态图
操作难度	中等（需 @标签语法）	极低（一键上传）
