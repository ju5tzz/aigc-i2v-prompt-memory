# Seedance 2.0 清道夫分镜提示词技能

## 技能简介
基于「清道夫模版」生成 Seedance 2.0 影视工业化分镜提示词。不是简单描述画面，而是将资产设定、摄影参数、画面调度、人物表演、声音设计、时间预算、物理约束统一写入一条可投喂提示词中，让 AI 知道这场戏应该怎么拍、怎么演、怎么运动、怎么保持风格统一。

## 适用场景
- 用户需要为 Seedance 2.0 生成视频分镜提示词
- 用户提到"分镜""清道夫""提示词""Seedance提示词""视频提示词"
- 用户提供了剧本/场景描述，需要转化为可投喂的影视级提示词
- 用户要求按照清道夫模版写分镜

## 核心原则
1. **资产锁定而非人物简介**：角色设定必须写清年龄、性别、身高、体型、五官、发型、肤色、服装款式/颜色/材质、配饰、气质和表演逻辑
2. **摄影机级画质参数**：不能只写"电影感"，必须写成摄影级参数——机身、镜头型号/焦段、景深、动态模糊、调色方案、光源方向
3. **分镜是情绪发生的过程**：不只写景别/构图/运镜，必须写镜头情绪、人物微表演、环境参与
4. **微表演替代情绪标签**：不用"愤怒""害怕"，写成可视动作——眼睫轻垂、喉结滚动、指节发白、呼吸停半拍
5. **环境是情绪放大器**：环境不是背景板，要参与叙事
6. **时间预算必须写**：每条提示词明确目标时长、有效叙事时长、时间片预算表
7. **兜底约束防崩坏**：结尾必须写质量和物理连续性约束

## 输出格式
每条提示词严格遵循以下结构：

```
一、基础设定
【基础设定】
▸ 角色 / 主体
▸ 场景
▸ 道具
▸ 声音
▸ 画幅

二、氛围与画质
【氛围与画质】
▸ 风格核心
▸ 视觉基调
▸ 色彩与影调
▸ 光影与参考

三、时间预算校验
目标生成时长
有效叙事时长
时间片预算表

四、画面内容·场景版分镜
【画面内容-xxx版】
▸ 分镜一：00.00-00.03
  景别：
  镜头情绪：
  构图：
  运镜手法：
  人物表演：
  环境参与：
  画面内容：
  声音/台词：

五、画质、风格与约束
```

## 执行步骤
1. 读取用户的场景描述/剧本素材
2. 提取角色、场景、情绪核心、叙事目标
3. 按清道夫模版结构逐节生成提示词
4. 校验时间预算表（4-15秒范围内）
5. 添加兜底约束
6. 输出完整提示词

## 参考文档
- `references/清道夫模版完整说明.md`：模版完整规则与示例
- `references/微表演词库.md`：常用微表演动作词库
- `references/运镜情绪编码表.md`：运镜与情绪对应关系

## 注意事项
- 竖屏短剧（9:16）必须按竖屏构图规则：人物脸部/手机屏幕/牌匾文字保持中央安全区，多用纵深深构图，人物中下部，动作不出画
- Seedance 单条建议 4-15 秒
- 时间预算拍数规则：一个物理动作=1拍，一次主运镜=1拍，一次环境变化=1拍，8字内短对白=1拍，9-16字对白=2拍，超24字必须拆分
- 声音写现场同期声和情绪节奏，不要强制生成具体音乐

# 清道夫模版完整说明

## 一、基础设定

### 1.1 角色 / 主体
✅ 正确示例：
> 32岁男性，身高185cm，体型魁梧，国字脸，浓眉大眼，短发平头，小麦肤色，身穿黑色战术背心+深灰色作战裤，脚穿黑色军靴，左手臂有纹身，气质冷峻，眼神锐利，表演逻辑：从冷静观察到突然爆发

❌ 错误示例：
> 一个男人，很厉害的样子

### 1.2 场景
✅ 正确示例：
> 废弃工厂内部，钢筋混凝土结构，天花板高10米，有大型机械设备，地面有油污和积水，空气中弥漫着灰尘和铁锈味，空间感强，适合追逐和打斗

❌ 错误示例：
> 工厂里

### 1.3 道具
✅ 正确示例：
> 手枪（格洛克17，黑色，握把有磨损痕迹）、手电筒（强光，光束清晰）、对讲机（挂在胸前，天线竖起）

❌ 错误示例：
> 一些武器

### 1.4 声音
✅ 正确示例：
> 环境音：远处滴水声、金属碰撞的回声、脚步声的混响
> 动作音：手枪上膛的咔哒声、急促的呼吸声、衣服摩擦声

❌ 错误示例：
> 背景音乐：紧张的音乐

### 1.5 画幅
✅ 正确示例：
> 16:9 宽屏电影画幅，2.35:1 Cinemascope 宽屏

❌ 错误示例：
> 竖屏

## 二、氛围与画质

### 2.1 风格核心
✅ 正确示例：
> 3D国漫写实风格，《斗破苍穹》级别渲染，人物模型精细，材质质感真实，光影层次丰富

❌ 错误示例：
> 电影感

### 2.2 视觉基调
✅ 正确示例：
> 冷峻压抑，高对比度，暗部细节丰富，整体偏蓝绿调，营造紧张悬疑氛围

❌ 错误示例：
> 好看

### 2.3 色彩与影调
✅ 正确示例：
> 主色调：深蓝+灰黑+少量暖黄灯光点缀
> 影调：低调影像，大面积暗部，小面积高光对比强烈

❌ 错误示例：
> 颜色好看

### 2.4 光影与参考
✅ 正确示例：
> 主光源：侧逆光，从左侧窗户射入，形成明显光束，勾勒人物轮廓
> 辅助光：环境漫反射，暗部有细节但不抢戏
> 参考：《银翼杀手2049》的光影质感

❌ 错误示例：
> 有光

## 三、时间预算校验

### 3.1 目标生成时长
> 8秒

### 3.2 有效叙事时长
> 7秒（扣除开头结尾各0.5秒）

| 拍4 | 快速环顾四周 | 1秒 |
| 拍5 | 脚步特写 | 2秒 |
| **合计** | | **7秒** |

## 四、画面内容·场景版分镜

### 分镜结构详解

每一个分镜必须包含这8个要素：
1. **景别**：远景/全景/中景/近景/特写/大特写
2. **镜头情绪**：这个镜头要传递什么情绪
3. **构图**：三分法/对称构图/框架构图/倾斜构图/黄金分割
4. **运镜手法**：推/拉/摇/移/跟/升降/旋转/固定
5. **人物表演**：具体的微表演动作，不是情绪标签
6. **环境参与**：环境如何参与叙事，不是背景板
7. **画面内容**：具体的画面描述
8. **声音/台词**：同期声和台词

### 分镜示例

▸ **分镜一：00.00-00.03**
  - 景别：中景
  - 镜头情绪：悬疑、紧张
  - 构图：框架构图，利用门框形成画框
  - 运镜手法：缓慢推镜，从全景推到中景
  - 人物表演：身体微微前倾，右手放在腰间手枪上，手指轻轻敲击枪柄三次，喉结缓慢滚动一次
  - 环境参与：门框的阴影落在人物脸上，一半脸在光明中，一半脸在黑暗中
  - 画面内容：人物站在工厂门口，背光而立，只能看到轮廓，随着推镜，面部细节逐渐清晰
  - 声音/台词：（环境音）远处的滴水声，越来越清晰的脚步声
                  （内心音）"猎物来了"

▸ **分镜二：00.03-00.07**
  - 景别：特写
  - 镜头情绪：压迫、危险
  - 构图：倾斜构图，打破平衡感
  - 运镜手法：快速摇镜，从脸部摇到手上
  - 人物表演：瞳孔骤然收缩，右手快速拔枪，左手握住套筒向后拉再松开，上膛动作一气呵成，指节因用力而发白
  - 环境参与：上膛的声音在空旷的工厂中产生明显回声
  - 画面内容：手枪特写，子弹上膛的金属碰撞瞬间，枪身反射寒光
  - 声音/台词：（动作音）"咔哒"——清脆的上膛声，带有明显混响
                  （呼吸音）急促但克制的呼吸声

## 五、画质、风格与约束

### 5.1 画质约束
> 8K超高清渲染，光线追踪全局光照，体积光效果，真实的物理材质，无明显AI伪影，人物面部无崩坏，手部动作自然，服装纹理清晰，金属质感真实

### 5.2 风格统一
> 全程保持3D国漫写实风格，人物模型统一，场景风格统一，光影风格统一，色彩调性统一

### 5.3 物理连续性
> 人物服装在分镜之间保持一致，道具位置合理，光影方向统一，物理运动符合自然规律，无穿模，无瞬移

### 5.4 动作约束
> 动作"慢、连、稳"——避免快速甩镜，避免快速切换，避免大幅度快速动作，保持镜头稳定，动作连贯自然，每个动作都有清晰的开始和结束

# 微表演词库

## 一、压迫感（OPPRESSION）

### 眼部动作
- 眼睫轻垂，眼帘半掩，目光从睫毛缝隙中射出
- 瞳孔骤然收缩，然后缓慢放大
- 眼皮微微颤动，频率越来越快
- 目光死死锁定目标，眼珠一动不动
- 眨眼频率明显降低，几乎不眨眼

### 喉部动作
- 喉结缓慢而用力地滚动一次
- 喉结上下滚动，频率越来越快
- 吞咽动作明显，喉咙发出轻微的"咕嘟"声
- 颈部肌肉绷紧，青筋微微暴起

### 手部动作
- 手指关节慢慢发白，握力越来越大
- 指节一个接一个地发白，像多米诺骨牌
- 手掌慢慢攥紧，指甲深深嵌入掌心
- 手背青筋暴起，随着心跳微微搏动
- 手指在某个物体表面反复敲击，节奏越来越快

### 呼吸动作
- 呼吸突然停半拍，然后猛地吸气
- 呼吸变得浅而快，胸口快速起伏
- 吸气时鼻翼微微张开，幅度越来越大
- 呼出的气息明显变粗，带着颤音

---

## 二、悲伤（SORROW）

### 眼部动作
- 眼眶慢慢泛红，眼泪在眼眶中打转但不落下来
- 睫毛被泪水打湿，一根一根粘连在一起
- 眼泪顺着脸颊慢慢滑落，留下清晰的泪痕
- 视线逐渐模糊，目光失去焦点
- 眨眼时眼泪顺着眼角溢出，沿着鼻翼滑落

### 面部动作
- 嘴角微微向下，想要忍住但忍不住
- 嘴唇微微颤抖，想要说话但发不出声音
- 脸颊肌肉微微抽动，频率不规则
- 鼻子微微皱起，鼻头泛红
- 下巴微微颤抖，咬紧嘴唇试图控制

### 呼吸动作
- 吸气时带着明显的颤音，胸口剧烈起伏
- 呼吸突然中断，像被什么东西堵住一样
- 鼻子发出轻微的"抽噎"声，一声接一声
- 深呼吸试图平复情绪，但吸到一半又卡住

### 手部动作
- 手指轻轻拂过脸颊，拭去眼泪但越拭越多
- 手掌捂住嘴巴，不让哭声发出，但指缝间漏出呜咽
- 手指紧紧攥住胸口的衣服，布料被揉成一团
- 双手抱头，手指插入头发中，用力抓扯

---

## 三、紧张（TENSION）

### 眼部动作
- 目光快速扫视，眼珠左右移动频率越来越快
- 瞳孔微微放大，对光线变化异常敏感
- 频繁眨眼，眨眼间隔越来越短
- 眼皮不受控制地微微跳动
- 视线不敢与任何人接触，一直看向地面或虚空

### 面部动作
- 额头渗出细密的汗珠，顺着鬓角滑落
- 脸颊肌肉不自主地抽动，左右交替
- 嘴唇发干，舌头反复舔舐嘴唇
- 牙关紧咬，脸颊肌肉绷紧
- 面部血色迅速褪去，变得苍白

### 手部动作
- 手指反复摩挲某个物体，动作越来越快
- 手心出汗，手掌在裤子上反复擦拭
- 手指交叉在一起，指节发白
- 手掌反复张开又攥紧，循环往复
- 手指颤抖，拿东西时明显不稳

### 身体动作
- 脚不自觉地踮起又放下，反复进行
- 身体重心不断左右转换，站姿不稳定
- 肩膀不自觉地绷紧，耸起又放下
- 身体微微发抖，幅度小但持续
- 喉咙反复吞咽，频率越来越高

---

## 四、愤怒（ANGER）

### 眼部动作
- 瞳孔骤然收缩成针孔状，眼神如刀
- 眼白布满血丝，眼睛瞪得浑圆
- 目光死死锁定目标，眼珠一动不动
- 眼皮微微跳动，频率与心跳同步
- 眨眼频率极低，几乎不眨眼

### 面部动作
- 脸颊肌肉绷紧，颧骨高高隆起
- 鼻翼剧烈张开，呼吸粗重
- 牙关紧咬，下颌肌肉鼓起
- 嘴角向下撇，形成明显的法令纹
- 额头青筋暴起，随着心跳搏动

### 喉部动作
- 喉结用力滚动，吞咽动作明显
- 从喉咙深处发出低沉的嘶吼声
- 说话时声音沙哑，带着明显的颤音
- 呼吸粗重，每一次呼吸都带着"呼哧"声

### 手部动作
- 拳头攥紧，指节发白，手背青筋暴起
- 手指关节发出"咔咔"的声响
- 手掌用力拍击某个物体，力度很大
- 手指指向目标，指尖因用力而颤抖
- 手臂肌肉绷紧，血管清晰可见

---

## 五、震惊（SHOCK）

### 眼部动作
- 眼睛骤然睁大，眼白暴露明显增多
- 瞳孔瞬间放大，然后又骤然收缩
- 目光死死盯住震惊源，完全移不开
- 眼皮完全抬起，眉毛高高扬起
- 眨眼动作完全停止，整个人僵住

### 面部动作
- 嘴巴不由自主地张开，呈O型
- 下巴微微下垂，完全失去控制
- 面部血色瞬间褪去，变得惨白
- 脸颊肌肉完全放松，呈现呆滞状态
- 额头渗出冷汗，顺着脸颊滑落

### 身体动作
- 整个身体瞬间僵住，所有动作停止
- 身体不由自主地向后退半步
- 肩膀猛地一缩，呈现防御姿态
- 呼吸完全停止，持续数秒后才恢复
- 手中的东西不由自主地掉落

### 手部动作
- 手掌下意识地捂住嘴巴
- 手指颤抖，完全不听使唤
- 手臂无力地垂下，失去所有力量
- 手指指向震惊源，但在空中颤抖
- 手掌扶住额头或太阳穴，支撑身体

---

## 六、疲惫（EXHAUSTION）

### 眼部动作
- 眼皮沉重，每一次眨眼都需要用力
- 眼神失去焦点，目光涣散
- 眼白布满血丝，黑眼圈明显
- 频繁打哈欠，眼泪都被挤出来
- 视线无法长时间聚焦，看一会儿就需要移开

### 面部动作
- 面部肌肉放松，呈现垮掉的状态
- 嘴角自然下垂，没有任何表情
- 面色苍白，没有血色
- 皮肤失去光泽，呈现灰暗状态
- 下颌松弛，嘴巴微微张开

### 呼吸动作
- 呼吸浅而无力，胸口起伏很小
- 每一次深呼吸都像是用尽全身力气
- 呼吸频率慢，间隔很长
- 呼气时带着明显的叹息声
- 呼吸时肩膀微微耸动，显得很费力

### 身体动作
- 身体重心下沉，站姿明显放松
- 肩膀垮下来，没有任何张力
- 脚步沉重，每一步都像是拖着铅块
- 身体微微驼背，脊柱失去挺直的力量

#!/usr/bin/env python3

"""
Seedance 2.0 清道夫分镜提示词生成脚本
时间预算规则与提示词结构模板
"""

# 时间预算拍数规则
TIME_BUDGET_RULES = {
    "physical_action": 1,      # 一个物理动作 = 1拍
    "camera_movement": 1,      # 一次主运镜 = 1拍
    "environment_change": 1,   # 一次环境变化 = 1拍
    "short_dialogue": 1,       # 8字内短对白 = 1拍
    "medium_dialogue": 2,      # 9-16字对白 = 2拍
    "long_dialogue": "split",  # 超24字必须拆分
}

# Seedance单条建议时长范围
MIN_DURATION = 4  # 秒
MAX_DURATION = 15  # 秒

def calculate_time_budget(shots):
    """
    计算分镜的时间预算
    
    Args:
        shots: 分镜列表，每个分镜包含动作类型
        
    Returns:
        total_time: 总时长（秒）
        budget_table: 时间预算表
    """
    total_time = 0
    budget_table = []
    
    for i, shot in enumerate(shots, 1):
        shot_time = 0
        shot_content = shot.get('content', '')
        
        # 计算这个分镜的拍数
        shot_parts = shot.get('parts', [])
        shot_beats = sum(TIME_BUDGET_RULES.get(part, 1) for part in shot_parts)
        shot_time = shot_beats * 0.8  # 每拍约0.8秒
        
        total_time += shot_time
        budget_table.append({
            'shot_num': i,
            'content': shot_content,
            'beats': shot_beats,
            'duration': round(shot_time, 1)
        })
    
    return round(total_time, 1), budget_table

def validate_duration(total_time):
    """
    验证时长是否在合理范围内
    """
    if total_time < MIN_DURATION:
        return False, f"时长过短（{total_time}秒），建议增加分镜或放慢节奏"
    elif total_time > MAX_DURATION:
        return False, f"时长过长（{total_time}秒），建议拆分成多条提示词"
    else:
        return True, "时长合理"

def generate_storyboard_prompt(scene_data):
    """
    按照清道夫模版生成完整的分镜提示词
    
    Args:
        scene_data: 场景数据字典
        
    Returns:
        完整的分镜提示词字符串
    """
    # 一、基础设定
    basic_settings = f"""一、基础设定
【基础设定】
▸ 角色 / 主体：{scene_data.get('character', '未设定')}

"""

    atmosphere = f"""

    shots = scene_data.get('shots', [])
