# Micro Expression Prompting

来源：2026-06-16 用户提供“AI 微表情提示词”图片资料。

## 核心原则

微表情是把抽象情绪翻译成 I2V 可执行表演的中间层。

不要只写：

```text
开心、害怕、悲伤、委屈。
```

要写：

```text
眼神、眉毛、嘴角、嘴唇、头部动作、呼吸、肩膀、手部反应。
```

## 使用范围

适合：

- 近景。
- 中近景。
- 面部特写。
- 对话反应镜头。
- 情绪转折镜头。
- 角色独处镜头。

不适合：

- 远景。
- 大远景。
- 群像调度。
- 快速动作镜头。
- 战场混乱镜头。

## 写法规则

一个镜头通常选择 2-4 个微表情锚点。

推荐组合：

- 眼神 + 嘴角。
- 眼神 + 眉毛 + 呼吸。
- 嘴唇 + 头部动作 + 手部动作。
- 眼眶 + 低头 + 声音。

不要把同一类情绪的全部细节塞进一个镜头。

## 情绪分层

### 喜

自然微笑、俏皮眨眼、灿烂大笑、坏笑 / 邪笑、甜蜜对视、天真无邪、暗爽得意、宠溺笑、羞涩低头、苦笑 / 无奈笑。

### 惊

瞳孔放大、瞳孔地震、惊恐后退、战栗恐惧、难以置信、怀疑警惕、心虚躲闪、惊吓后怕、毛骨悚然、绝望失神。

### 哀

哀伤泛红、空洞麻木、泪水滑落、隐忍不哭、低声啜泣、绝望闭眼、崩溃大哭、默默流泪、委屈撇嘴、触景生情。

## 示例

弱写法：

```text
她很悲伤，但努力忍住。
```

更稳写法：

```text
她眼眶泛红，嘴唇紧抿，低头停顿半秒，右手攥住衣角，低声说：“我……没事。”
```

弱写法：

```text
他非常震惊。
```

更稳写法：

```text
他眼睛睁大，眉毛猛地上提，嘴唇微张，身体向后退半步，呼吸明显变急。
```
