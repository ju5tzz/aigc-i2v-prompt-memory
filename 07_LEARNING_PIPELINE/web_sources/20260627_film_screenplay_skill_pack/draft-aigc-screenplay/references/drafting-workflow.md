# 剧本扩写流程

## 输入检查

完整初稿需要：

- 项目创作简报；
- 已锁定故事核心卡；
- 已锁定人物与关系圣经；
- 已锁定节拍表和分场表；
- 世界与资产圣经；
- 当前连续性账本。

缺少锁定项时，说明只能进行试写。

## 场次扩写

每场先读取：

```text
场次 ID：
场景目的：
进入人物及状态：
人物目标：
阻力：
策略：
转折：
离场状态：
下一场因果：
资产引用：
预计时长：
```

然后按以下顺序写：

1. 只建立与本场冲突有关的环境；
2. 让人物以行动表达当下目标；
3. 引入阻力；
4. 让人物改变策略；
5. 产生不可忽略的结果；
6. 以新状态离场。

## 动作行

- 使用现在时；
- 优先具体动词；
- 避免“他感到、她意识到”等不可见心理；
- 写清动作对象和结果；
- 连续动作过多时按因果节拍拆开；
- 普通背景物件不建立资产 ID。

## 对白

初稿对白服务目标、冲突和信息。避免角色向彼此解释双方都知道的背景。

本阶段不追求每句都是金句，也不进行逐句七维诊断。

## AIGC 连续性

每场结束记录：

- 人物位置和移动方向；
- 知识与关系变化；
- 伤势、服装、污损和装备变化；
- 道具归属和损坏；
- 场景破坏、光线、天气和时间；
- 新伏笔与已回收伏笔。

## 长内容

短片可输出完整初稿。长片按序列分批，每完成一个序列更新状态快照，不一次生成完整长片。
