## 1. 故事发动机

先回答：

```text
故事前提：
主角：
外在目标：
为什么必须现在行动：
内在缺失：
错误信念：
对抗力量：
时间压力：
失败代价：
核心两难：
高潮选择：
结局如何证明改变：
主题问题：
独特性：
```

外在目标必须可以判断成功或失败。内在需求不是主角嘴上想要的东西，而是其必须改变或承认的部分。

错误信念应能产生行动：

```text
错误信念
→ 惯用策略
→ 暂时奏效
→ 制造更大问题
→ 被迫选择改变或付出代价
```

## 2. 前提检验

逐项判断：

- 清晰性：一句话是否能说清人物、目标、阻力和代价；
- 冲突性：目标与阻力是否天然对立；
- 持续性：矛盾能否支撑目标时长；
- 升级性：阻力是否越来越难；
- 主动性：关键转折是否由人物选择触发；
- 独特性：换一个主角，故事是否仍完全一样；
- 兑现性：开头承诺的类型体验是否在中后段兑现；
- 结局性：高潮是否不可被普通谈话轻易替代。

如果其中三项以上明显薄弱，先修正核心前提。

## 3. 方案比较

不要只换皮。每个方案至少改变一个高影响变量：

- 谁是主角；
- 主角追求什么；
- 谁或什么是主要对抗力量；
- 谁掌握关键信息；
- 观众跟随谁的视角；
- 世界规则如何运作；
- 高潮面对什么道德选择；
- 结局付出什么代价。

评价表：

```text
一句话定位：
核心变化：
戏剧强度：
人物潜力：
主题潜力：
类型兑现：
视觉潜力：
生成稳定性：
资产复用率：
制作复杂度：
最大收益：
最大风险：
```

推荐方案时说明依据，不把生产最简单等同于创作最好。

## 4. 节拍设计

节拍是局势发生改变的最小叙事单位：

```text
节拍 ID：
人物当下目标：
阻力：
行动或策略：
结果：
局势变化：
情绪变化：
建立或回收的信息：
使用资产：
生成复杂度：
```

相邻节拍优先满足：

```text
发生 A，因此人物做 B。
人物做 B，但是遭遇 C。
```

连续使用“然后”通常意味着因果不足。

## 5. 场次设计

每场填写：

```text
场次 ID：
内／外景：
地点与时间：
出场角色及进入状态：
主导者：
场景目标：
对抗者及其目标：
双方策略：
转折：
离场状态：
下一场为什么必然发生：
核心可见动作：
关键声音：
资产引用：
预计时长：
生成风险：
```

场次必须至少改变一项：

- 信息；
- 关系；
- 权力；
- 危险；
- 物理状态；
- 人物决定；
- 目标或策略。

删场测试：删除后若剧情、人物和状态都不受影响，应删除、合并或重写。

## 6. 常见问题

### 主角被剧情推着走

让转折来自主角的决定，即使该决定错误。

### 冲突只有争吵

让双方拥有互斥目标，并通过行动争夺具体结果。

### 高潮靠解释解决

把主题答案变成有代价的行动。

### 场景信息很多但没有戏

为场景增加目标、阻力、策略变化和离场转折。

### 为 AI 生产而削平故事

先保留戏剧功能，再寻找替代表现；不要先删掉困难部分。
