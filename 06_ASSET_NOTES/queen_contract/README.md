## 后续写某一集提示词的默认读取顺序

1. 先读本文件。
2. 读 `PROJECT_OVERVIEW.md`。
3. 读 `CHARACTER_BIBLE.md` 中当前集涉及人物。
4. 读 `CONTINUITY_LEDGER.md` 中当前集所属段落。
5. 读 `EPISODE_INDEX.md` 中当前集及前后一集概要。
6. 涉及实际生产、素材评估或后期剪辑时，读 `PRODUCTION_WORKFLOW.md`。
7. 读 `00 FILES/projects/queen_contract/episodes/EP###.md` 的当前集原文。
8. 若当前集强依赖前后承接，再读取前后一集原文。

## 使用边界

- 本项目笔记用于减少重复全量读取，不替代原剧本。
- 如果用户要求修改剧情，以用户最新指令覆盖本索引。
- 写正式 I2V 提示词时仍遵守 `09_SKILLS/i2v-prompt-workflow/SKILL.md`：只输出提示词正文层，不写资产绑定标签。
- 做后期剪辑方案时遵守 `PRODUCTION_WORKFLOW.md`：先盘点原始片段，再按剧本节点、台词节奏和情绪反应重组时间线。
