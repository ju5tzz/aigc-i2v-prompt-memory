## 章节脉络

### 00:00-03:00 开场与全流程预告

作者说明自己会从头到尾演示 AI 短片制作流程：从一个点子开始，扩展成剧本，再做资产图，最后生成视频。视频强调高质感 AI 短剧和普通 AI 生成视频的差距，主要不在单一模型或单条提示词，而在完整制作思路。

他把本期流程分成四段：

1. 前期准备：选择智能体，以及为什么要使用带 Skill 的智能体。
2. 剧本创作：哪些内容可以交给 Agent，哪些必须由人决定。
3. 资产库制作：把剧本拆解成角色、场景、道具等资产。
4. 拍摄环节：如何写可执行的镜头段落、生成视频、检查并重抽。

### 03:00-06:00 为什么用 Agent + Skill

作者区分了普通提示词模板和 Skill 化智能体的差别。普通网页对话通常是一次性回答，而 Skill 更像岗位说明书，会告诉 Agent 它在什么流程、承担什么角色、需要问什么、什么时候需要用户确认、什么时候可以继续推进。

本期使用或提到的三个核心 Skill：

- 剧本创作 Skill：帮助从点子扩展人物、世界观、冲突、剧情段落。
- 资产图设计 Skill：从剧本拆解角色、场景、道具，并输出资产清单。
- 辅助拍摄 / 视频提示词 Skill：把剧本和资产转成拍摄列表、镜头提示词、检查项。

关键观点：Skill 不是固定答案，而是一套可复用流程。用户可以基于作者的 Skill 改出自己的工作习惯。

### 06:00-10:00 工具准备

作者讲到 Codex 的使用环境和模型接入。大意是可以使用 Codex 桌面端，也可以结合第三方平台或不同模型能力。视频中还提到中文设置、会员/平台登录等准备步骤。

由于本次只做音频转文字，没有做画面检查，具体界面操作细节没有被完整保留；能确认的是：作者希望用 Codex 作为执行流程的 Agent 容器，通过 Skill 调用不同阶段的专业流程。

### 10:00-14:00 从故事点子开始，而不是让 AI 一键写完整剧本

作者反复强调：不要直接让 AI 从一句话生成完整剧本。那样很容易得到平均、平庸、缺少冲突的故事。

他的做法是先由人给出一个有冲突、有反转、有价值观张力的故事种子，再让 Agent 扩展。视频中的案例大致是一个“现代社畜/普通人误入或卷入修仙世界”的设定，并强调反差、身份错位和价值观冲突。

这一段的核心方法：

- 人负责提供方向、冲突、价值观和判断。
- Agent 负责扩展人物、世界观、关系、剧情可能性。
- 不追求第一次输出完美，而是把故事放进可迭代流程。

### 14:00-19:00 剧本创作 Skill 的价值

剧本 Skill 的价值不只是“帮你写剧本”，而是先问清楚故事目标、核心冲突、角色关系、短片时长和表达重点，再逐步扩展。

作者提到这个 Skill 会做类似以下事情：

- 明确故事核心冲突。
- 扩展人物和世界观。
- 生成短片可拍摄段落。
- 通过“剧本医生”或量化评分检查故事问题。
- 对冲突、节奏、设定、人物动机提出修改建议。

关键判断：如果核心卖点错了，不要等完整剧本写完才发现问题。应该在早期就让 Agent 分析故事是否成立，然后人再决定保留、修改或重写。

### 19:00-22:30 用 25 宫格分镜图检查剧本

剧本初稿出来后，作者不建议立刻进入资产图制作，而是先生成类似 25 宫格的分镜/故事版，用来直观看到这个故事是否清楚、是否有冲突、是否过于复杂。

这里的分镜图不是最终资产，也不是正式镜头参考，而是检查工具。如果图里暴露出叙事太乱、设定太重、核心不突出，就回到剧本阶段修改。

作者的经验判断：

- 一分钟短片不需要讲完整世界观。
- 需要让观众快速知道人物处境和核心冲突。
- 如果早期分镜已经看不懂，后面生成视频只会放大问题。

### 22:30-29:20 资产图与资产库

剧本确定后，进入资产拆解。作者认为高质量 AI 短剧不能只靠临时生成图片，而要把剧本拆成可管理的资产库。

资产大致包括：

- 人物资产：主角、女主、反派、重要配角等。
- 场景资产：主要空间、环境、建筑、室内外位置。
- 道具资产：剧情关键物、身份标识、武器、服装等。

作者强调人物资产最重要。人物图需要做出身份、气质、服装、表情和与世界的反差。例如现代人进入修仙世界，服装和气质不能完全像修仙世界原住民。

场景图也不建议都做成正面视角。侧面、斜角、不同时间、不同空间关系的图，往往更有利于后续视频生成。资产图本质上是在做美术设计和视觉设定，不只是“生成几张好看的图”。

### 29:20-36:00 拍摄环节：文本约束 + 资产引用 + 镜头列表

作者认为拍摄环节是整套流程中最核心的部分。很多 AI 视频卡住的不是图，而是如何把剧本和资产变成能被视频模型理解的镜头。

他比较了几种方式：

- 只用文字让模型自由分镜：动态可能好，但稳定性和准确性不可控。
- 用故事板或分镜图作为参考：结构更明确，但可能限制模型发挥。
- 用结构化文字把分镜、构图、动作、表演说清楚：让模型在文字约束下生成镜头。

他更倾向第三种，并用资产图辅助控制人物、空间和风格。

拍摄列表大致包含：

- 镜头编号和时间。
- 画面动作与剧情功能。
- 画面构图：人物位置、前景/中景/远景。
- 机位和镜头运动。
- 人物动作、表演和情绪。
- 需要引用的资产图。
- 文生视频或图生视频提示词。
- 可能的错误检查项。

这一段对提示词仓库有价值，因为它把“视频提示词”从一句描述升级成“拍摄任务单”。

### 36:00-43:30 生成、检查、补镜头和抽卡

进入实际生成后，作者强调要把资产图上传给模型，让模型理解人物和位置关系。对于复杂位置关系，可以先让 Agent 生成类似 SVG/结构图的空间关系说明，帮助减少人物站位错误。

生成后要检查：

- 人物是否一致。
- 空间关系是否错乱。
- 镜头动作是否符合剧情。
- 角色表演是否准确。
- 画面是否出现物理或逻辑错误。
- 两段视频之间是否衔接自然。

如果两个镜头衔接不好，可以把前一段视频尾帧和后一段视频首帧交给 Agent，说明想要的过渡方式，让它辅助设计补镜头或转场方案。

作者最后强调，精品短剧需要大量有目标的抽卡。抽卡不是盲目重试，而是每次识别错误、修改提示词或资产引用，再继续生成。

## 可复用方法论

1. 不要追求“一条万能视频提示词”，而要拆成剧本、资产、拍摄、检查四个阶段。
2. 人要负责故事方向、价值判断和最终审美，Agent 负责扩展、拆解、检查和生成中间物。
3. Skill 的价值在于沉淀流程，而不是沉淀某一句固定提示词。
4. 剧本阶段要先检查核心冲突，不能等到完整剧本甚至视频生成后才发现故事不成立。
5. 25 宫格分镜适合作为早期诊断工具，不一定作为最终资产或视频参考。
6. 资产图是美术设计，不是随便生成好看图片；人物、场景、道具应进入可管理资产库。
7. 拍摄提示词应该像镜头任务单，包含镜头编号、构图、机位、动作、表演、资产引用和检查项。
8. 视频生成后的反馈要结构化：发现什么错、为什么错、下一次提示词或资产如何改。
9. 高质量 AI 短剧来自流程和迭代，不来自单次生成。
