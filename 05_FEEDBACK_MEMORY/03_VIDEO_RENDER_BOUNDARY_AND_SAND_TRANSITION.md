# Video Render Boundary And Sand Transition

来源：2026-06-09《丝路上的绿洲》新疆历史人文短片成片反馈。

## 观察到的问题

1. 视频前面几帧出现黑屏。
2. 预期的“风沙吹过”转场没有真正覆盖切换瞬间，实际观感变成闪黑转场。

## 可能原因

- 首帧没有被显式绘制为第一张有效画面，时间线在 `t=0` 附近使用了淡入或透明度窗口，导致前几帧背景色暴露。
- 场景淡出与下一场景淡入之间存在短暂空窗，底层黑色背景在交叉淡化中露出。
- 风沙转场只是附加光扫效果，没有作为“遮罩层”覆盖场景切换点；它出现的时间与画面切换时间没有严格对齐。
- 转场层透明度、宽度、模糊和持续时间不足，无法在切换时完全遮住前后画面差异。

## 有效修正

- 第 0 帧必须直接显示首个有效画面，不允许从黑底淡入。首场景在 `t=0` 的 opacity 应为 `1`。
- 场景切换必须使用交叉淡化，且任意时刻至少有一个场景完全或近似可见；禁止出现所有场景 opacity 同时接近 `0` 的空窗。
- 风沙转场应覆盖在切换点前后，例如从 `cut - 0.35s` 持续到 `cut + 0.45s`，并在 `cut` 附近达到最高不透明度。
- 风沙层要足够宽、足够亮、带模糊边缘，并跨越全画面高度，作为真实遮挡层，而不是仅作装饰光束。
- 渲染后必须抽查 `0s`、`0.1s`、每个切换点前后各 `0.2s` 的帧，确认无黑屏、无闪黑、转场可见。

## 后续生成硬性检查

- 首帧检查：`t=0` 和 `t=0.1s` 必须是有效画面。
- 切点检查：每个切换点附近必须抽帧，例如 `3.8s / 4.0s / 4.2s`。
- 透明度检查：合成逻辑中不得让所有主场景同时透明。
- 转场检查：若文案要求风沙、烟雾、光扫、擦除等效果，必须让该效果跨越切换点并实际承担遮挡功能。

## 适用范围

- 竖屏短片合成
- 图文海报式短视频
- 多张静帧做动态推拉的 I2V / slideshow 视频
- 需要沙尘、烟雾、光束、纸张擦除等转场的历史、人文、古风内容

## 不适用范围

- 用户明确要求硬切或黑场转场的片段
- 片头故意从黑场渐入的电影化开场，但仍需避免“意外黑帧”
