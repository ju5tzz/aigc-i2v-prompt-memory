## 1. 不要把运镜清单误解为术语教学

### 核心判断

这 36 种运镜的价值不是教模型认识“推、拉、摇、移”等传统概念。当前模型本身已经理解常见影视语言。

它们真正提供的是一份能力许可清单：当镜头任务需要时，Codex 可以主动提出更有表现力的运镜，不应因为旧预训练经验而提前否定。

### 行动规则

先判断镜头任务，再从能力清单中选择可用方案。

不要默认退回：

```text
平视、中景、固定微推。
```

## 3. 能力成立不等于术语单独足够

弱写法：

```text
使用俯冲下降镜头。
```

可执行写法：

```text
镜头从营寨上空高位俯拍开始，快速下降穿过飘动军旗，在帐门前减速，最后停在押送士兵和黑瘦少年上方的中远景。
```

术语用于选择能力，路径用于驱动执行。

## 4. 可以大胆组合，但一次只围绕一个主镜头任务

可以组合：

```text
低机位仰拍推进 + 环绕半圈
```

```text
物体视角跟拍 + 冲击拉远
```

```text
第一人称穿行 + 前景遮挡转场
```

但不要无边界叠加：

```text
高速穿越 + 360度环绕 + 急速变焦 + 俯冲 + 甩镜 + 长距离飞越
```

每个镜头仍需一个主任务：追逐、揭示、压迫、反转、线索或情绪。

## 5. 需要继续实测的高表现力能力

建议后续优先验证：

1. 子弹时间环绕在人物动作镜头中的稳定性。
2. 时间凝固推进在群像场景中的人物一致性。
3. 镜头穿越门窗或人群时的空间连续性。
4. 物体视角跟拍在抛掷物、箭矢、炮弹、掉落物上的执行力。
5. 冲击拉远对“先特写后揭示危机”的控制力。
6. 鸟瞰旋转在战场、仪式和群体调度中的可用性。
7. 变焦压缩是否能稳定体现背景空间变化。
