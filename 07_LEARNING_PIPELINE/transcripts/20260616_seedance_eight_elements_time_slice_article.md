## 1. 为什么 Seedance 视频不出彩

文章认为，新手常写低信息密度提示词，例如：

```text
一个女生在海边跑步，日落很美。
```

这种提示词能生成画面，但往往只有平均水准。原因是信息密度太低，AI 不知道 15 秒视频应按什么节奏、运镜、质感来呈现，只能按默认值填充。

## 2. 八要素公式

文章提出 Seedance 提示词公式：

```text
主体 + 动作 + 场景 + 光影 + 镜头语言 + 风格 + 画质 + 约束
```

八个要素分别是：

- 主体：谁 / 什么在画面里。
- 动作：主体做什么，最好具体到发丝、脚步、手部等细节。
- 场景：年代、地点、空间。
- 光影：自然光、人工光、时间点。
- 镜头语言：景别、运镜、切换。
- 风格：日系、武侠、电影、治愈等调性。
- 画质：4K、电影感等清晰度与质感。
- 约束：人物一致、动作连贯等不能出错的部分。

文章认为，提示词不应只是 prompt，而应接近分镜脚本或导演指令。

## 3. 时间轴切片

文章建议把 15 秒视频切成 4 段：

```text
0-3 秒：全景，交代环境。
3-7 秒：中景，主体出现，开始动作。
7-11 秒：特写，动作细节、情绪放大。
11-15 秒：拉远 / 收尾，结束或转折。
```

文章观点：每 3-4 秒一个节奏点，AI 才能跟着创作者的节奏走。

## 4. 实战案例

错误写法：

```text
一个农民在深夜把地下党藏在地窖里，紧张，感人。
```

正确写法使用 16:9、15 秒、时间轴切片、水墨动漫风、真实质感，并按全景、中景、特写、近景收尾组织动作。

重点包括：

- 月色下华北村庄远景。
- 农民快步走出，拎旧铁锹，踩过冰霜泥地。
- 农民揭开地窖木板，灰尘在油灯光中飘散。
- 地下党带血的手抓住木板边缘。
- 农民犹豫后咬牙把人拽进地窖。
- 木板盖上后，农民瘫坐喘气，镜头上移拉远定格。

## 5. 强化词模板

文章列出强化词类别：

- 画质类：4K 超高清、电影质感、细节丰富、胶片颗粒感。
- 稳定类：面部清晰不变形、人体比例自然、动作流畅连贯无跳帧、五官一致。
- 光影类：暖黄逆光、丁达尔效应、自然光电影级打光、月光冷色调。
- 氛围类：治愈清新、赛博朋克、史诗级、紧张压抑、温馨怀旧、肃杀冷峻。
- 风格类：水墨动漫风、那兔模式、迪士尼皮克斯风、吉卜力风、新海诚风、电影质感。

## 6. 快速模板

文章给出模板：

```text
【标题】
画面比例（9:16 / 16:9），15 秒，【风格定位】。
0-3 秒：全景【环境描写】。
3-7 秒：中景【主体出现 + 动作】。
7-11 秒：特写【动作细节 / 情绪】。
11-15 秒：近景到全景【收尾 / 转折】。
【强化词】关键词1，关键词2，关键词3，关键词4。
```

## 7. 常见坑

文章提醒：

- 不要写“感人”“紧张”这类抽象词，要转化为可见动作和细节。
- 不要省略动作细节。
- 不要忘记强化词。
- 不要试图一镜到底，15 秒内要有 3-4 个节奏切换点。
- 不要期待 AI 懂历史细节，年代、地点、服装、军装等要写具体。

## 8. 文章结论

文章认为，Seedance 提示词的难点不是门槛高，而是具体和细节。

高信息密度、时间轴、微观动作和清楚的分镜结构，可以显著提高出片率和节奏控制力。
