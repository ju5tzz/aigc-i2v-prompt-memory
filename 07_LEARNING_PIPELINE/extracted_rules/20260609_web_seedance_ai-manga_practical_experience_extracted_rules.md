# Extracted Rules - Seedance 2.0 / AI漫剧 Web Search

- 日期：2026-06-09
- 来源类型：外部 Web 搜索
- 当前状态：待验证

这些内容来自外部社区、教程站和测评文章，只能作为“待验证经验”，不能直接写入 `01_ACTIVE_RULES/`。

## 1. 用 shot list 替代整段 blob prompt

### 原始观点

社区创作者反馈：从整段提示词改为结构化 shot list 后，Seedance 2.0 的连续性和镜头控制明显改善。

### I2V 可迁移假设

对多镜头短剧片段，每个镜头都应单独写成结构化条目，而不是把全部动作塞进一段长段落。

### 建议验证格式

```text
镜头1：时长，景别，机位，镜头运动。
画面：
人物调度：
台词：
声音 / SFX：
结束状态：
```

### 待验证实验

同一段 15 秒剧情分别使用整段描述和 shot list 描述生成，比较镜头边界、角色连续性和动作执行。

## 2. 每个镜头加入“镜头行为”而不只写画面内容

### 原始观点

多处教程强调，提示词需要写运镜，不能只写主体和场景。常见结构为：

```text
主体 + 动作 + 场景 + 光影 + 镜头语言 + 风格 + 画质 + 约束
```

### I2V 可迁移假设

当前短剧提示词应持续强化景别、机位、运镜、镜头终点，而不是只交代剧情动作。

### 待验证实验

对同一镜头测试：

```text
人物走进帐中说话。
```

对比：

```text
中近景侧面，镜头平稳跟随人物从帐门进入，前景门帘掠过镜头，人物停在帐中央后转头开口。
```

## 3. SFX 层可能帮助视觉节奏

### 原始观点

Reddit 创作者认为，即使 Seedance 不生成音频，SFX layer 仍会被读作节奏提示，帮助视觉节奏。

### I2V 可迁移假设

在短剧提示词中保留“声音 / SFX”字段，不只是为了音频，也可能帮助模型理解动作节奏和剪辑卡点。

### 风险

当前仓库已有“声音只写当前可生成声音”的规则。SFX 不能写后期备注，也不能引入不该出现在画面中的道具。

### 待验证实验

同一动作镜头分别加 / 不加 SFX 层，比较动作节奏、停顿、卡点强度。

## 4. 多镜头数量需要控制

### 原始观点

社区经验认为，一个 prompt 内 6-8 个镜头还可以保持，超过约 10 个镜头连续性开始变差。

### I2V 可迁移假设

当前 15 秒短剧片段更适合 3-5 个镜头。如果需要 6-8 个镜头，应使用明确的短镜头快切，不要让每个镜头承担复杂动作。

### 待验证实验

同一剧情分别拆成 4 镜头、6 镜头、8 镜头生成，比较连续性和可剪辑性。

## 5. Lens / 焦段词可能减少“平庸中景”

### 原始观点

社区创作者称显式写 24mm / 35mm / 50mm 可让模型更明确焦段，减少默认中景扁平感。

### I2V 可迁移假设

在部分关键镜头中加入“广角 / 标准镜头 / 长焦压缩感 / 24mm / 35mm / 50mm”等词，可能帮助区分空间冲击、人物近景和压迫感。

### 风险

焦段词可能对中文工作流不是稳定触发词；过度使用会让提示词变成术语堆砌。

### 待验证实验

同一镜头分别使用中文景别、中文景别 + 焦段词、焦段词 + 镜头运动三种写法，对比画面差异。

## 6. AI漫剧需要分镜后的制作统筹表

### 原始观点

AI漫剧工具强调，分镜确认后应生成角色、场景、道具、资产总览和接戏风险表。

### I2V 可迁移假设

对多集短剧，分镜提示词生成后应增加一轮“统筹检查”，检查：

- 本镜头出现哪些角色。
- 使用哪个场景。
- 有哪些关键道具。
- 起点 / 终点状态是否能接下一镜。
- 是否有角色服装、位置、道具消失等接戏风险。

### 待验证实验

为第五集或第六集分镜生成一版制作统筹表，检查是否能提前发现接戏和资产遗漏问题。

## 7. 不要被“自分镜 / 自运镜”诱导成懒提示词

### 原始观点

部分测评认为 Seedance 2.0 有较强自分镜和自运镜能力，简单剧情也能自动规划镜头。

### I2V 可迁移假设

这说明模型有基础导演能力，但对当前短剧项目，仍应主动写清镜头任务。自运镜可以作为兜底，不应替代精确分镜。

### 风险

如果只写剧情让模型自行拍摄，可能出现镜头漂亮但戏剧信息错位、人物关系不稳定、结尾状态不可控。

### 待验证实验

同一片段分别使用“只写剧情”和“明确分镜”生成，比较戏剧信息准确率。
