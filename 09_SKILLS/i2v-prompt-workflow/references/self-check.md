# 提示词输出前自检清单

> 每次完成 I2V 提示词输出后，按本清单逐项检查。发现问题立即修正后再交付。

---

## 一、硬性纪律（必过）

### 1.1 15秒上限
- [ ] 每个生成单位总时长 ≤ 15 秒？
- [ ] 超了的已经继续拆成多个 ≤15 秒单位？

### 1.2 不写资产绑定
- [ ] 全文无 `@Image`、`@Video`、`@Audio`、`{{Portrait N}}` 或猜测性的平台资产编号？
- [ ] 无参考对象职责表（除非用户明确要求）？

### 1.3 对白时长预算
- [ ] 每句台词都按「字数 ÷ 语速系数 + 气口 + 反应镜头」算过镜头秒数？
- [ ] 台词过长时已经拆镜续接，而非删词压缩？
- [ ] 所有镜头时长只出现整数或 .5？

---

## 二、镜头丰富度

### 2.1 同单位内连续镜头
- [ ] 有没有连续 2 个以上镜头用了相同的「景别 + 机位 + 运镜」组合？
- [ ] 如果有，至少改变其中一项（例如：中景固定 → 近景轻微推近，或平视 → 低机位仰拍）

### 2.2 跨单位衔接（⚠️ 新增）
- [ ] 上一个生成单位的**最后一个镜头**，和下一个生成单位的**第一个镜头**：
  - 景别是否相同？（如都是"中近景正面固定" → 改其中一个）
  - 机位是否相同？（如都是平视 → 改仰拍/俯拍/越肩）
  - 运镜是否相同？（如都是固定微推 → 改其中一个为固定或跟拍）
- [ ] 两个相邻单位之间在视觉上有明确的差异（景别、角度或运动三者至少变一项）

### 2.3 戏剧节点运镜
- [ ] 关键情绪转折点（对峙、告白、发现、牵手、落泪、打断）的镜头是否有别于普通对话？
- [ ] 有没有使用竖屏原生强运镜（低机位抬升、俯拍收网、推近急停、台阶上推等）在对应的戏剧节点？
- [ ] 9:16 竖屏中没有连续使用平视中景？

### 2.4 反应镜头与短插镜
- [ ] 长对白（超过 3 句）是否插入了听者反应、手部特写或道具空镜？
- [ ] 短插镜时长是否控制在 0.5-1.5 秒以内，且只写一个视觉重点？

---

## 三、人物感情

### 3.1 前置信息
- [ ] 每个生成单位的【当前片段前置信息】是否能解释角色为什么此刻用这种语气/表情/停顿？
- [ ] 它只写了能影响当前表演的画面外原因，没有复述全局剧情或未来剧情？

### 3.2 微表情锚点
- [ ] 每个近景/特写镜头是否写了 2-4 个具体脸部部位的变化？
- [ ] 有没有出现"笑着""眼神变锐""很愤怒"这类抽象情绪描述？（有的话必须改写成可见部位）
- [ ] 表情变化是否绑定到具体的触发点（听到哪句话 / 看到什么东西 / 那一瞬间）？

### 3.3 微表情写法
- [ ] 抽象情绪 → 可见脸部部位（眉毛 / 眼神 / 嘴角 / 嘴唇 / 面部肌肉 / 呼吸 / 身体反应）
- [ ] 景别决定颗粒度：远景写大动作姿态，中景写眼神嘴角呼吸，近景/特写才写瞳孔眼尾泪光
- [ ] 微表情写成短暂动态过程：初始表情 → 触发事件 → 细微变化 → 立刻恢复
- [ ] 没有每个镜头硬套四部位（只有近景/特写/反应镜头/情绪转折才展开）

### 3.4 台词语气（⚠️ 新增）
- [ ] 有没有出现裸写「XXX说："XXXX"」？（有的话必须补上语气/动作/微表情）
- [ ] 每句台词是否配合了以下至少一项：

**语气描述**（必选其一）：
  - 低声、压低声音、声音发颤、尾音微扬、一字一顿、语速突然放慢/加快
  - 声音带笑意、鼻音、压着情绪、清冷、低沉、清脆、嗫嚅

**同步微表情/动作**（配合台词同时发生）：
  - 说话时 + [眼神/手指/嘴角/呼吸/头部动作]
  - 例：「她竖起一根手指，嘴角勾起算账式的笑，声音清脆："这账可得算清楚。"」

- [ ] 关键台词（金句、告白、威胁、反转）有没有配合**台词执行时的同步表演**，而不是只写说之前和说完后的表情？
- [ ] 标点符号是否正确引导语气？（迟疑用`……`、爆发用`！`、压低用`。`、上扬用`？`、拉长用`——`）

### 3.5 多人场景表情主次
- [ ] 主角表情精细突出，对手表情形成反差，配角符合人设但简化处理？
- [ ] 没有所有人都同等详细的表演指令？

---

## 四、质量收束

### 4.1 生成边界
- [ ] 【生成边界】/【重要要求】写成了正向停点和主体优先级描述？
- [ ] 没有写成"不要生成XXX"的负面列表？

### 4.2 结束状态
- [ ] 每个生成单位的最后一个镜头有明确的结束状态（停在哪个画面/谁在哪里/什么表情）？
- [ ] 结束状态与下一个生成单位的第一个镜头能自然衔接？

### 4.3 声音
- [ ] 声音字段只写了当前片段内模型能生成/同步的真实声音？
- [ ] 禁止项保持精简（默认：禁止字幕，禁止 BGM）？
