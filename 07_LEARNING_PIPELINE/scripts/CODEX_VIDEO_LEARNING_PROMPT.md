# Codex Video Learning Prompt

当用户提供 YouTube / B站 / 其他公开视频教程链接，并要求学习其中与 AIGC、I2V、多参考、故事板或提示词工程相关的内容时，按以下流程执行。

## 执行边界

你只能把外部教程经验写入 `07_LEARNING_PIPELINE/`。

未经用户明确实测反馈，不允许直接修改：

```text
01_ACTIVE_RULES/
```

## 执行流程

1. 先登记视频链接到 `07_LEARNING_PIPELINE/video_urls.md`。
2. 尝试获取官方字幕。
3. 如果没有官方字幕，再尝试获取平台自动字幕。
4. 如果字幕不可用，才提取音频并转录。
5. 将字幕或转录文本保存到 `07_LEARNING_PIPELINE/transcripts/`。
6. 单独生成视频摘要，保存到 `07_LEARNING_PIPELINE/summaries/`。
7. 单独提炼待验证经验，保存到 `07_LEARNING_PIPELINE/extracted_rules/`。
8. 更新 `video_urls.md` 中的视频状态。

## 输出要求

摘要文件只说明视频内容，不要写成规则。

待验证经验文件必须明确标注：

- 原始观点
- I2V 可迁移假设
- 适用条件
- 风险与不适用场景
- 与现有规则的关系
- 待验证实验
- 当前状态：待验证

## 禁止行为

- 不允许把外部视频观点直接写入 `01_ACTIVE_RULES/`。
- 不允许把“教程作者说法”改写成“本库正式规则”。
- 不允许跳过字幕抓取，直接做音频转录。
- 不允许把摘要和规则提炼混在同一个文件中。
- 不允许编造视频标题、作者、发布时间或字幕内容。

## 建议回复用户

完成后，向用户说明：

- 使用了哪种抓取方式。
- 生成了哪些文件。
- 提炼出的经验目前仍是“待验证”。
- 需要用户通过真实 I2V 任务反馈后，才可能升级到正式记忆库。
