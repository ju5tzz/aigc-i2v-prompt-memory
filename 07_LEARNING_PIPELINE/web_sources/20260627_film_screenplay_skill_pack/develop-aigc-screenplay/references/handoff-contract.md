# 分镜交接契约

## 目标

让下游分镜或视频提示词 Skill 不必重新推断剧本事实，同时不越权规定最终镜头设计。

## 每场交接字段

```text
场次 ID：
剧情目的：
不可删除的戏剧信息：
出场角色及状态 ID：
场景状态 ID：
道具、装备、视效和声音资产 ID：
开始状态：
结束状态：
核心可见动作：
关键对白及说话状态：
空间方向与出入口：
情绪方向：
生成风险：
下游优先测试：
允许调整：
禁止改变：
```

## 必须明确

- 谁在场，谁不在场；
- 人物进入和离开的方向；
- 谁持有什么；
- 动作前后物体和人物状态；
- 哪些对白必须保留原文；
- 哪些内容是剧情信息，不能只靠美术表达；
- 哪些动作可换表现方式；
- 哪些连续性依赖前后场；
- 是否已有角色图、场景图或道具参考。

## 不应包含

- 未经用户要求的最终焦段；
- 最终运镜方案；
- 特定视频模型提示词；
- 虚构的参考图编号；
- 与本场不可见内容无关的全部资产信息。

## 交接质量检查

下游应能仅凭剧本、资产圣经、连续性账本和交接单回答：

1. 这一场为什么存在；
2. 谁要什么；
3. 本场发生了什么不可逆变化；
4. 角色和资产当前是什么状态；
5. 最难生成的部分是什么；
6. 哪些表现可调整；
7. 哪些戏剧事实绝对不能改。
