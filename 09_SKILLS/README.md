## 同步规则

以后凡是修改或优化本机 `SKILL.md`，执行完成后都要：

1. 将对应 Skill 的最新 `SKILL.md` 和必要元数据镜像到本目录。
2. 更新相关仓库索引或反馈记忆。
3. 只提交本次相关文件，避免混入无关工作区改动。
4. 提交后推送到远端 GitHub 仓库。
