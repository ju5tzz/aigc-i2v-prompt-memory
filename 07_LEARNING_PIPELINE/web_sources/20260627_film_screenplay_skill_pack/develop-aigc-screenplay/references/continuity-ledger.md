# 连续性状态账本

## 目的

记录跨场次和跨生成片段必须保持一致的事实。它不是剧情复述，而是状态差异表。

## 状态类别

### 人物

- 所在位置；
- 身体方向和移动方向；
- 知道与不知道的信息；
- 对其他人物的关系和信任；
- 情绪能量；
- 伤势、污损、湿润、妆容和头发；
- 服装与装备；
- 持有、失去或交出的道具。

### 场景

- 日期和时刻；
- 天气与能见度；
- 主光方向与可见光源；
- 门窗、家具、车辆和固定物位置；
- 破坏、血迹、水、火、烟和碎片；
- 入口、出口与人物移动方向。

### 叙事

- 已公开信息；
- 角色私下掌握的信息；
- 谎言和误解；
- 伏笔状态；
- 未兑现承诺；
- 倒计时或资源消耗。

## 更新规则

每场戏：

1. 引用进入状态；
2. 只记录本场发生变化的字段；
3. 创建新的状态 ID；
4. 将新状态作为下一场输入；
5. 若回改早期场次，检查所有下游引用。

## 冲突检查

交付前检查：

- 已丢失的道具是否重新出现；
- 伤势和污损是否无原因消失；
- 角色是否提前知道尚未获得的信息；
- 昼夜和天气是否无过渡变化；
- 人物移动方向是否与空间出口冲突；
- 关系是否无事件支撑突然改变；
- 已破坏场景是否恢复；
- 已回收伏笔是否被再次当作未知。

## 状态命名

```text
CHR001-S0 角色初始状态
CHR001-S1 第一次关键变化
ENV002-E0 场景初始状态
ENV002-E1 场景受损状态
PROP004-P0 道具完整
PROP004-P1 道具损坏或耗尽
```

状态编号表示连续版本，不表示好坏或镜头顺序。
