# Seedance 2.0 官方指南资料包价值分析

- 来源：飞书官方指南《即梦 Seedance 2.0 使用手册（全新多模态创作体验）》
- 本地资料包：`07_LEARNING_PIPELINE/web_sources/20260628_lark_seedance_2_official_guide/`
- 分析日期：2026-06-28
- 处理原则：这是官方指南；若与仓库既有信息冲突，官方指南优先。

## 结论

这份官方指南对仓库有实质价值，但价值不在“新增一套提示词写法”，而在确认并修正 Seedance 2.0 的能力边界：

1. Seedance 2.0 已经明确进入图像、视频、音频、文本四模态组合创作，不应再只按“图生视频 + 文本提示词”理解。
2. 仓库原有“提示层 / 参考层分离”方向正确，但最终 Skill 包需要增加“参考对象职责表 / 平台绑定备注”这个中间层，否则无法覆盖官方推荐的全能参考用法。
3. 官方把参考视频的职责从“运镜参考”扩展到动作节奏、镜头语言、创意特效、复杂模板复刻；仓库现有 `04_ASSET_RESPONSIBILITIES.md` 对视频参考的定义偏窄。
4. 官方确认音频参考是一级输入，不只是提示词里的 SFX 字段；仓库“默认禁止 BGM”需要改成“默认不额外添加 BGM，除非用户明确上传音频/音乐参考并指定其职责”。
5. 官方新增的视频延长、视频编辑、音乐卡点、音色复刻能力，应进入最终 Skill 包的任务类型判断，而不是被塞进普通 I2V 分镜模板。

## 与仓库已有规则的关系

### 1. 被官方强力确认的既有规则

**I2V 是连续视频事件，不是让一张图动起来。**

官方开篇明确 Seedance 2.0 支持图像、视频、音频、文本四种模态输入，并强调视频创作不是单纯“生成”，而是对表达的控制。这与 `01_ACTIVE_RULES/01_I2V_CORE_RULES.md` 完全一致。

**参考资产必须有职责。**

官方多次要求提示词中说明素材是首帧、动作参考、声音参考、编辑对象还是融合对象。这与 `01_ACTIVE_RULES/04_ASSET_RESPONSIBILITIES.md` 一致，但官方给出的职责颗粒度更细。

**复杂运镜不是禁区。**

官方展示高难度/可控运镜、动作精准复刻、镜头连贯性、一镜到底等能力，支持 `05_CAMERA_MOVEMENT_CAPABILITY_MAP.md` 中“不要默认判断模型做不了”的方向。

**一镜到底可以成立，但要靠路径和连续性描述。**

官方把“镜头连贯性（一镜到底）更强”列为能力点，支持仓库现有“一镜到底是非常规但可保留”的判断。

### 2. 需要修正或扩展的规则

**参考视频职责偏窄。**

仓库现有定义：

```text
运镜参考视频负责摄影机运动、动作节奏、转场方式。
```

官方应修正为：

```text
参考视频可负责镜头语言、复杂动作节奏、创意特效、模板形式、转场方式，也可能作为编辑/延长/融合对象。
```

仍需保留职责边界：如果视频只负责运镜，就不要让它改角色或场景；如果它是编辑对象，则要单独标明。

**默认禁止 BGM 需要加条件。**

仓库模板默认写“禁止字幕，禁止 BGM”是为了避免模型乱加音乐。但官方支持音频输入、音色参考、音乐卡点。最终 Skill 包应写成：

```text
默认不额外生成字幕和无关 BGM。
如用户上传音频/音乐参考，必须明确它负责台词节奏、音色、环境声、动作声或音乐卡点。
```

**“同一空间参考图更稳”不是绝对规则。**

仓库过去强调连续镜头参考图最好来自同一母场景，这是对连续空间生成有效的规则。官方展示“融合多个视频”“在两个视频之间加一个场景”“视频编辑可用度高”，说明跨空间/跨素材也可以作为明确编辑任务成立。

修正方式：

- 连续空间镜头：仍优先同一母场景。
- 视频编辑/融合/转场：允许跨空间素材，但必须写清素材职责和过渡目标。

**Codex 不写 `@图1` 的规则需要分层表达。**

官方示例大量使用 `@图1`、`@视频1`、`@音频1` 这样的平台对象引用。仓库当前规则“不在正式提示词中替用户写 @ 标签”方向仍然正确，因为 Codex 无法知道平台实际绑定。

但最终 Skill 包不能只输出纯提示词，还需要输出一个独立的“参考对象职责表”：

```text
参考对象职责表
- 图1：首帧 / 起点构图 / 主体位置
- 图2：场景参考 / 空间结构
- 视频1：动作节奏与运镜参考
- 音频1：节奏或音色参考

提示词正文
只写模型可执行的画面、动作、镜头、声音、结束状态。

平台绑定备注
用户粘贴到即梦后，按参考对象职责表手动绑定对应素材。
```

这样既符合官方用法，也保持仓库“提示层与参考层分离”的核心原则。

## 有价值内容提炼

### A. 官方参数边界应进入最终 Skill 包

官方给出 Seedance 2.0 输入约束：

- 图片：jpeg/png/webp/bmp/tiff/gif，最多 9 张，小于 30 MB。
- 视频：mp4/mov，最多 3 个，总时长 2-15 秒，小于 50 MB，像素范围约 480p 到 720p。
- 音频：mp3/wav，最多 3 个，总时长不超过 15 秒，小于 15 MB。
- 文本：自然语言。

价值：这不是创作观点，而是硬边界。后续 Codex 在设计多参考方案时，应该主动检查素材数量和时长，不要设计超过平台限制的参考层。

### B. 入口选择是新增流程节点

官方说明 Seedance 2.0 支持首尾帧和全能参考入口。如果只上传首帧图 + prompt，可走首尾帧入口；如果要组合图像、视频、音频、文本，应进入全能参考入口。

价值：最终 Skill 包应在写提示词前先判断输入模式：

- 纯文本生成。
- 首帧 / 首尾帧。
- 全能参考。
- 视频延长。
- 视频编辑。
- 音频 / 音乐卡点。

这比单一“写 I2V 提示词”更符合官方产品结构。

### C. “参考万物”的正确用法是职责标注，不是素材堆叠

官方 2.1 多模态介绍中，Seedance 2.0 可参考动作、特效、形式、运镜、人物、场景、声音，但要求素材多时检查每个对象有没有标清楚，不要把图、视频、角色搞混。

价值：仓库的资产职责表应升级成“每次多模态生成前的强制检查项”，尤其适用于：

- 多角色。
- 多图 + 视频动作参考。
- 音频参考。
- 视频编辑。
- 多个视频融合。

### D. 视频参考能力被官方显著扩展

官方 Case 矩阵展示参考视频不只是运镜，还可承担：

- 高难度动作复刻。
- 镜头语言复刻。
- 复杂特效复刻。
- 创意模板复刻。
- 音画节奏参考。
- 一镜到底连贯性参考。

价值：`04_ASSET_RESPONSIBILITIES.md` 需要把“运镜参考视频”扩展为“视频参考 / 视频对象”，并进一步拆分职责：

- 动作参考视频。
- 运镜参考视频。
- 特效模板参考视频。
- 剪辑节奏参考视频。
- 被编辑视频。
- 被延长视频。

### E. 音频不是装饰层，而是控制层

官方支持上传音频，且列出“音色更准，声音更真”“可进行音乐卡点”。这意味着音频参考在 Seedance 2.0 里已是控制层。

价值：仓库现有 SFX 字段应扩展：

- 声音字段：当前片段可生成的环境音、动作音、台词。
- 音频参考字段：上传音频的职责，是口型、台词节奏、音色、环境声，还是音乐卡点。

### F. 视频延长和视频编辑应独立成任务类型

官方明确视频可以平滑延长与衔接，也能对已有视频做角色更替、删减、增加。视觉联系图中 `order_27_video_screens.jpg` 和 `order_27_images.jpg` 显示这一部分大量依赖“原视频/目标主体/目标场景/编辑说明”的组合。

价值：最终 Skill 包不能只包含“剧本转分镜”。应增加：

- `extend_video_prompt`：从已有视频继续生成。
- `edit_video_prompt`：替换、删除、增加视频元素。
- `bridge_two_videos_prompt`：在两个视频之间生成过渡片段。

### G. 真实人脸上传限制必须进入素材检查

官方交互部分明确：当前不支持上传包含写实真人脸部的图片和视频素材。

价值：后续素材检查必须增加：

```text
若素材包含写实真人脸，按官方说明可能无法上传或生成；应改用非写实角色、授权/合规素材，或调整为不依赖真人脸上传的方案。
```

这是官方合规限制，优先级高于仓库旧经验。

## 不建议吸收的内容

1. 不直接吸收官方 Case 里的具体示例提示词作为通用模板。很多示例依赖平台对象绑定和页面中的具体图/视频素材，不适合直接变成仓库通用提示词。
2. 不把所有任务都升级成全能参考。简单动作、单图首帧、普通对话仍可保持轻量。
3. 不把 `@图1/@视频1` 直接写入 Codex 默认输出正文。应输出参考对象职责表，让用户在平台中手动绑定。
4. 不把“模型能做复杂特效/一镜到底”理解成每个片段都该复杂。仓库“故事优先于运镜”的原则仍然成立。

## 推荐进入最终 Skill 包的模块

### 1. 输入模式判断

```text
先判断任务属于：
- 文生视频
- 首帧 / 首尾帧
- 全能参考
- 视频延长
- 视频编辑
- 音频/音乐卡点
- 多视频融合
```

### 2. 参考对象职责表

```text
素材名 | 类型 | 职责 | 是否进入提示词正文 | 用户平台绑定备注
```

### 3. 官方限制检查

```text
图片 ≤ 9 张；视频 ≤ 3 个，总时长 2-15 秒；音频 ≤ 3 个，总时长 ≤ 15 秒。
检查是否包含写实真人脸素材。
```

### 4. 视频参考职责分类

```text
视频参考可能负责：动作、运镜、特效模板、节奏、声音、延长对象、编辑对象。
必须明确本次只取哪一类职责。
```

### 5. 音频参考职责分类

```text
音频参考可能负责：台词节奏、口型、音色、环境声、动作声、音乐卡点。
```

### 6. 编辑/延长专用提示结构

普通分镜模板不适合直接套视频编辑任务。应新增专用结构：

```text
原视频内容：
需要保留：
需要替换/删除/增加：
参考素材职责：
编辑后的连续动作：
结束状态：
声音/音频参考：
```

## 对明天整合的建议

官方指南不需要推翻仓库结构，但需要把仓库从“提示词写作系统”升级为“Seedance 2.0 多模态生成任务系统”。

最值得优先整合的不是更多镜头术语，而是这四个前置判断：

1. 当前任务是什么输入模式。
2. 每个参考对象承担什么职责。
3. 是否触碰官方素材限制。
4. 这次是生成、延长、编辑、融合，还是音频/音乐控制。

这四项会比继续吸收更多外部 Skill.md 更能提升仓库的实用性。
