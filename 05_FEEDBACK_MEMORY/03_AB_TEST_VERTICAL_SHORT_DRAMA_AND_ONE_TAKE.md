# AB Test - Vertical Short Drama And One-Take

来源：2026-06-09 用户 A/B 实测反馈。

## 1. Shot list 默认成立

### 观察

`Blob Prompt vs Shot List` 测试价值有限。当前行业标准格式已经是结构化 `shot list`，可控性更强已经得到验证。

### 经验

Codex 输出短剧 I2V 提示词时，应默认使用 `shot list`。

整段式 `blob prompt` 只适合极短、单镜头、无复杂调度的场景，不作为常规工作流。

## 2. 竖屏快切成立，但不能过度平均化

### 观察

15 秒 9:16 竖屏、7 个短镜头、平均约 2 秒快切，模型基本可以遵循。

但快切不是越多越好。主要人物特写合理，普通士兵反应特写过多会造成镜头重叠和主次不分。

### 经验

竖屏短剧的反应镜头组应分层：

- 核心人物：可给近景或特写。
- 次要关键人物：可给短反应镜头。
- 普通士兵 / 群众：优先用群体反应、背景反应或声音，不要轻易给大量单人特写。

## 3. 人物运动目标必须写完整

### 观察

提示词写：

```text
李破奴接过水壶，转身扑向病榻。
```

模型可能让人物冲向错误方向。

更稳写法：

```text
李破奴接过水壶，转身扑向病榻上的萧烈。
```

### 经验

人物运动不能只写空间名词。必须写完整目标：

- 人物 + 动作 + 方向 + 目标对象。
- 如果目标对象是人，应写清“目标所在的空间 + 人物名”。

例如：

```text
他快步走向帐门右侧的押人士兵。
```

```text
她转身看向病榻上的萧烈。
```

```text
李破奴接过水壶，转身扑向病榻上的萧烈。
```

## 4. SFX 字段保留，但不作为优先测试项

### 观察

`无 SFX vs 明确 SFX` 测试价值有限。声音 / 同期声字段已经是结构化提示词的稳定组成部分。

### 经验

声音字段继续保留，但只写当前片段可生成、可同步、不会污染画面的声音。

不要写后期剪辑备注。

## 5. 焦段词在 9:16 近景中差异不明显

### 观察

在 9:16 近景镜头中，中文景别、景别 + 50mm、景别 + 85mm 之间几乎没有明显区别。

会产生后景虚化，但焦距差异没有有效体现。

### 经验

焦段词暂不作为竖屏近景镜头的强规则。

后续如要验证，应放到：

- 16:9 横版。
- 中远景 / 远景。
- 大空间纵深。
- 需要广角透视或长焦压缩的镜头。

## 6. 长去 AI 味负面项暂不进入工作流

### 观察

平时生成视频中没有明显所谓“AI 味”效果，本轮未测试长负面项。

### 经验

默认禁止项保持精简：

```text
禁止字幕，禁止 BGM。
```

不要默认加入大量“不要蜡质皮肤、不要 ghosting、不要 frame blend”等长负面提示。

## 7. 一镜到底成立，但属于非常规手段

### 观察

一镜到底方案在 9:16 竖屏中成立。摄像机确实会按提示词持续移动。

但故事板方案和一镜到底提示方案很难明确判断哪种更好。

### 经验

一镜到底可作为非常规拍摄手段保留。

适合：

- 入帐。
- 押送。
- 突然打断。
- 空间进入。
- 单一动作路径。

不适合：

- 普通对白。
- 需要强反应快切的短剧爆点。
- 多人物复杂调度。
- 需要稳定交代信息的段落。
