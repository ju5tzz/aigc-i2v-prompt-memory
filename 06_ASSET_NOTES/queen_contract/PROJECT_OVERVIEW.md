# Project Overview

## 基础信息

- 剧名：《签订合约后，皇后她赖着不走》
- 短名：皇后她赖着不走
- 频类：女频
- 题材：架空宫廷、先婚后爱、萌娃助攻、双向救赎
- 总集数：80
- 单集时长：1-2 分钟
- 核心一句话：假皇后带着真皇子赖在宫里不肯走，逼得冷情帝王跪地求她留。

## 叙事卖点

- 女主不是隐忍型宫斗受害者，而是精明市侩、敢开价、会谈判的牙行姑娘。
- 宫廷权谋被转译成“契约、账目、成本、收益、违约金、情报网”的商业博弈。
- 男主从冷面帝王、试探利用，到破防心动，再到公开护后、跪地求婚。
- 萌娃萧团子负责打破帝王威严，推动一家三口关系升温。
- 喜剧外壳包裹权谋与生死危机，整体应保持“嬉笑怒骂、甜虐交织、越甜越虐”的节奏。

## I2V 风格抓手

- 竖屏短剧优先：强冲突、强表情、强台词卡点。
- 女主高光不靠武力，而靠眼神镇定、嘴快、算账、反问、当场开价。
- 男主压迫感来自低声、静止、冷脸、突然靠近和被女主打破节奏后的微表情。
- 宫廷视觉不要只沉重：要让市井烟火、算盘、账本、银票、库房、商贾网络进入宫廷空间。
- 萌娃戏避免只拍可爱，应拍“父皇抱就哭、母亲抱就安静、抓算盘”等关系动作。

## 不要丢失的长期钩子

- 苏瑾是假皇后，但逐步成为真国母。
- 萧珩表面冷酷，实际在夺权与守家之间不断转变。
- 楚恒是纯粹权力反派，不要为他加洗白动机。
- 商业逻辑是女主解决宫斗、外交、军需、商税的核心方法。
- “那袋金子”从交易报酬变成最终聘礼，是全剧情感闭环道具。
