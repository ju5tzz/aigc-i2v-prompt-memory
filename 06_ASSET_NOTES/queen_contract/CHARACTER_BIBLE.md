# Character Bible

## 纪桃枝

- 身份：女主，大齐皇后 / 前牙行金牌牙人。
- 人设核心：被摄政王掳入宫顶替先皇后的平民傀儡，靠市井牙行经验在深宫谈判求生，最终成为真国母。
- 外形气质：东方古典淡颜系美人，杏眼灵动，精明狡黠，烟火气强，和已故先皇后七分相似但气质完全不同。
- 表演锚点：眼神机灵、嘴快、算盘式思考、遇强不怯、被触动时先嘴硬再泄露柔软。
- 台词口吻：语速快且清脆，三句话不离银子和买卖。
- 高频口头禅：“这在牙行可是要加钱的！”“定金不退，违约三倍！”“买卖不成仁义在，皇上别急着掀桌子啊。”
- I2V 提示重点：她的爽感来自“站稳、抬眼、反问、开价、算账、把对方话术拆穿”，不要写成普通柔弱宫女。

## 萧珩

- 身份：男主，大齐冷面帝王。
- 人设核心：表面被摄政王掣肘，实则蛰伏夺权；起初把纪桃枝当棋子，后来为她和团子打破祖制。
- 外形气质：浓颜系古典帅哥，眉眼冷、轮廓深、薄唇紧抿，帝王压迫感强。
- 表演锚点：少动、低声、冷眼、下颌绷紧；在纪桃枝面前被气笑、破功、笨拙温柔。
- 台词口吻：低沉冰冷，字字压人。
- 高频口头禅：“皇后想去哪？”“放肆，朕准你走了吗？”“天下是朕的，你也是。”
- I2V 提示重点：他不是纯霸总，而是权谋压力下长期自控的人；情绪变化适合用眼神松动、嘴角压笑、手部保护动作表现。

## 萧团子

- 身份：助攻萌娃，大齐皇长子。
- 人设核心：帝后意外结晶，打破冷宫廷规则的人形变量。
- 表演锚点：母亲怀里安静、父亲手里大哭；对算盘有天然亲近；在大场面中用童真拆掉威严。
- I2V 提示重点：萌娃戏要用动作关系承载情绪，不要只写“可爱”。

## 楚恒

- 身份：男反派，大齐摄政王。
- 人设核心：权倾朝野、通敌叛国、企图篡位；找纪桃枝顶替皇后是为了控制后宫与朝局。
- 外形气质：儒雅伪善，常带笑意，眼底阴鸷，常把玩折扇或玉扳指。
- 表演锚点：温和笑、慢条斯理、眼神阴冷；失控时笑容凝固。
- I2V 提示重点：不要给苦衷，不要洗白；他是纯权力欲反派。

## 沈妙音

- 身份：女反派，大齐贵妃 / 摄政王眼线。
- 人设核心：嚣张跋扈、嫉妒女主，常被纪桃枝用商业逻辑反杀。
- 表演锚点：眼尾上挑、红唇、刻薄笑、高高在上；输掉时脸色铁青、手指发抖。

## 冯德海

- 身份：太监总管 / 内务府大总管 / 摄政王暗线。
- 人设核心：截留物资、克扣宫人、投毒伪证，是后宫贪腐的具体执行人。
- I2V 提示重点：适合用账本、袖口、跪地冒汗、眼神闪烁表现。

## 柳娘

- 身份：牙行情报头子 / 后续商署总管事。
- 人设核心：纪桃枝的市井后援与情报中枢。
- I2V 提示重点：她代表宫外市井力量进入宫廷，画面可带账本、货单、商贾口信、暗号。

## 小杏

- 身份：凤仪宫大宫女 / 双面间谍。
- 人设核心：被沈妙音威胁做内应，后被纪桃枝救母策反。
- 表演锚点：胆怯、躲闪、跪地痛哭、效忠后的坚定。

## 苏蔓

- 身份：楚恒训练的替身皇后 / 后续女掌柜。
- 人设核心：被训练成先皇后影子，用来取代纪桃枝；后被纪桃枝救济走向自立。
- I2V 提示重点：她的“假”要通过过度端庄、背熟礼仪、被套话时露破绽表现。

## 顾岩

- 身份：侍卫长，萧珩与纪桃枝的武力保护线。
- 功能：保护纪桃枝、团子，传递萧珩暗中在意的证据，后期在刺杀与逼宫中承担动作戏。
