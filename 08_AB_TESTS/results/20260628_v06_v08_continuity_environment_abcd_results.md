## User Feedback Summary

本轮测试总体有价值，但测试案例本身存在一个明显设计缺陷：原定 10 秒 3 镜头，镜头数过少，且缺少真正的脸部特写镜头。因此，微表情差异没有被充分放大，V08 的对比不够明显。

后续类似测试不应只为了控制变量而压缩镜头数量。如果测试对象包含微表情、眼神、语气、犹豫、心虚、察觉等表演差异，应给至少一个清晰脸部特写或极近景反应镜头。

## Observed Differences

### V06: Continuous Information State

加入连续性信息后，除了角色动作和视线更容易贴合剧情关系，还出现了一个之前未重点预期的差异：角色配音情绪更明确。

在 B / D 版本中，沈砚开头诱使陆衡签字时，语气明显更低，有蛊惑感；A / C 版本则更平淡、更像普通对话。

这说明“角色当前知道什么、隐藏什么、误解什么、想达成什么”不仅影响画面表演，也可能影响台词语气和配音情绪。

### V08: Environment Participation

加入环境参与后，出现了有效亮点：陆衡准备签字时，突然响起雷声，帐外闪电一瞬间照亮他的脸。

这个环境细节不是装饰，而是参与了戏剧转折：它把“即将签字”这一动作卡在更强的心理压力点上，也强化了角色发现破绽前后的瞬间变化。

## Validated Value

两个机制都有效，但不能滥用。

V06 更适合作为当前片段的前置解释，而不是完整全局剧情梗概。它可以写画面外原因，例如角色刚被解雇、刚被背叛、刚得知真相、正在隐瞒身份等。只要这些信息能改变当前片段中的表演、语气、停顿或动作选择，就可以进入提示词。

但它不应扩展成上一集回顾、完整剧本复述，或与当前片段表演无关的背景说明。

V08 更适合用于剧情高潮、关键发现、身份反转、情绪爆点、重大决定之前或之后。它不适合覆盖所有镜头，否则环境会抢戏，削弱人物表演。

## Case Design Problems

1. 三个镜头不足以稳定测试微表情差异。
2. 缺少脸部特写，导致表演细节没有足够画面空间。
3. 若要测试 V08，环境参与最好绑定到具体戏剧节点，而不是平均铺满全段。
4. 若要测试 V06，除观察人物动作外，也应观察台词语气、停顿、音量和情绪色彩。

## Rule Upgrade Recommendation

进入最终 Skill 包时，应采用以下边界：

- 当前片段前置信息：只写能影响本段表演、语气、停顿和动作选择的画面外原因。
- 环境参与：只在高冲突节点启用，让环境对表演形成推力，而不是每个镜头都加环境描写。
- 微表情测试：必须包含脸部近景 / 特写镜头，否则测试结果不充分。
