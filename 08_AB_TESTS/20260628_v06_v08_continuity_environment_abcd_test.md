# V06 + V08 ABCD Test - 连续性信息状态与环境参与

日期：2026-06-28

用途：验证两个机制是否值得进入最终 Skill 包：

- V06：无信息状态 vs 连续性信息状态
- V08：微表情 vs 微表情 + 环境参与

本次采用 2x2 ABCD 测试，而不是两组独立 A/B。四版使用同一个历史写实场景、同一人物、同一镜头结构、同一时长，只改变两个变量。

## 1. 测试目标

### 待验证问题

1. 在提示词中加入“角色当前知道什么、误解什么、隐藏什么”，是否会让表演、视线、停顿、台词重点更符合剧情关系？
2. 在微表情之外加入环境参与，是否会增强情绪表达，而不是引入无关物体污染？
3. 同时加入 V06 和 V08 时，是否会比单独加入其中一项更稳定、更有戏剧张力？

### 四版变量

| 版本 | 连续性信息状态 | 环境参与 | 目的 |
|---|---|---|---|
| A | 无 | 无 | 基线：只写可见动作和微表情 |
| B | 有 | 无 | 只测试 V06 |
| C | 无 | 有 | 只测试 V08 |
| D | 有 | 有 | 测试两项叠加是否互相增强 |

## 2. 统一测试设置

- 风格：历史写实，明末边关军帐，真人写实质感，电影级自然光影。
- 画幅：9:16 竖屏短剧。
- 时长：10 秒。
- 镜头数：3 个镜头。
- 参与人数：3 人。
- 禁止字幕，默认不添加无关 BGM。
- 四版都不写平台 `@image/@video/@audio` 绑定。
- 四版都使用同一人物、同一动作、同一台词、同一镜头时长。

## 3. 测试场景

明末边关，风雨夜，军帐内。

三个人：

- 陆衡：边军守将，被逼签一份降书。
- 沈砚：监军，表面奉命审问，实际是叛徒，正在嫁祸陆衡。
- 阿照：受伤信使，被绑在帐内，知道沈砚伪造了降书印泥，但不敢直接喊出真相。

核心动作：

沈砚把笔推到陆衡面前，逼他签降书。陆衡原本犹豫，但在沈砚拇指上看到红色封泥痕迹，意识到降书印记来自沈砚。阿照在旁边用眼神提醒。陆衡最终没有签字，而是抬眼看向沈砚，说：“这印，不该在你手上。”

## 4. A 版：无信息状态 + 无环境参与

```text
生成一段 10 秒 9:16 竖屏历史写实短剧视频，由 3 个镜头组成。场景为明末边关军帐内，画面只出现陆衡、沈砚、阿照三人。禁止字幕，禁止无关 BGM。当前片段只生成逼签降书这一件事。

镜头1：3秒，中近景，军案正前方平视，固定镜头。
镜头任务：建立三人位置和逼签关系。
画面：陆衡站在军案左侧，沈砚站在军案右侧，阿照双手被绑坐在军案后方地面。军案上摊着一份降书和一支毛笔。沈砚把毛笔缓慢推到陆衡面前，陆衡低头看着降书，眉心微微收紧。
人物调度：沈砚身体略向前压，陆衡站住不动，阿照抬头看向两人。
台词：沈砚压低声音说：“签了，城门还能活。”
声音：帐内低沉呼吸声，毛笔擦过纸面的轻响。
结束状态：毛笔停在陆衡手边，陆衡仍未伸手。
硬切结束。

镜头2：3秒，陆衡面部近景，右侧微侧视，固定微推。
镜头任务：表现陆衡从犹豫转为察觉异常。
画面：陆衡眼神向下扫过降书，又抬眼看向沈砚的手。陆衡嘴角绷紧，眼睑轻轻一颤，右手悬在毛笔上方但没有落下。
人物调度：陆衡保持原位，视线在降书和沈砚手部之间移动；画面边缘带到沈砚按在军案上的手。
台词：无。
声音：陆衡压住呼吸，衣袖轻微摩擦军案边缘。
结束状态：陆衡的视线停在沈砚手上。
硬切结束。

镜头3：4秒，三人中景，军案侧前方平视，固定镜头。
镜头任务：表现陆衡拒签并反压沈砚。
画面：陆衡没有拿起毛笔，而是慢慢抬眼看向沈砚。沈砚嘴角保持很浅的笑，但眼神短暂闪躲。阿照坐在后方，紧张地看着陆衡。
人物调度：陆衡向前半步，沈砚没有后退，阿照身体绷紧但仍坐在地上。
台词：陆衡低声说：“这印，不该在你手上。”
声音：毛笔在纸上轻轻滚动一下，帐内呼吸声变重。
结束状态：陆衡盯住沈砚，沈砚的笑僵在脸上，阿照看向陆衡。
片段结束。
```

|---|---|---|---|---|---|
| 陆衡是否像“发现破绽”而不是普通犹豫 |  |  |  |  | 看视线、停顿、抬眼时机 |
| 沈砚是否像“心虚叛徒”而不是普通威胁者 |  |  |  |  | 看笑容僵住、眼神闪躲 |
| 阿照是否承担“提醒者”功能 |  |  |  |  | 看视线是否能引导陆衡 |

| 环境是否增强情绪 |  |  |  |  | 看雨声、灯影、墨痕、影子是否服务冲突 |
| 环境是否污染画面 |  |  |  |  | 是否引入多余人物、物体或抢戏 |
| 三镜头时长是否稳定 |  |  |  |  | 3s / 3s / 4s 是否大体成立 |
| 三人关系是否清楚 |  |  |  |  | 陆衡、沈砚、阿照是否各有功能 |

## 9. 判断标准

### V06 是否有效

比较 A vs B、C vs D。

如果 B/D 明显比 A/C 更能表现“谁知道什么、谁在隐藏、谁在提醒”，则 V06 值得进入最终 Skill 包。

### V08 是否有效

比较 A vs C、B vs D。

如果 C/D 的环境能增强压迫感、停顿和情绪转折，且没有引入无关物体污染，则 V08 值得进入最终 Skill 包。

### 叠加是否有效

比较 D vs B/C。

如果 D 既保留清楚的信息状态，又让环境服务情绪，且没有因为信息过多导致执行混乱，则最终 Skill 包应采用“连续性信息状态 + 环境参与”的组合，但只在高冲突情绪镜头中启用。
