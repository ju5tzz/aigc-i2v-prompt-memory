# Asset Responsibilities

Seedance / I2V 全能参考模式下，不同参考资产必须有明确职责，避免互相冲突。

## 1. 角色设定图

负责：

- 脸型
- 发型
- 服装
- 体型
- 五官
- 身份特征

不要让角色设定图承担场景调度任务。

角色设定图属于参考层，不属于 Codex 输出的提示词正文。

Codex 生成提示词时，只写人物名、动作、站位、视线和台词：

```text
镜头2：3秒，李破奴近景，侧视，固定镜头。
```

用户进入 I2V 平台后，再手动把人物名绑定到对应角色设定图。以下只是平台最终输入示意，不由 Codex 直接输出：

```text
李破奴@人物资产
```

人物名可以服务于提示词写作和剧情调度，但真正让模型识别人物外貌的是平台参考层中的角色设定图。

Codex 不应猜测资产编号，不应在提示词正文中替用户写 `@` 标签。

## 2. 母场景图

负责：

- 空间结构
- 光影
- 地面
- 门窗
- 楼梯
- 城墙
- 阵地
- 主要方向关系

母场景是空间稳定的核心资产。

## 3. 裁切图 / 关键景别图

负责：

- 起点画面
- 中段画面
- 终点画面
- 镜头揭示阶段

裁切图最好来自同一母场景，而不是多张独立生成的相似图。

## 4. 故事板图

负责：

- 镜头路线
- 时间分配
- 信息揭示顺序
- 人物行动路径
- 最终状态

故事板不是替代母场景，而是说明如何使用母场景。

## 5. 运镜参考视频

负责：

- 摄影机运动
- 动作节奏
- 转场方式

如果有运镜参考视频，提示词中应明确它只负责运镜，不负责改变角色和场景。

## 6. 音频参考

负责：

- 口型
- 台词节奏
- 环境音
- 动作声
- 音画同步

不要默认禁用台词。台词是否保留由戏剧节奏决定。
