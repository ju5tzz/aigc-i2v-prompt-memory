# 清道夫分镜

## 定位

按用户最初提供的「清道夫分镜 · Seedance 2.0 影视工业化分镜」原版规则生成提示词。

清道夫不是普通分镜表，也不是剧情梗概拆镜。它的目标是把资产设定、摄影参数、画面调度、人物表演、声音设计、时间预算、物理约束统一写进可投喂提示词，让模型知道这场戏应该怎么拍、怎么演、怎么运动、怎么保持风格统一。

## 必须保留的原版骨架

输出必须围绕这五段结构，不要改成其他模板：

```text
一、基础设定
【基础设定】
▸ 角色 / 主体
▸ 场景
▸ 道具
▸ 声音
▸ 画幅

二、氛围与画质
【氛围与画质】
▸ 风格核心
▸ 视觉基调
▸ 色彩与影调
▸ 光影与参考

三、时间预算校验
目标生成时长
有效叙事时长
时间片预算表

四、画面内容·场景版分镜
【画面内容-xxx版】
▸ 分镜一：00.00-00.03
  景别：
  镜头情绪：
  构图：
  运镜手法：
  人物表演：
  环境参与：
  画面内容：
  声音/台词：

五、画质、风格与约束
```

## 核心原则

1. 资产锁定而非人物简介：角色必须写清年龄、性别、体型、五官、发型、肤色、服装款式/颜色/材质、配饰、气质和表演逻辑。
2. 摄影机级画质参数：不能只写“电影感”，要写摄影机质感、镜头型号/焦段风格、景深、动态模糊、调色方案、光源方向。
3. 分镜是情绪发生的过程：每个分镜必须写镜头情绪、人物微表演、环境参与，而不是只写人物站位和剧情动作。
4. 微表演替代情绪标签：把“愤怒、害怕、暧昧、压迫”翻译成眼神、呼吸、指节、喉结、停顿、肩线、嘴角等可见动作。
5. 环境是情绪放大器：风、帘、灯、尘、反光、回声、衣料、道具都要参与叙事。
6. 时间预算必须写：每条提示词明确目标生成时长、有效叙事时长、时间片预算表。
7. 兜底约束防崩坏：结尾写画质、风格统一、物理连续性和动作约束。

## 执行流程

1. 读取用户剧本或场景，提取角色、场景、情绪核心、叙事目标。
2. 判断适合生成的单条提示词范围。Seedance 单条建议 4-15 秒；超过承载量时拆成多条清道夫提示词。
3. 对每条提示词都按原版五段式输出，不要只给“镜头号 + 时间轨道”。
4. 在“基础设定”里完成资产锁定，不要把角色设定降级成表格摘要。
5. 在“氛围与画质”里写摄影级参数，不能只写总风格口号。
6. 在“画面内容·场景版分镜”里逐个分镜写八项：景别、镜头情绪、构图、运镜手法、人物表演、环境参与、画面内容、声音/台词。
7. 最后添加“画质、风格与约束”，保证人物、道具、光影、动作、空间连续。

## 时间预算规则

使用原版拍数规则判断能不能生成：

- 一个物理动作 = 1拍
- 一次主运镜 = 1拍
- 一次明确环境变化 = 1拍
- 8字以内短对白 = 1拍
- 9-16字对白 = 2拍
- 超过24字对白必须拆分

时间预算表推荐字段：

```text
| 时间片 | 段落秒数 | 预算拍数 | 实际拍数 | 对白字数 | 风险结论 |
```

## 竖屏短剧规则

- 9:16 竖屏时，人物脸部、关键道具、牌匾文字、手部动作保持中央安全区。
- 少用横向大全景，多用前景-中景-后景纵深构图。
- 人物通常位于中下部，灯、帘、门头、牌匾等空间信息位于上三分之一。
- 动作不能频繁出画，尤其是拔剑、摔倒、递物、跪地、抬手、抓握等动作。

## 不要做的事

- 不要把原版清道夫改成“全局画质锚点 + 资产表 + 审阅版分镜 + 投喂版提示词”。
- 不要用“连续性继承、负面约束”替代原版的“镜头情绪、构图、人物表演、环境参与”。
- 不要只按剧情顺序复述发生了什么。
- 不要让每条分镜都变成短句清单。清道夫的分镜要写出镜头如何制造情绪。
- 不要省略时间预算校验。
