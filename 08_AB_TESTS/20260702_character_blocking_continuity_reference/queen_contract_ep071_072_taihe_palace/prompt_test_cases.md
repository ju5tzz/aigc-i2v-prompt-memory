# 太和殿台阶站位参考提示词测试用例

> 本文件只记录测试用提示词骨架，不代表正式成片提示词。
> 所有用例都应结合人物设定图、服装图和项目正式 I2V 写法另行生成。

## 通用站位参考说明

当使用彩色剪影参考图时，在提示词正文中加入以下说明：

```text
本轮测试使用站位参考图：红色剪影代表苏瑾，黑金剪影代表萧珩，蓝色剪影代表礼官。剪影只表示站位、远近、朝向和动作关系，不表示人物外貌、服装、五官或最终画面风格。
```

## T00：纯文字对照组

### 目的

验证不使用任何站位参考图时，模型是否能仅凭文字稳定把二人放到太和殿台阶最高处。

### 参考图

- 人物设定图：使用正式角色参考。
- 母场景图：`assets/mother_scene_taihe_palace.png`
- 站位参考图：无。

### 测试片段

```text
生成一段 8 秒 9:16 竖屏视频。

场景：太和殿中央台阶最高处，殿门前平台。苏瑾与萧珩已经登上最高台阶，不在台阶中段，不在底部广场。

镜头1：3秒，中景，固定镜头。
画面：苏瑾站在画面左侧，萧珩站在画面右侧，二人并肩站在太和殿殿门前平台，背后能看到殿门和朱红立柱，台阶从他们脚下向画面下方延伸。
声音：台阶下百官低声议论，衣料轻响。

镜头2：5秒，萧珩近景转苏瑾反应。
画面：萧珩侧身看向苏瑾，眼神沉定，苏瑾微微抬眼看他，表情从端庄转为隐约不安又强行镇定。
台词：萧珩低声说：“朕有几句话，要当着天下人告诉你。”
声音：台阶下人群安静下来。

禁止字幕，禁止 BGM。
```

## T01：全景彩色剪影参考图

### 目的

验证“完整母场景 + 彩色剪影”是否能同时提供宏观位置与透视关系。

### 参考图

- 站位参考图：`assets/model_ref_C1_top_platform_standing_marker.png`

### 测试片段

使用 T00 的同一段提示词，并在开头加入通用站位参考说明。

观察重点：

- 二人是否在最高平台。
- 是否误把人物放到台阶中段。
- 是否因为全景图信息太多导致人物过小或位置不稳定。

- 站位参考图：`assets/model_ref_C1_top_platform_standing_crop_marker.png`

### 测试片段

使用 T00 的同一段提示词，并在开头加入通用站位参考说明。

## T03：顶部平台求婚动作参考图

### 目的

验证当萧珩从并肩站立切换为单膝跪地时，模型是否仍能保持同一个 C 位空间。

### 参考图

- 站位参考图：`assets/model_ref_C2_top_platform_kneeling_crop_marker.png`

### 测试片段

```text
生成一段 10 秒 9:16 竖屏视频。

本轮测试使用站位参考图：红色剪影代表苏瑾，黑金剪影代表萧珩，蓝色剪影代表礼官。剪影只表示站位、远近、朝向和动作关系，不表示人物外貌、服装、五官或最终画面风格。

镜头1：3秒，双人中景，略低机位固定。

镜头2：7秒，萧珩近景切苏瑾微表情。
画面：萧珩仰头看着苏瑾，眼神坚定而温柔，说话时手没有收回。苏瑾先错愕地垂眼看钱袋，随后眼眶变红，嘴角想压住却微微发抖。
台词：萧珩说：“朕今天把它还给你，再加上朕的整个天下作为聘礼。”
声音：萧珩声音压低但清晰，最后一句后停半秒。

禁止字幕，禁止 BGM。
```

## T04：平面图辅助组

### 目的

验证平面图是否能增强空间逻辑，尤其是 A、B、C 三段连续移动时的上下台阶关系。

### 参考图

- 站位参考图：`assets/model_ref_ABC_flat_map_marker.png`
- 可组合参考图：对应状态的裁切参考图。

### 测试建议

本组不建议作为第一优先级单独使用。更适合在 T02 或 T03 仍然出现空间漂移时，作为第二张辅助参考图加入。

观察重点：

- 模型是否能理解 A 底部、B 中段、C 顶部的顺序。
- 平面图是否会让画面变得像示意图，或引入非真实俯视构图。
- 平面图与场景裁切图同时存在时，哪一个权重更强。
