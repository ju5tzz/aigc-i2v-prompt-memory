# Extracted Rules - AI Micro Expression Prompt Cards

- 来源：用户提供 3 张“AI 微表情提示词”图片
- 当前状态：可吸收为人物表演提示词规则

## 1. 微表情是抽象情绪的可执行翻译层

### 原始观点

图片将“喜、惊、哀”拆成 30 种具体表情状态，并描述眼神、嘴角、眉毛、头部、呼吸和身体细节。

### 可迁移规则

I2V 提示词应避免只写：

```text
她很开心。
```

```text
他很害怕。
```

```text
她很悲伤。
```

应改写为可见微表情：

```text
她嘴角轻轻上扬，眼神放松柔和，脸颊微微抬起。
```

```text
他眼睛睁大，眉毛上提，嘴唇微张，肩膀微微后缩。
```

```text
她眼眶泛红，嘴唇紧抿，低头忍住眼泪。
```

## 2. 微表情只在合适景别中写细

### 适用镜头

- 近景。
- 中近景。
- 面部特写。
- 对话反应。
- 情绪转折。
- 角色独处镜头。

### 不适用镜头

- 远景。
- 大远景。
- 群像调度。
- 快速动作。
- 战场混乱镜头。

在远景中写“瞳孔放大、嘴唇轻颤”通常无法稳定执行。应改成更大的身体动作，例如后退、停住、低头、握拳、跪倒。

## 3. 一个镜头只选择少量微表情锚点

### 规则

一个镜头中通常选择 2-4 个表演锚点即可。

推荐组合：

- 眼神 + 嘴角。
- 眼神 + 眉毛 + 呼吸。
- 嘴唇 + 头部动作 + 手部动作。
- 眼眶 + 低头 + 声音。

不要在同一个镜头中堆叠过多状态，例如同时写“瞳孔放大、嘴唇颤抖、眉头紧锁、眼神空洞、嘴角上扬、脸颊上扬、低头啜泣”。这会造成表演冲突。

## 4. 情绪要分层，不要一概而论

### 喜

- 自然微笑：亲切、放松。
- 俏皮眨眼：活泼、小心思。
- 灿烂大笑：纯粹快乐。
- 坏笑 / 邪笑：狡黠、玩味。
- 甜蜜对视：温柔、暧昧。
- 暗爽得意：小小优越感。
- 苦笑 / 无奈笑：心酸、妥协。

### 惊

- 瞳孔放大：突发刺激。
- 瞳孔地震：极端震惊。
- 惊恐后退：本能防御。
- 战栗恐惧：高度恐惧。
- 怀疑警惕：戒备。
- 心虚躲闪：逃避、不安。
- 绝望失神：麻木失去希望。

### 哀

- 哀伤泛红：压抑难过。
- 空洞麻木：情感抽离。
- 泪水滑落：悲伤外溢。
- 隐忍不哭：克制痛苦。
- 低声啜泣：委屈压抑。
- 崩溃大哭：彻底失控。
- 默默流泪：孤独承受。
- 委屈撇嘴：渴望理解。

## 5. 与台词标点协同

微表情应和台词标点配合。

例如：

```text
她眼眶泛红，嘴唇紧抿，低声说：“我……没事。”
```

比：

```text
她悲伤地说我没事。
```

更容易让模型执行出停顿、克制和隐忍。

## 建议升级到正式规则的内容

- 增加“微表情提示只适合近景和特写”的规则。
- 增加“抽象情绪转译为眼神、眉毛、嘴角、头部、呼吸和身体动作”的规则。
- 增加“同一镜头不要堆叠过多微表情锚点”的规则。
