# A/B Test Plan - Vertical Short Drama And I2V Rules

日期：2026-06-09

状态：待执行

## 1. 本轮测试目标

本轮 A/B 测试用于验证仓库中若干“待验证经验”是否可以升级为正式规则。

优先测试对象：

- 竖屏短剧镜头节奏是否需要更强快切、特写和反应镜头。
- 结构化 shot list 是否优于整段 blob prompt。
- SFX / 同期声字段是否有助于动作节奏。
- 焦段词是否能减少默认平庸中景。
- 长负面提示是否真的能“去 AI 味”，还是会污染画面。
- 一镜到底中“摄影机路径优先”是否优于“动作列表优先”。

## 2. 推荐测试素材

优先使用 `00 FILES/分镜头脚本.txt` 中的第五集帐内片段。

原因：

- 同一空间：中军大帐。
- 同一角色关系：勤天、萧烈、李破奴、苏瑾、老军医、士兵、乌鲁。
- 戏剧节点明确：苏醒、震惊、跪谢、认错、病灶未除、细作入帐。
- 既有保守分镜版本，可作为对照组。
- 仓库已有竖屏短剧节奏反馈，适合验证。

建议画幅：9:16 竖屏。

建议每组 A/B 使用同一参考资产、同一片段内容、同一平台参数。每个版本至少生成 2 次，避免单次随机性误判。

## 3. 评分表

每条生成结果按 1-5 分评分。

| 指标 | 说明 |
|---|---|
| 角色一致性 | 人物外观、服装、身份是否稳定 |
| 空间一致性 | 是否仍在同一大帐空间，方向是否混乱 |
| 镜头执行力 | 景别、机位、运镜是否符合提示 |
| 动作可读性 | 关键动作是否清楚，例如睁眼、跪地、递水、押入 |
| 情绪冲击 | 是否有短剧需要的爆点和反应强度 |
| 台词/口型 | 台词归属、停顿、口型是否可用 |
| 声音节奏 | 同期声/SFX 是否帮助动作节奏 |
| 可剪辑性 | 是否容易剪出可用片段 |
| 污染/跑偏 | 是否出现无关道具、现代元素、画面误读 |

记录格式：

```text
测试编号：
版本：A / B
生成次数：
最可用结果：
总体评分：
最大成功点：
最大失败点：
是否建议升级为规则：
```

## 4. 测试矩阵

建议优先执行 6 组，共 12 个版本。

| 测试 | 变量 | A 版本 | B 版本 | 验证结论 |
|---|---|---|---|---|
| T01 | 提示词结构 | 整段剧情描述 | 结构化 shot list | 多镜头短剧是否必须 shot list |
| T02 | 竖屏节奏 | 原保守分镜 | 爆点快切版 | 竖屏短剧是否需要更强镜头节奏 |
| T03 | SFX 字段 | 无声音字段 | 明确同期声/SFX | 声音是否帮助节奏和动作 |
| T04 | 焦段词 | 只写景别 | 景别 + 焦段 | 焦段词是否提升镜头差异 |
| T05 | 负面提示 | 短禁止项 | 长去 AI 味负面项 | 长负面提示是否有效 |
| T06 | 一镜到底 | 动作列表优先 | 摄影机路径优先 | 一镜到底是否应摄影机优先 |

## 5. T01 - Blob Prompt vs Shot List

### 片段

建议使用：片段 7 `药材难找`。

### A 版本：整段剧情描述

变量：把 15 秒剧情写成连续段落，不拆镜头。

观察重点：

- 模型是否自行分镜。
- 是否准确完成“老军医提难题 -> 勤天准备接话 -> 士兵押乌鲁入帐”的打断节奏。
- 是否漏掉黑瘦少年入场。

### B 版本：结构化 shot list

变量：使用 4 镜头结构，每镜头写时长、景别、机位、画面、人物调度、声音、结束状态。

观察重点：

- 镜头边界是否更清楚。
- 打断节奏是否更稳定。
- 乌鲁入场位置是否更明确。

### 预期结论

如果 B 在镜头边界、入场动作、结尾状态上明显更稳，则把“多镜头短剧优先使用 shot list”升级到正式规则。

## 6. T02 - 保守分镜 vs 竖屏爆点快切

### 片段

建议使用：片段 1 `王爷睁眼`。

### A 版本：原保守分镜

沿用原 4 镜头：

- 萧烈睁眼中近景。
- 李破奴近景。
- 萧烈说水。
- 李破奴喊水。

### B 版本：竖屏爆点快切

变量：保留同一剧情，但加入特写、反应快切、物件特写。

建议结构：

```text
生成一段 15 秒 9:16 竖屏视频，由 7 个短镜头组成。

镜头1：2秒，萧烈眼部特写，固定微推。
画面：萧烈苍白的脸只露眼部和眉心，眼皮连续颤动，最后睁开一条缝。
声音：帐内压低呼吸声。

镜头2：2秒，李破奴近景，低机位轻微仰拍。
画面：李破奴猛地前探，眼眶发红，嘴唇发抖。
台词：“王爷……王爷！”

镜头3：2秒，老军医近景快切。
画面：老军医瞪大眼，手里的银针停在半空。
声音：老军医倒吸一口气。

镜头4：2秒，将士反应组，三连快切。
画面：三名将士依次看向病榻方向，每人都是不可置信的单人近景。
声音：压抑吸气声，甲片轻响。

镜头5：3秒，萧烈唇部和喉结特写。
画面：萧烈喉结滚动，嘴唇干裂，极弱地说道：“破奴……水……”

镜头6：2秒，水壶动作特写。
画面：一名将士急忙解下水壶，金属扣撞响，水壶从画面右侧递入。

镜头7：2秒，李破奴中近景，手接水壶。
画面：李破奴接过水壶，转身扑向病榻。
结束状态：水壶已经在李破奴手中。
```

### 观察重点

- B 是否更有短剧爆点。
- B 是否因镜头过多导致角色/空间混乱。
- 7 个短镜头在 15 秒内是否可执行。

### 预期结论

如果 B 情绪冲击更强且空间不乱，则竖屏短剧可采用“爆点快切 + 反应镜头组 + 动作特写”的策略。

## 7. T03 - 无 SFX vs 明确 SFX

### 片段

建议使用：片段 3 `李破奴跪谢`。

### A 版本：不写声音字段

只写画面和动作。

### B 版本：写当前可生成声音

加入：

- 膝盖落地声。
- 甲片碰撞声。
- 众将齐声。
- 帐内短暂安静。

### 观察重点

- B 的跪地动作是否更有节奏。
- 齐声感谢是否更整齐。
- 声音字段是否导致不该出现的视觉元素。

### 预期结论

如果 B 的动作节奏和齐跪更清楚，则保留 SFX 字段作为视觉节奏提示，但仍禁止后期备注式声音。

## 8. T04 - 中文景别 vs 焦段词

### 片段

建议使用：片段 8 `又抓到一个细作` 的最后镜头。

### A 版本：只写中文景别

```text
中近景，平视，固定慢推。镜头推到黑瘦少年脸上。
```

### B 版本：中文景别 + 焦段词

```text
50mm 标准镜头，中近景，平视，固定慢推。镜头从少年胸口位置缓慢推到脸部，背景帐内众人轻微虚化，但仍能看出都在看他。
```

可追加 C 版本：

```text
85mm 长焦压缩感，少年脸部近景，背景人物明显虚化，只保留压迫感和注视感。
```

### 观察重点

- 焦段词是否改变景深和压迫感。
- 是否减少默认平庸中景。
- 是否影响角色脸部稳定。

### 预期结论

如果 B/C 明显更稳定地产生镜头差异，可把焦段词列为“可选增强词”，但不作为必填项。

## 9. T05 - 短禁止项 vs 长去 AI 味负面项

### 片段

建议使用：片段 5 `勤天扶起李破奴`，动作平稳，便于观察画质差异。

### A 版本：短禁止项

```text
无字幕、无水印、无logo、无现代元素。真人写实质感，电影级自然光影。
```

### B 版本：长去 AI 味负面项

```text
无字幕、无水印、无logo、无现代元素。不要蜡质皮肤，不要假 bloom，不要滥用镜头炫光，不要过锐数字细节，不要游戏引擎渲染感，不要漂浮橡胶物理，不要融化脸，不要断手，不要 ghosting，不要 frame blend。
```

### 观察重点

- B 是否更真实。
- B 是否引入“断手、融化脸”等污染联想。
- B 是否削弱动作执行。

### 预期结论

如果 B 真实感提升但污染不明显，可保留“短去 AI 味负面词”。如果污染或无收益，则维持现有短禁止项规则。

## 10. T06 - 动作列表优先 vs 摄影机路径优先

### 片段

建议额外做一个简单动作测试，不必放在第五集主线里。

场景：中军大帐，士兵押黑瘦少年入帐。

### A 版本：动作列表优先

```text
士兵押着黑瘦少年进入大帐，少年挣扎，被推到帐中央跪下。帐中众人转头看向他。
```

### B 版本：摄影机路径优先

```text
一镜到底。摄影机从帐内右侧低位开始，先拍到门帘被急促掀开；士兵押着黑瘦少年从帐门逆光进入时，镜头向后退让，保持少年在画面中央；少年被推向帐中央时，摄影机贴着右侧木柱横移避开士兵身体；少年膝盖落地时，镜头降到低位，最后从少年肩后越肩看见帐中众人同时转头看向他。
```

### 观察重点

- B 是否更像一镜到底。
- B 是否比 A 更稳定交代空间方向。
- B 是否因路径过细导致失败。

### 预期结论

如果 B 明显更好，可把“一镜到底时摄影机路径优先于动作列表”升级为正式规则。
