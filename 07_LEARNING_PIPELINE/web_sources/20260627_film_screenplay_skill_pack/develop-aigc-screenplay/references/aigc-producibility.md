# AIGC 可生产性诊断

## 目的

识别可能导致身份漂移、动作失败、空间混乱、物理结果不清或大量返修的剧本设计。诊断不自动改写核心创作。

## 风险等级

### 低

单主体、简单动作、稳定场景、少量交互，状态容易锁定。

### 中

两至三人同框、明确的道具交互、有限运动或环境变化，需要参考和连续性控制。

### 高

多主体调度、复杂手部交互、打斗、高速运动、口型密集、动物/异形、液体、镜面或连续破坏。

### 极高

多个高风险因素叠加，并要求跨长时间保持精确身份、空间和物理连续。

## 风险分类

- 多角色同框与遮挡；
- 相似人物的身份混淆；
- 精细手部、拥抱、传递和接触；
- 连续打斗、高速运动和复杂受力；
- 群众、大场面和多主体同步；
- 镜面、玻璃、透明、液体和复杂材质；
- 动物、怪物和非标准身体；
- 口型、长对白和多人抢话；
- 场景大幅变形、破坏或跨环境变化；
- 伤势、血迹、污损、湿润和服装连续；
- 空间轴线、出入口和移动方向；
- 烟、火、粒子等遮挡关键动作的视效；
- 精确文字、屏幕界面和小物细节。

## 诊断格式

```text
场次：
风险等级：
风险类型：
具体证据：
故事必要性：
失败时会损害什么：
建议处理等级：
建议方案：
保留的戏剧功能：
可能损失：
下游优先测试：
```

## 处理等级

### 1. 保留并攻克

用于故事不可替代、视觉收益高的设计。清楚标记关键资产和连续性，让下游专项测试。

### 2. 保留功能，调整表现

可采用：

- 减少同时发生的动作；
- 把复杂动作拆成意图、发力和结果；
- 用声音、遮挡、反应或后果替代最不稳定的过程；
- 降低同时同框人数；
- 让关键对白发生在更稳定的构图或表演状态；
- 复用场景与资产状态。

### 3. 重写场景

只有当原设计无法可靠传达核心信息或代价失衡时采用。涉及高潮、结局、主题或人物选择时必须先说明损失并确认。

## 禁止做法

- 把“难生成”直接等同于“不值得写”；
- 未告知用户就删除核心高潮；
- 用含糊的“史诗、震撼、高级感”代替可执行动作；
- 在剧本层提前写具体模型参数；
- 对所有场景都给出同样的泛化风险警告。
