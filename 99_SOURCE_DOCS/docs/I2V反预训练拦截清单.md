# I2V反预训练拦截清单｜GPT项目版

用途：
当讨论 I2V、Seedance 全能参考、故事板、AI短剧镜头设计时，用于拦截模型的旧式 AI 视频认知。

核心原则：
如果模型本能地想“保守一点”“别写台词”“别做运镜”“别做复杂调度”“先做首帧”，先暂停判断，检查这是否是旧预训练经验，而不是当前工具实测结论。

拦截1：不要把口型同步当成主要风险
错误反射：台词多了会不会口型对不上。
正确判断：当前 I2V 对口型能力已经足够强，台词是否保留由戏剧节奏决定。
行动：台词该写就写，但控制节奏和归属，不因为口型恐惧删台词。

拦截2：不要把平静表情误判为失败风险
错误反射：平静、凝视、克制情绪 AI 演不出来。
正确判断：风险不是情绪平静，而是没有可执行动作。
行动：给平静情绪增加可拍动作，例如凝视、停顿、呼吸、握紧、转头、风吹衣甲。

拦截3：不要把所有运镜都当成漂移风险
错误反射：镜头一动就会乱。
正确判断：环绕、推拉、跟随物体、多阶段运镜是可用的；高风险主要是长距离自由飞越和复杂空间重建。
行动：先判断运镜类型，不要把安全运镜阉割成固定机位。

拦截4：真正风险是状态改写，不是大动作
错误反射：爆炸、冲击、大动作危险。
正确判断：外部物体进入并发生事件通常可做；难的是强行改变参考图中已有对象的状态。
行动：用“事件过程”替代“状态改写”。

拦截5：故事板不是万能，不要滥用
错误反射：所有 I2V 都要故事板。
正确判断：普通对话、简单动作不一定需要；复杂运镜、空间揭示、机械奇观、战场调度才最适合故事板。
行动：先判断镜头任务，再决定是否使用故事板。

拦截6：15秒是上限，不是目标
错误反射：每个片段都写满15秒。
正确判断：单一揭示镜头可能只需要5-8秒。
行动：根据镜头任务判断时长。

拦截7：连续镜头的参考图必须同一空间
错误反射：多给几张好看的参考图就更稳。
正确判断：不同空间的参考图会导致跳切式强行对齐。
行动：起点、中段、终点必须属于同一主体、同一场景、同一方向。

最后提醒：
当模型对当前 I2V 工具产生“保守担忧”时，先怀疑这个担忧是否来自旧预训练经验。
